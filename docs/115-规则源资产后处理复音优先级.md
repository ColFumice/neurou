# 规则源编辑 / 资产增删 / 后处理任意参数 / 复音优先级（v6.9）

## 1. 规则源文本编辑

F7 新增源文本框：

- 选中规则/动作后显示原始声明块；
- 可改 `当` 条件、`效果` 行、耗时/优先级；
- 「应用源文本」整块替换入口源文件；
- 写前重新编译校验，失败不改文件；
- 支持单文件与模块入口（模块规则不进入列表）。

核心：

```ts
ruleBlockText(text, rule)
replaceRuleBlockText(text, rule, nextSource)
```

## 2. 资产重命名 / 删除

F6 资源栏：

- 名称输入框 → 重命名；
- 路径输入框 → 改 src；
- 「删除资产」→ 删除声明；
- 只允许未被 `配乐`/视觉端口引用的资产重命名/删除；
- 行级 patch 保留注释，按资产顺序匹配。

## 3. 任意后处理参数

F6「后处理」从三档改为：

- `0..2` 连续滑杆，步长 0.05；
- 实时改 GLSL 第二 pass 暗角/颗粒强度；
- 仍保留点击循环快捷方式。

## 4. 复音优先级

`startSustainedSpectrum(..., priority)`：

- F2 方向键合奏 voice 优先级 10；
- 普通弦/鼠标持续音优先级 0；
- 超过 12 voice 时偷**优先级最低**、同优先级最早 的 voice。

## 验收

- 单元 **395/395**：
  - 规则源块提取/整块替换+重编译；
  - 资产重命名/删除 patch；
  - 被引用资产拒绝。
- GUI **324/324**：
  - F7 源文本应用并写回；
  - 资产重命名写回；
  - 后处理滑杆任意值 1.35。
- 生产冒烟 / perf 通过。

## 边界

- 资产只能重命名/删除未引用项，引用更新暂不自动做；
- 规则源编辑是整块替换，块内注释随新文本保留/替换；
- voice stealing 按优先级+年龄，不做渐隐抢占。
