# 分步首次教学（v1.46.0）

## 教学页

首次进入游戏现在分三步：

```text
STEP 1 / 3  目标
STEP 2 / 3  操作
STEP 3 / 3  暂停 / 存档 / 帮助
```

内容来源：

- 目标：`GameModuleInfo.description[language]`；
- 操作：`GameModuleInfo.controls[language]`；
- 暂停 / 存档 / 帮助：统一说明。

## 操作

```text
← / →   翻页
Enter   下一步 / 最后一页开始游戏
Esc     跳过教学
H / ?   打开完整帮助
```

开始或跳过后写入：

```text
neurou.game.tutorial:<moduleId> = 1
```

以后进入不再显示。

## 兼容

- 已读教学的游戏直接进入 ready；
- 暂停菜单里的「帮助」仍然是完整帮助层；
- 编辑器 / 世界测试默认跳过教学，单独的教学页会清除 key 验证首次流程。

- 教学页文案固定三步，不能按游戏定制更多步骤；
