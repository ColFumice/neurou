# 流场六项补充完成（v1.13.0）

## 1. 每节点独立卷积混响

- 每个 FlowNode 拥有独立 `ConvolverNode`；
- `depth` 控制干声/混响发送比；
- `diffusion` 控制卷积脉冲长度与衰减；
- 节点之间互不共享混响尾音。

音频链：

```text
osc → filter → sampler → shaper → ADSR gain
  → panner → dry ─────────────→ master
            → send → convolver → master
```

## 2. 完整 ADSR

- `attack / decay / sustain / release` 四项独立参数；
- 数字/字母演奏键按下触发节点 ADSR；
- 松开进入 release；
- 视觉闭环幅度也由 ADSR 包络驱动，不再使用呼吸式正弦。

## 3. LoFi sample-rate reduction

- `sampleRate` 参数（4kHz..44.1kHz）；
- 每个节点独立 `ScriptProcessorNode` 做采样保持降采样；
- `bits` 用 `WaveShaper` 量化；
- 视觉上 sample-rate 降低会导致节点等值线出现空间量化阶梯。

## 4. `.nrm` 侧车持久化与导入导出

- `E` 导出 `.nrm`；
- `I` 导入 `.nrm`；
- 面板提供「导出 .nrm / 导入 .nrm」按钮；
- 格式：

```json
{
  "version": 1,
  "world": "examples/flow-field.nro",
  "nodes": [
    {
      "id": "n1", "x": 14, "y": 10, "radius": 6.4,
      "depth": 0.55, "diffusion": 0.62,
      "cutoff": 3200, "resonance": 2.4,
      "attack": 0.18, "decay": 0.4, "sustain": 0.45, "release": 0.8,
      "lfoRate": 0.16, "lfoDepth": 1.8,
      "bits": 12, "sampleRate": 32000, "layer": 0
    }
  ]
}
```

本地缓存仍在 `neurou.flow.nodes:<world>`。

## 5. 节点复制 / 删除 / 分层

- `C` 复制当前节点；
- `Delete` / `Backspace` 删除当前节点；
- `PageUp` / `PageDown` 调整层级（L0/L1/L2）；
- 层级越高，节点在视觉标量场中权重越高；
- 面板显示当前层级。

## 6. 键盘演奏触发节点

- `KEY_ORDER` 的数字/字母直接映射到节点序号；
- 按下触发该节点的 ADSR 包络；
- 松开进入 release；
- 多个键可同时触发多个节点；
- 不再只是环境声。

面板的 `data-flow-gates` 可观测当前按下的节点数。

## 边界

- `.nrm` 通过浏览器下载/上传，不自动写回磁盘；
- 节点音频需首次交互后启动；
- 层目前影响视觉权重与显示，尚未实现 solo/mute 面板；
- 撤销/重做尚未覆盖节点操作。
