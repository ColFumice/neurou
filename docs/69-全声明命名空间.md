# 全声明命名空间（v5.12）

> v5.11 只给弦加了命名空间。v5.12 把实体、系统、场景、规则、谱/关系谱、端口
> 等声明都纳入命名空间；引用仍由作者显式写限定名。

## 1. 语法

```nro
世界 全命名空间
  版本 0.1

命名空间 天气
  叙事弦 雨量
    类型 数值 0..100
    基线 40

  系统 潮汐
    阶段 传导
    效果
      天气.雨量 += 1

  场景 夜
    启用 系统 潮汐

  力迫 久旱
    当 天气.雨量 < 20
    效果
      天气.雨量 += 5

结局 停: 当 天气.雨量 >= 100
```

规则：

- 命名空间内不能声明 `世界`，不能嵌套命名空间；
- 所有声明名被改写为 `天气.<名字>`；
- 场景里的 `启用 系统 <短名>` 会自动补当前命名空间，也可写全限定名；
- 规则/效果里的弦引用必须显式 `天气.雨量`；
- 声明/引用名字允许带 `.`（v5.12 扩展 `readQualifiedName`）；
- 字符串会序列化为 `命名空间` 块；其它声明序列化为限定的扁平名字。

## 2. 边界

- 没有导出表/私有性；所有限定名仍全局可见；
- 没有命名空间内短名自动解析；
- 跨命名空间引用必须手写全限定名；
- 序列化会保留字符串命名空间块，但非字符串声明不再有命名空间分组；
- 没有嵌套/别名/导入重命名；
- GUI 仍为 273，无命名空间编辑 UI。

## 3. 验收

- 单元 **343/343**：新增
  - 实体/系统/场景/力迫进入命名空间；
  - 场景系统自动限定；
  - 世界/嵌套命名空间被拒绝；
  - 全声明序列化 roundtrip。
- 既有世界无命名空间时行为不变；
- `check` / `test` / `check:docs` / `build` 通过。
