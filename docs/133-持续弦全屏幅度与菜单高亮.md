# 持续弦全屏幅度与初始菜单高亮（v1.5.0）

## 1. 持续弦幅度覆盖全屏

问题：持续弦实际编辑幅度仍被 `maxPull` 截断，显示只有屏幕中段。

修复：

- 键盘按键幅度按当前持续布局的**最大按键距离**归一化，顶部/底部键可到 1.0；
- 波形显示以屏幕中心为轴，按上下可用空间自适应铺满，不再被 `maxPull` 压扁；
- 拖尾层同步使用同一中心偏移，避免重影错位；
- 波形编辑仍写入原来的 0..1 波段数据。

效果：

- `focusWaveSpread` 从约 **410** 提升到约 **852**；
- 上下留白 20px，不裁切。

截图：`artifacts/146-sustain-amplitude-final.png`

## 2. 调律台选项文字不再常亮

初始界面菜单：

- 默认没有任何选项高亮；
- 只有鼠标悬停项放大加黑加粗；
- 键盘 ↑/↓ 才显示键盘选中项；
- 鼠标进入选项区后切回悬停模式，离开立即清除。

新增 GUI：

```text
初始界面悬停高亮
鼠标离开后悬停高亮消失
```
