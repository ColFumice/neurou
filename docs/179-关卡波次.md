# 关卡 / 波次（v1.54.0）

## 通用波次契约

`GameModule` 新增可选：

```ts
wave?(state): number
```

GameHost 统一在画布右上角绘制：

```text
WAVE n
```

四款内置游戏：

| 游戏 | wave |
|---|---|
| 俄罗斯方块 | 当前 level |
| 贪吃蛇 | 当前 level |
| 乒乓 | 每 5 个得分 +1 |
| 打砖块 | 当前波次 |
| 外部插件 | 可选 |

## DSL 波次

```text
游戏 拆墙
  模块 打砖块
  结果弦 重力
  胜利分数 100
  难度 3
  波次 3
```

- 编译期限制 1..10；
- 序列化往返保留；
- App 传给 GameHost；
- 打砖块用它设置 `maxWaves`。

## 打砖块波次

- 清空砖块后：
  - 若未到最后一波：`wave + 1`，砖块重排，球速提高 8%；
  - 最后一波：`won = true`，游戏结束。
- 每清一波额外 +25 分。

## 验收

新增单元：

```text
清空砖块进入下一波，最后一波结束
```

新增 GUI：

```text
波次参数进入游戏
```

检查：

```json
{ "wave": 1, "maxWaves": 3 }
```

## 当前边界

- 波次目前主要影响打砖块；Tetris/Snake 的波次只是展示等级；
- 没有波次间暂停/过场；
- 没有每波目标/奖励配置；
- 外部插件可以返回 wave，但没有专门 DSL。
