# 月潮之间：把谱、关系谱、动态耦合放在一个世界里（v2.5.1）

> `examples/moon-tide.nro` 是一个综合示例：4 根弦、1 条谱音色、1 张关系谱、3 条耦合（其中一条强度由曲线决定）、
> 5 条规则（3 动作 + 2 力迫）、4 个信号、3 个结局。用来试听「世界真的在动」时它们如何一起工作。

## 1. 世界结构

| 元素 | 内容 |
|---|---|
| 弦 | 月相 / 潮位 / 岸线 / 灯火 |
| 谱音色 | `潮声`（6 段，平滑、循环；潮位弦的 `音色`） |
| 关系谱 | 两张：`月潮`（4×4，月相×潮位/灯火×月相，周期30、速度1.4、相位0.1）与 `灯影`（2×2，灯火×岸线，周期20、速度0.8、相位0.3）；F3 内用 Tab 切换 |
| 动态耦合 | `月相 → 潮位` 的强度 = `查关系谱("月潮","月相","潮位", 谱位("月潮"))`；潮位反向推岸线；灯火推月相 |
| 规则 | 6 个动作：观潮 / 筑堤 / 点灯 / 放舟 / 补网 / 守夜；3 个力迫：涨潮、夜潮、灯影 |
| 信号 | 潮声 / 潮退 / 岸裂 / 灯火将熄 / 月相沉 / 月出 / 灯暖（7 条，带文案） |
| 结局 | 淹没（潮位≥85）/ 长夜（灯火≤8）/ 平静（潮位≤40 且 岸线≥45 且 灯火≥30） |

## 2. 怎么玩

```bash
pnpm dev run examples/moon-tide.nro
pnpm dev sim examples/moon-tide.nro --runs 80 --ticks 90
```

在 GUI（开发服）：

```
http://127.0.0.1:5188/?world=examples%2Fmoon-tide.nro
```

- 八弦模式里按住/拨动弦，听潮位弦的「潮声」音色；
- `F2` 看潮声谱曲线，按 46 键试听；
- `F3` 看月潮矩阵：播放头随世界拍数（周期 30、速度 1.4、相位 0.1）走，关系曲线当前值就是月相→潮位的传导强度；**Tab 可切到第二张「灯影」矩阵**（周期20/速度0.8/相位0.3）；
- `P` 播放/暂停矩阵播放头，`Space` 开关聚焦，曲线编辑/行列编辑都在这里。

## 3. 设计意图

- 关系谱曲线负责**结构性变化**（月相如何牵动潮位），而不是靠规则写死每一步；
- 规则负责**玩家可做的事**与少数强制事件；
- 谱音色让潮位弦有“水声”而不是默认拨弦；
- 三个结局分别对应潮、岸、灯三个方向，容易被拉向不同命运。

## 4. 验收

- `pnpm dev check examples/moon-tide.nro` 通过；
- `pnpm dev sim ... --runs 80 --ticks 90` 至少出现「平静 / 淹没」两种结局（当前 sim 约 39% / 61%）；
- 其余 unit/GUI 测试不依赖该示例，保持 **244/244** 与 **196/196**。
