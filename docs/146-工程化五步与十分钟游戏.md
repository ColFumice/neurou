# 工程化五步：F7 流场、Overlay、世界操作与十分钟游戏（v1.21.0）

## 1. F7 流场 .nrm 编辑

- 在流场界面按 F7，打开当前目标弦类型的 FlowNode `.nrm` JSON；
- 可编辑节点数组；
- 应用后：
  - 写回 `localStorage["neurou.flow.nodes:<world>:<kind>"]`；
  - 同时以 `# @neurou:flow:<kind> ...` 注释侧车写回 `.nro`；
  - 重新进入 F10 时加载新节点。

## 2. RuntimeOverlay 序列化

保存世界时，测试世界 / 十分钟游戏 / 本机世界会自动把运行期覆盖层写回 `.nro`：

```text
# 音频配置（RuntimeOverlay）
# @neurou:audio:叙事 {"reverb":0.16,"cutoff":9000,...}
# 流场（RuntimeOverlay）
# @neurou:flow:叙事 [...]
```

- 进入世界时自动读取这些注释并恢复：
  - 按弦类型效果总线；
  - 流场节点；
- 这些行是 `.nro` 内的正式持久化侧车，编译器会忽略注释；
- 旧示例世界不写 overlay，保持回归测试的原始排版。

## 3. 世界栏删除 / 重命名 / 导入

世界栏每个本机世界：

```text
✎ 重命名
× 删除
```

世界栏底部：

```text
＋ 添加世界（模板向导）
导入 .nro
```

- 删除/重命名只影响本机世界；
- 导入 `.nro` 会先编译校验，通过后加入本机世界库；
- 当前世界被删除时回到默认测试世界。

## 4. 十分钟可通关示例

新增：

```text
examples/ten-minute.nro
```

「十分钟灯塔」：

- 5 类弦：信任 / 时间 / 灯火 / 线索 / 恐惧；
- 3 个场景；
- 6 个动作（检查、修灯、倾听、点亮、守夜、开门）；
- 力迫、信号、配乐；
- 3 个结局：归航 / 守夜 / 沉没。

世界栏现在有 2 个世界：

```text
测试世界
十分钟灯塔
```

## 5. 工程模板向导

「＋ 添加世界」打开三步向导：

1. 命名；
2. 选择模板：
   - 空白世界；
   - 测试世界；
   - 十分钟小游戏；
3. 确认并创建。

创建后自动进入本机世界，可继续 F7 编辑与保存。
