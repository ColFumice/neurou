# 测试世界、世界栏与 F7 DSL（v1.20.0）

## 1. 世界重置

- 世界栏只保留一个 **测试世界**：`examples/testbed.nro`；
- 测试世界覆盖八弦、谱、关系谱、耦合、规则、动作、信号与结局；
- 发布清单只导出测试世界；
- 旧示例文件只作为内部回归样本保留，不再出现在世界栏与发布清单中。

## 2. 世界栏加号

- 「世界」文件夹底部新增「＋ 添加世界」；
- 添加后创建一个基于测试世界模板的本机世界；
- 世界保存在 `localStorage["neurou.localWorlds.v1"]`；
- 地址形如 `?world=local:<id>`；
- 本机世界可继续写回、编辑与进入章节。

## 3. F7：当前元素的 DSL 声明编辑

任意界面按 **F7**：

| 当前界面 | F7 打开的声明 |
|---|---|
| 八弦 | 当前焦点弦的 `叙事弦/视觉弦/...` 块 |
| 谱 | 当前 `谱` 块 |
| 关系谱 | 当前 `关系谱` 块 |
| 流场 | 流场节点上下文（当前 JSON/侧车说明，只读） |

规则/动作编辑器保留在 **Shift+F7**。

- 只替换当前元素的声明块；
- 编译通过才写回；
- 保留其它声明、注释与排版；
- 这是 UI 世界与 DSL 之间最重要的“回到源码”入口。

## 4. 新功能对引擎数据/语言的映射

当前真源仍是世界 DSL → IR：

```text
.nro 源码 → 编译 → World IR → 确定性 Runtime → GUI
```

新增功能分三层：

### A. 进入 IR / DSL 的部分

- 弦、谱、关系谱、耦合、回路、规则、动作、信号、结局、章节；
- F7 直接编辑这些声明；
- F2/F3 的可写回编辑最终也投影回 IR。

### B. 运行期音频覆盖层

- 按弦类型效果总线：`reverb / cutoff / resonance / drive / LFO`；
- F10 FlowNode：声场、滤波、ADSR、LFO、LoFi；
- F12 采样循环：当前页面内存中的音频层；
- 这些尚未全部写入 `.nro`，属于 `RuntimeOverlay`；
- 流场节点使用 `.nrm` 侧车。

### C. 表现层

- 视觉端口、音频端口、记忆模式、节拍器、世界栏；
- 不改变 IR 语义，只改变播放与创作体验。

## 5. 如何创作一个真正可玩的游戏

1. 启动 `pnpm gui`，打开 `http://127.0.0.1:5188/`；
2. 世界栏进入「测试世界」或点「＋ 添加世界」创建新世界；
3. 用 DSL 写：
   - 8 类弦作为游戏状态；
   - 谱作为音色/曲线；
   - 关系谱作为关系网络；
   - 耦合与回路作为状态传导；
   - 动作/力迫/信号/结局作为玩法闭环；
4. 调律台试玩：
   - 拖弦改变状态；
   - 按住弦/键盘演奏；
   - 动作菜单执行世界动作；
5. F2/F3 调曲线与关系；
6. F7 直接编辑当前元素声明；
7. F10 调当前弦类型的音色与空间效果；
8. F12 录制记忆声部，F11 开节拍器；
9. `Ctrl+S` 保存（dev 写文件，本机世界写 localStorage）；
10. `pnpm build && pnpm release` 导出发布包。
