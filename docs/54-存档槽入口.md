# 存档槽入口：Backquote 淡列表（v4.4）

> v4.1 的 `?slot=` 只能改 URL。v4.4 给桌面一个不下线的入口：
> 按 ` 打开 0–9 槽列表，上下选择，Enter 切槽。

## 1. 操作

八弦视图中按 **`**（Backquote）：

- 出现极淡的竖向槽列表：`0 · 空` / `2 · 18 拍` / `3 · 42 拍 · 完`；
- `↑/↓` 选择，`Enter` 进入，`Esc` 或再按 ` 关闭；
- 列表打开时拦截其它键盘，避免误触拨弦；
- 选择空槽 → `fresh=1` 新局；
- 选择已有槽 → `resume=1` 续上；
- 切换前先保存当前槽。

无面板、无按钮、pointer-events:none；未选 alpha≈0.28，选中≈0.88。

## 2. 数据属性

| 属性 | 含义 |
|---|---|
| `data-slot-menu-open` | 列表是否打开 |
| `data-slot-menu-selected` | 当前选中的槽 |
| `data-slot` | 当前运行槽 |

`[data-testid="slot-menu"] .slot-row` 共 10 行，`data-slot-row` 为槽号。

## 3. 验收

- GUI **255/255**：新增

  - 上下选择到 2；
  - Enter 切到 slot=2。
- `check` / `check:gui` / `check:docs` / `build` / 生产冒烟通过。

## 4. 边界

- 桌面键盘专属；移动端仍靠 URL；
- 槽列表没有删除/复制/命名；
- 切换槽会 reload 页面（不是热切换）；
- 槽位仍是本机 localStorage；
- 列表只显示槽号/拍数/是否结束，不显示世界名或摘要。
