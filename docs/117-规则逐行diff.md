# 规则逐行 diff 编辑（v6.11）

## 1. 目标

把 F7 规则源应用从「整块覆盖」改为「逐行 diff」：

- 未改动的行按原字节保留；
- 未改行的行尾注释保留；
- 1:1 修改行若新行没有注释，沿用旧行尾注释；
- 增删行仍支持，但结构变化以整段新行为准。

## 2. 接口

```ts
patchRuleBlockText(text, rule, nextSource): PatchResult
```

- 使用公共前后缀 + 行数对齐；
- 行数相同：逐行替换，保留旧行尾 `#` 注释；
- 行数变化：以新行集合重建中间段；
- 调用方仍必须重新编译校验。

F7 「应用源文本」改用这个函数。

## 3. 验收

- 单元 **396/396**：
  - 修改一处效果值；
  - 条件行尾注释保留；
  - 块内注释保留；
  - 修改行尾注释保留；
  - 重编译通过。
- GUI 原有规则源应用用例继续通过；
- 文档 327 链接 / 120 文档。

## 4. 边界

- 行数变化时不保证旧行尾注释迁移；
- 不做字符级 diff；
- 源文本仍以用户最终草稿为准。
