# 参考谱：把谱当作目标曲线（v2.1b）

> v2.1a 让规则能读谱；v2.1b 让**音准仪/批量模拟**能拿一条谱当目标：
> 指定「哪根弦的轨迹」去贴合「哪条谱」，输出每局与批量的 MAE / RMSE / 贴合分。

## 1. 用法

CLI：

```bash
pnpm dev sim examples/spectra.nro --runs 200 --ticks 60 --ref 情绪地形:情绪强度 --json
```

- `--ref <谱名>:<弦名>`：把「情绪地形」谱按 0..1 时间位置采样，与「情绪强度」弦每拍归一化值比较；
- `--json` 输出里多一个 `reference` 块：

```json
"reference": {
  "spectrumId": "情绪地形",
  "stringId": "情绪强度",
  "runs": 200,
  "meanScore": 87.4,
  "meanMae": 0.06,
  "meanRmse": 0.08,
  "models": [{ "model": "random", "score": 82.1, "mae": 0.07, "rmse": 0.09, "runs": 67 }, ...]
}
```

不配置 `--ref` 时行为与之前完全一致。

## 2. 语义

- 参考曲线 = 谱的**锚点 bands**（不是运行时被调制的 values）按 `插值/循环` 在时间 `i/(n-1)` 采样；
- 模拟轨迹 = 该弦每拍的值按自身 `min..max` 归一化到 0..1；
- 指标：
  - `mae`：平均绝对误差；
  - `rmse`：均方根误差；
  - `score`：`clamp(round((1 - rmse) * 100), 0, 100)`（100 = 完美贴合）；
- 每局 `RunSummary.reference` 带本局指标；批量 `BatchResult.reference` 带均值与按模型分解；
- 参考谱/参考弦不存在时直接报错（不静默 0）。

## 3. 代码

- 新增 `packages/runtime/src/reference.ts`：`sampleReference`、`scoreReference`、`ReferenceSpec/Score`；
- `RunOptions/SimOptions` 增加可选 `reference`；`runOnce` 记录该弦每拍归一化值，结束时评分；
- `simulate` 聚合 `ReferenceBatch`（均值 + 按模型）；
- CLI `sim` 增加 `--ref`，JSON 输出 `reference`；纯函数与批量各有单测。

## 4. 验收

- `pnpm test` **186/186**：新增参考谱纯函数 2 项 + 批量集成 2 项（输出有限、每局带 reference、未知谱/弦抛错）；
- `pnpm test:gui` **151/151** 不回归；`check`/`check:gui`/`build`/生产冒烟通过；
- CLI 冒烟：`pnpm dev sim examples/spectra.nro --runs 20 --ticks 10 --ref 情绪地形:情绪强度 --json` 输出 `reference`。

## 5. 边界与下一步

- 参考谱按**锚点**比较，不含运行时调制后的动态曲线（未来可加）；
- 时间轴是均匀的（第 i 拍 / 总拍数），不能自定义时间映射/权重；
- 只比较一根弦；不比较整张图或关系矩阵；
- 还没有把参考分并入 `HealthReport.score`（目前作为独立指标输出）。

下一步（v2.1c）：
1. **关系矩阵谱**：所有配对 × 时间的关系数据；
2. 参考谱进入健康分/音准仪等级；
3. 自定义时间轴与权重。
