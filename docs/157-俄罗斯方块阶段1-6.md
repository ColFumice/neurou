# 俄罗斯方块：阶段 1–6 完成（v1.32.0）

## 阶段 1 · 实时调度层

新增 `packages/gui/src/gameLoop.ts`：

```text
FixedStepLoop
- 固定 60Hz 步长
- 输入队列按步消费
```

验收：

- 固定步长推进；

- 追帧上限；

## 阶段 2 · 游戏状态原语

新增 `packages/gui/src/tetrisEngine.ts`：

```text
10×20 棋盘
7 种方块 I O T S Z J L
4 向旋转 + 简单踢墙
碰撞 / 锁定 / 消行
软降 / 硬降
```

消行纯函数 `clearFullLines` 单独导出并测试。

## 阶段 3 · 实时输入层

新增 `packages/gui/src/tetrisInput.ts`：

```text
← →   移动
↑ / W / X   顺时针旋转
Z / Ctrl    逆时针旋转
↓ / S   软降（允许 repeat）
Space   硬降
P       暂停
R       重开
Esc     返回初始界面
Enter   开始 / 继续 / 重开
```

- 方向与旋转忽略 key repeat；
- 软降允许长按；
- 游戏按键阻止浏览器默认行为。

## 当前边界

- 游戏是宿主场景（TypeScript 引擎），不是 DSL 世界；
- 暂不支持 hold、锁定延迟、T-spin、连击；
- 暂未接入现有弦音频作为 SFX；
- 后续可把游戏状态/输入/渲染逐步下沉为 DSL 原语。
