# 谱：世界里的曲线数据 / 波形资源（设计文档）

> 本文是「数据集弦」的落地方案。结论：它不是第 9 根弦，而是弦网之外的第三类原语——
> **谱（spectrum / field）**：一条沿横轴分段、每个采样点是数据、**没有回复力**、
> 可被玩家锚定编辑、可被别的波调制、并能作为其他弦音色的曲线资源。
>
> 分阶段实现：**v1.7 语言/IR、v1.8 运行时、v1.9 GUI、v2.0 音色绑定（均已完成）**，
> GUI 谱模式、音频绑定放到后续版本，避免一次跨太多层。

## 1. 为什么需要新的原语

现有的世界模型有两个层次：

| 层 | 表示 | 行为 |
|---|---|---|
| 状态 | 8 类数值弦（标量） | 有回复力：被推离基线会回弹、沿耦合传导、有阈值/共振 |
| 关系 | 耦合 / 回路 | 弦之间的有向影响 |

但有很多“世界内容”既不是标量状态，也不是关系：

- 音色/波形：一段频谱，决定某根弦听起来是什么样；
- 环境曲线：叙事张力、节奏、难度、概率随位置/时间变化的弧线；
- 参考谱：音准仪/批量模拟想逼近的目标曲线；
- 关系矩阵：所有配对之间的关系剖面。

它们共同的形态是：**沿某个轴采样的一组数据点，点与点之间插值，整体可被编辑、被调制**。
用标量弦去硬塞会破坏回复力语义；写成一堆阈值/规则又无法表达连续形状。
所以新增第三类原语：**谱**。

## 2. 第一性语义

一条谱由三部分组成：

```
显示值 / 采样值 = clamp( 锚点曲线(位置) + 外部调制(位置, 时间), 范围 )
```

1. **锚点（anchor）**：玩家编辑的数据点。每个频段一个值，段与段之间按 `插值` 连接；
   - 没有回复力：锚点不会自己回到旧值；
   - 玩家修改锚点时，界面用缓动过渡（例如 180–300ms），不是闪变；
2. **外部调制（modulation）**：其他弦/耦合/规则对频段的写入；
   - 必须**显式寻址**（`谱.段` 或段范围），不允许隐式 FFT/卷积；
   - 叠加后 clamp 到 `范围`，保证有界；
   - 是“保持”还是“慢衰减”由谱的模式声明（见 §4），默认建议 `固定`（保持）。
3. **插值**：`线性`（默认）或 `平滑`（余弦/样条均可，规范里写死一种实现）；
   - 采样位置 = 归一化横轴 `[0,1]`，段数 = bands.length；
   - 端点外：默认 clamp 到端点值；`循环` 为 true 时按周期回绕。

### 与数值弦的关键区别

| | 数值弦 | 谱 |
|---|---|---|
| 值类型 | 标量 | 采样数组（曲线） |
| 回复力 | 有（回到基线） | 无（锚点即稳态） |
| 玩家手势 | 拖弦改基线 | 拖段值点，带缓动 |
| 耦合 | 两端标量相加 | 写入指定段/段范围（显式） |
| 阈值/共振 | 有 | 无（谱不共振） |
| 音频 | 拨弦事件 | 可作为音色/波表被引用 |

谱**不参与** `tab` 焦点循环、不占调律台 8 根弦、不进入阈值/共振/八弦叠影逻辑；
它是独立的“资源层”，有自己的编辑模式。

## 3. 语言表面（v1.7 编译期 / v1.8 模式）

```nro
谱 情绪地形
  段 0.1 0.4 0.8 0.5
  范围 0..1
  插值 平滑
  循环 否
  模式 固定            # 可选：固定（默认）| 受迫
```

- `段`（必填，1..256 个数字）：采样点；必须落在 `范围` 内；
- `范围`（可选，默认 `0..1`）：`min..max`，min < max；
- `插值`（可选，默认 `线性`）：`线性` / `平滑`；
- `循环`（可选，默认 `否`）：端点回绕（音频波表常用）；
- 名字在顶层唯一（与弦/实体/其他谱不得重名），便于未来引用；
- 未来引用语法（v1.8+ 设计，不在 v1.7 实现）：
  - 音色：弦声明里 `音色 谱:情绪地形`；
  - 规则/表达式：`谱(情绪地形, 0.42)`、`谱.情绪地形[2]`；
  - 调制：耦合目标可写 `谱.情绪地形 段 2..5`。

### v1.7 编译期校验

- 段数 1..256；数字必须有限；
- 段值必须在 `范围` 内（拒绝而不是静默 clamp，避免作者笔误被吞）；
- `范围` min < max；
- 插值/循环字段枚举校验；
- 重复谱名/与其他顶层名冲突；
- `stats.spectra` 出现在 IR 统计里；
- 序列化器输出规范块，round-trip 与幂等；
- 未知字段、缺 `段`、重复 `段` 都给出中文诊断。

## 4. 调制语义（v1.8 已实现）

每条谱有一个 `模式`（声明见 §3；默认 `固定`）：

| 模式 | 含义 | 适用 |
|---|---|---|
| `固定` | 锚点 + 调制持久叠加，clamp 到范围；玩家编辑改锚点 | 数据/音色/环境场 |
| `受迫` | 调制按每拍衰减回锚点（谱自己的“回复力”），但**锚点不反弹** | 瞬时强调、包络 |

- 调制写入必须带**段地址**（单段或 `a..b` 范围）；整条谱的“平均受扰”不是本阶段的语义；
- 多源调制按写入顺序叠加（确定性），每拍末尾 clamp 一次；
- 玩家拖点写入锚点，不覆盖当前调制；界面显示 = 锚点 + 调制（玩家看到的是最终曲线）；
- `模式` 字段自 v1.8 起可声明，默认 `固定` 保持现有世界兼容；受迫模式的衰减在每拍先衰减旧偏移、再叠加本拍调制。

## 5. 音频映射（v2.0 实现，先定规范）

谱最直接的价值是“把波形变成其他弦的音色”：

- 弦声明 `音色 谱:情绪地形` 建立引用；编译器校验谱存在；
- GUI 侧音频（Karplus-Strong）优先实现：
  - 谱归一化到 `[-1,1]`（按 `范围` 线性映射），按 `循环` 周期化；
  - `线性/平滑` 插值 → 波表采样；作为激励波形/共振体/频谱包络之一；
  - 世界状态调制谱的段 → 音色随世界变化（例如恐惧段上升 → 高频变尖）；
- 运行时音频求解器（未来）使用同一映射规范，保证 GUI/运行时听感一致；
- 确定性：采样率/插值/归一化写进规范；禁止依赖随机数；
- 引用循环（A 的音色用谱 S，而 S 被 A 调制）允许但必须有界/每拍有限步，不递归求值。

## 6. GUI 谱模式（v1.9 已实现）

- 独立模式（例如 `V` 进入/退出），**不混入 8 弦视图**；
- 极简白纸：一条曲线 + 段点 + 极淡网格/端点；无数字、无面板；
- 手势：拖段点上下改值（缓动跟随）、左右切换选中段、方向键微调、`Alt+Enter` 加段 /
  `Alt+Backspace` 删段（后续）、`Ctrl+Z` 缓动撤销；
- 实时反映调制后的曲线（静态锚点 + 动态调制用不同墨色/粗细极淡区分）；
- 写回：`谱` 块走行级/块级 patch，注释与排版保留；段增删走块级 patch。

## 8. 风险与边界

- **语义漂移**：调制不显式寻址会变成不可复现的“糊在一起”；必须坚持段地址 + clamp。
- **性能**：256 段 × 多谱 × 每拍调制；先限制 256 段，运行时用 TypedArray/增量更新。
- **8 弦不变量**：谱不是第 9 类弦；任何把谱塞进 `STRING_KINDS` 的捷径都会破坏视图/音准仪/批量模拟。
- **写回**：谱是新块类型；v1.7 只做规范序列化，行级 patch 留到 v1.9 与 GUI 一起做。
- **音频确定性**：GUI 音频是本地合成，必须与未来运行时音频共享映射规范，否则调律台听到的≠世界听到的。
- **兼容性**：`WorldIR` 新增 `spectra` 字段是加法；旧 `.nro` 照常编译（0 条谱）。
- **不做**：隐式 FFT/卷积、跨谱自动耦合、把谱当标量参与四则运算、实时音频线程安全（本阶段不碰）。

## 10. 一句话

**谱是“没有回复力的曲线数据”：它让世界拥有可编辑的场/波形，而第一件该被它改变的事，是其他弦的音色。**
