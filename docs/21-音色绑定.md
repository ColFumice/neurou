# 音色绑定：让谱成为可以听见的世界数据（v2.0）

> v1.7/v1.8 让谱能被声明、被运行时采样；v1.9 让谱能被拖拽编辑；
> v2.0 把谱接到声音上：**弦可以写 `音色 <谱名>`，拨弦时用这条谱作为 Karplus-Strong 的初始激励，
> 谱模式里按键盘也能直接试听当前谱**。

## 1. 语言：弦引用谱

```nro
谱 情绪音色
  段 0.12 0.35 0.7 0.45 0.22 0.55 0.82 0.3
  范围 0..1
  插值 平滑
  循环 是

叙事弦 信任
  类型 数值 0..100
  基线 55
  悬崖 25
  安全 75
  响应 缓出
  音色 情绪音色
```

- `音色 <谱名>` 是弦声明里的可选字段；
- 编译器要求谱存在（NRO2101：`弦「信任」的音色引用了不存在的谱「…」`）；
- 序列化会在弦块里写 `音色 <名字>`；没写音色的弦保持原来的合成音色；
- 改音色引用属于结构变化，写回会回退规范序列化（不是行级 patch）。

## 2. 声音：谱 → Karplus-Strong 激励

`waveMath.ksPluckBuffer` 新增可选 `timbre`：
- 把段值归一化到 `[-1,1]`、去掉直流分量、峰值归一化；
- 按 `插值`（线性/余弦）与 `循环` 采样成长度为延迟线的初始波形；
- 延迟线反馈与包络沿用原 Karplus-Strong；
- 没有 `timbre` 时走原来的噪声激励路径，既有 8 弦声音完全不变。

`stringAudio`：
- `pluck(..., timbre?)`：把谱作为激励；缓存键包含音色指纹；
- `previewSpectrum(bands, xNormalized, yNormalized, smooth, loop)`：给谱模式键盘试听用。

## 3. GUI：谱模式里的键盘试听

- `F2` 进入谱模式后，按 46 键隐形映射中的任意物理键（数字/字母/符号三行）：
  - 用当前谱作为音色，按该键在屏幕上的 x 位置决定音高，立即试听一次；
  - 音高随键位从左到右升高，音色就是曲线当前的形状；
- `Tab`/`Shift+Tab`（切谱）、方向键（选段/微调）、`Esc`/`F2`（退出）、修饰键不会误触发试听；
- root 新增 `data-auditions`、`data-last-key`；debug `window.__neurouSpectrum.auditions()`。

默认 `tuner.nro` 的「信任」已经写了 `音色 情绪音色`；拨一下信任弦即可听到这条谱的音色，
`F2` 进入谱模式拖段点、再按键试听，能直接听到波形变化。

## 5. 边界与下一步

- 音频仍由 GUI 本地合成（Web Audio）；运行时不产出音频，但谱的音色数据已经进入 IR；
- 一条弦只能引用一条谱；没有叠加/混合多条谱、没有包络/滤波参数；
- 谱模式试听是“按下即发声”，不做按键释放包络或复音管理（AudioContext 自然叠加）；
- 运行时的谱调制（v1.8）还没有实时反映到声音——目前听到的是当前编辑后的锚点曲线；
- 下一步：运行时调制 → 音色实时变化、多谱混合、规则/参考谱（v2.1）。
