# 运行层 v5.1：场景与系统

> 这是 [v5 架构基线](57-DSL引擎架构-v5.md) 的第一个实现切片。
> 本体没有变：弦网络仍是唯一的世界本体；场景/系统只在运行层调度与作用域。

## 1. 语法

### 系统

```nro
系统 潮汐
  阶段 传导
  当 能量 > 0
  效果
    能量 += 2
```

- `阶段`：`投递 / 输入 / 规则 / 传导 / 校验 / 终止 / 观测 / 收尾`，默认 `规则`；
- `当`：可选守卫；
- `效果`：必填，复用现有的效果语法（含弦值、关系谱写入、和弦施加）；
- 系统按声明顺序稳定执行，不做同阶段递归。

### 场景

```nro
场景 夜
  启用 系统 潮汐
  进入
    能量 += 5
  离开
    能量 -= 2
```

- 场景不声明弦，只启用系统 + 进入/离开效果；
- 按声明顺序，第一个场景是默认场景；
- 没有声明场景时，所有系统在隐式默认场景中启用；
- 没有声明系统时，行为与 v4.x 完全一致。

## 2. 运行语义

阶段与旧 tick 的对应关系：

```text
投递   → 到期耦合投递之后
输入   → 玩家动作之后
规则   → 力迫/和弦之后
传导   → 耦合传导之后
校验   → 公理检查之后
终止   → 结局判定之后
观测   → 信号 cue 之后
收尾   → 谱衰减/段落之后、tick+1 之前
```

- 系统效果产生的值变化进入本拍 deltas；是否继续传导由阶段决定；
- 进入/离开效果在切换时立即生效；
- 快照包含 `sceneId`，旧快照回退默认场景；
- 场景切换由 Host 调用 `Universe.transitionScene()`；DSL 的 `切换场景` 效果见 v5.3。

## 3. 运行时 API（v5.1 仍是内部内核）

```ts
universe.sceneName          // 当前场景名
universe.activeSystems()    // 当前启用系统名
universe.transitionScene('昼') // 进入/离开 + 切换
```

`Engine` facade 与 Host 隔离仍在 v5.2/v5.3。

## 4. 验收

- 单元 **323/323**：新增
  - 系统/场景解析、IR、序列化、roundtrip；
  - 非法系统引用/阶段；

## 5. 边界

- 场景不能声明局部弦；
- 系统没有私有状态、冷却、优先级，只有阶段 + 守卫 + 效果；
- `切换场景` 效果见 [v5.3](60-场景切换DSL.md)；`Engine` 门面见 [v5.2](59-Engine门面.md)；
- 没有可视化场景/系统视图；
- 预览蒙版、hot swap 尚未实现（v5.4）；
- 不新增游戏内容/示例世界。
