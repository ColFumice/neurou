# 现象层预览蒙版（v5.4）

> v5.4 把 GUI 从直接持有 `Universe` 迁到 `Engine` 门面，并给 Host 加了一层
> 全屏现象层预览：编辑器仍在原地，预览以蒙版叠加，不启动第二套模拟。

## 1. Space：预览蒙版

八弦视图按 **Space**：

- 全屏出现半透明纸感蒙版（`radial-gradient` + `backdrop-filter: grayscale`）；
- 中央极淡显示当前场景名；没有场景时回退章节标题/世界名；
- 下方显示当前拍数与启用的系统；
- 底部显示最近 4 条 runtime cue（台词/视觉/音频）；
- 再按 Space 关闭；
- **蒙版 `pointer-events: none`**，指针事件继续落到下面的编辑器；键盘编辑也不被拦截。

这不是第二个渲染器，也不是游戏画面：它是 `Engine.observe()` 的 Host 投影。

## 2. GUI 迁到 Engine

`App.tsx` 现在：

- `createEngine` 构造运行时；
- `engine.step()` 推进；
- `engine.dispatch()` 执行动作；
- `engine.snapshot()/restore()` 存档；
- `engine.state` 只读投影用于界面读取；
- `collectLanes` / `withCurrentBaselines` 接受 `Engine`。

GUI 不再 `new Universe`。`Universe` 仍是内部内核。

## 3. 可观测属性

| 属性 | 含义 |
|---|---|
| `data-preview-open` | 蒙版是否打开 |
| `data-preview-scene` | 当前场景 |
| `data-preview-tick` | 当前拍 |
| `[data-testid="preview-mask"]` | 蒙版容器 |
| `[data-testid="preview-scene"]` | 场景文字 |

## 5. 边界

- 结构编辑通过 `Engine.replaceWorld` 保 tick 热替换（v5.5），弦值/tick/预览不断；
- 值编辑在当前 Engine 上实时可见；
- 蒙版只有场景/拍/系统/cue，没有角色/画面渲染；
- Space 预览只在八弦视图生效；谱/矩阵的 Space 语义不变；
- 没有场景选择 UI；
- 蒙版不写回、不存档、不改变世界状态。
