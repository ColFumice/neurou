# 边界完善（v6.10）

## 1. 资产引用自动更新

重命名资产时：

- 音频资产 → 同步更新 `配乐 <资产>`
- 纹理资产 → 同步更新所有视觉端口 `贴图 <资产>`
- 声明行与引用行走同一个行级 patch，保留注释
- 删除被引用资产仍会拒绝（引用更新只做重命名）

## 2. 规则源块

F7 源文本编辑器：

- 载入当前规则块原文（含注释）；
- 用户未改动的注释按草稿保留；
- 整块替换后重新编译，失败不落盘；
- 边界：块内注释以用户编辑后的源文本为准。

## 3. 复音优先级可观测

- `StringAudioEngine.voicePriorities()`；
- Spectrum debug 暴露 `window.__neurouSpectrum.voicePriorities()`；
- GUI 验收：F2 方向键合奏 voice 优先级 10；
- voice 上限 12，超出时偷优先级最低、同优先级最早。

## 4. 后处理参数持久化

- 后处理强度按世界写入 `localStorage`：

```text
neurou.post.level:<世界文件>
```

- 刷新后恢复；
- 不写 `.nro`，不会改变世界语义。

## 5. Host 快照兼容

- 旧快照缺少 `stateVersion` 时按 1 处理；
- 仍校验 `abi === 'neurou-host/1'`；
- 单元覆盖 legacy 快照恢复。

## 验收

- 单元 **395/395**；
- GUI **326/326**；
- 文档 **326 链接 / 119 文档**；
- 生产冒烟 / perf 通过。

## 剩余边界

- 资产删除引用不自动做；
- 后处理参数是本地偏好，不进入世界源；
- 规则源编辑不是逐行 diff，而是整块替换；
- Host 跨 ABI 版本迁移仍需显式迁移器。
