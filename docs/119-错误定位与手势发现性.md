# 错误定位与手势发现性（v6.13）

## 1. 编译错误带行号

保存/写回/规则源应用失败时：

- `data-save-error-line` 暴露行号；
- 错误文本追加 `· 第 N 行`；
- F6/F7 编辑器顶部显示「编译错误 · 第 N 行」；
- 失败不写文件。

覆盖：

- 单文件写回；
- 模块入口写回；
- F7 规则源应用。

## 2. 手势帮助层

按 `?` 打开右下角淡层：

- Tab / ←→ / 拖动 / 拨弦；
- F2 / F3 / F6 / F7；
- Space / Ctrl+Z / R / ?；
- Esc 关闭。

无打开时无任何额外 DOM 文字，不破坏首屏克制。

## 3. 验收

- GUI **332/332**：
  - 规则源语法错误 → 错误行出现；
  - 规则编辑器显示错误行；
  - `?` 打开帮助层；
  - Esc 关闭帮助层。
- 单元 **397/397**（无新增，现有回归）。
- 文档 329 链接 / 122 文档。

## 4. 边界

- 模块项目的错误行号基于合并文本，入口行号可能偏移；
- 帮助层是手动手势，不做首次自动弹出；
- 错误行不回跳到具体编辑器光标。
