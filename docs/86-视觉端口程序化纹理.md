# 视觉端口程序化纹理（v5.29）

> v5.27 所有视觉端口共用同一张内置棋盘纹理。v5.29 让端口自己声明
> 纹理图案与尺度；仍是程序化生成，不依赖外部图片/资产服务。

## 1. 语法

```nro
视觉端口 雨幕
  参数 强度 雨量
  纹理 条纹 6
```

- `纹理 <图案> <尺度>` 可选；
- 图案：`棋盘`、`条纹`、`渐变`、`噪点`；
- 尺度默认 8，范围 `(0, 64]`；
- 只有视觉端口可以声明纹理，音频端口会报 `NRO2003`；
- 未声明时沿用 v5.27 的棋盘默认。

## 2. IR

```ts
interface IRPort {
  texture?: { pattern: string; scale: number };
}
```

- 端口帧 `BackendPortFrame.texture` 透传给 Host；
- GLSL artifact 记录 `texturePattern` / `textureScale`；
- 序列化保留 `纹理 …` 行。

## 3. Host 生成

`GlslCanvas` 在上传纹理时按图案生成 64×64 灰度：

| 图案 | 生成 |
|---|---|
| 棋盘 | 按尺度分格交替 |
| 条纹 | 纵向条纹 |
| 渐变 | 横向灰度渐变 |
| 噪点 | 确定性整数散列 |

- 全部无随机、无外部资源；
- 片元仍只做一次 `texture(uTexture, …)` 采样；
- 不同端口可以有不同的纹理。

## 4. 验收

- 单元 **363/363**：纹理进入 IR/序列化、音频端口拒绝纹理；
- GUI **278/278**：两个视觉端口 `条纹,渐变` 可观测，2 个 canvas；
- 生产冒烟 / perf 通过。

## 5. 边界

- 没有图片文件/纹理资产声明；
- 没有 UV 缩放/旋转/偏移端口；
- 没有多纹理/采样器数组；
- 纹理生成仍是 Host 内置，不支持作者自定义像素。
