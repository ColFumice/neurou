# 持续弦波形持久化（v5.42）

持续型弦的波形编辑此前只存在当前 GUI 会话，刷新即丢。v5.42 增加按世界文件持久化。

## 1. 存储

- localStorage key：

```text
neurou:sustained-waves:<worldFile>
```

- 每条持续型弦保存 32 段波形；
- 编辑时自动写回；
- 页面重载后自动恢复；
- 不同世界互不影响；
- 坏数据/隐私模式静默退回默认波形。

## 2. 与 `.nro` 的关系

v5.43 起，波形也进入世界源文件：

```nro
视觉弦 色温
  类型 数值 0..100
  基线 64
  波形 0.5 0.55 0.6 0.55 0.5
```

- 只允许持续型弦声明波形；
- 2..64 个采样，值在 0..1；
- 编译后进入 `IRString.waveform`；
- 序列化保留 `波形` 行；
- GUI 编辑时通过 `setStringWaveform` 更新 IR，并走行级 patch 写回，保留注释；
- 页面刷新优先使用 `.nro` 中的波形，再回退 localStorage。

## 3. 验收

- 单元 **376/376**；
- GUI **288/288**；
- 波形 IR/序列化/patch roundtrip；
- F2 合奏只取当前世界真实存在的持续弦；
- 手动：编辑波形 → 文件出现 `波形` 行 → 刷新保留；
- 生产冒烟 / perf 通过。

## 4. 边界

- 波形仍按“弦类别”在调律台内共享显示，若同类多根弦各有不同波形，GUI 只取第一根；
- localStorage 仍保留为本地缓存；
- 没有波形编辑器面板/重置按钮。
