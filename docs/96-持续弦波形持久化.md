# 持续弦波形持久化（v5.42）

持续型弦的波形编辑此前只存在当前 GUI 会话，刷新即丢。v5.42 增加按世界文件持久化。

## 1. 存储

- localStorage key：

```text
neurou:sustained-waves:<worldFile>
```

- 每条持续型弦保存 32 段波形；
- 编辑时自动写回；
- 页面重载后自动恢复；
- 不同世界互不影响；
- 坏数据/隐私模式静默退回默认波形。

## 2. 与 `.nro` 的关系

- 波形属于调律台演奏层，不写进 `.nro`；
- `.nro` 仍只保存世界本体/弦结构；
- 清空该 key 即可恢复默认波形。

## 3. 验收

- 单元 **371/371**；
- GUI **288/288**；
- 手动：编辑持续弦波形 → 刷新 → 波形仍保留；
- 生产冒烟 / perf 通过。

## 4. 边界

- 只持久化到当前浏览器，不跨设备；
- 没有 GUI 重置按钮；
- `.nro` 写回不包含波形。
