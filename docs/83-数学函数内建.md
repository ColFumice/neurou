# 数学函数内建（v5.26）

> v5.26 给表达式加入一组确定性数学内建，供规则、函数、谱参数使用。
> 全部是纯函数，不引入状态、不依赖随机数。

## 1. 内建

| 函数 | 参数 | 说明 |
|---|---|---|
| `正弦(x)` | 1 | `Math.sin` |
| `余弦(x)` | 1 | `Math.cos` |
| `平方根(x)` | 1 | 负数先夹到 0 |
| `向下取整(x)` | 1 | `Math.floor` |
| `向上取整(x)` | 1 | `Math.ceil` |
| `四舍五入(x)` | 1 | `Math.round` |
| `幂(x, y)` | 2 | `Math.pow` |
| `夹紧(x, lo, hi)` | 3 | `min(max(x, lo), hi)` |
| `插值(a, b, t)` | 3 | `a + (b - a) * t` |

- 参数/返回统一按数值处理；
- 负数平方根返回 0，而不是 NaN；
- 编译期检查参数数量与数值类型；
- 序列化后按普通调用保留。

## 2. 示例

```nro
值 = 夹紧(插值(0, 10, 0.5) + 幂(2, 3) + 平方根(16), 0, 100)
```

## 3. 验收

- 单元 **360/360**：新增
  - 数学内建运行时结果；
  - 序列化 roundtrip；
  - 类型/参数数量错误。
- 既有表达式/函数行为不变；
- GUI 仍为 276。

## 4. 边界

- 仅基础数学，没有随机数/噪声/矩阵运算；
- 没有角度制/弧度制切换（`正弦/余弦` 用弧度）；
- 没有精度/溢出特殊处理；
- 常量折叠暂不覆盖全部新内建；
- 没有复数/向量。
