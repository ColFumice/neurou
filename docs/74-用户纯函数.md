# 用户定义纯函数（v5.17）

> v5.17 给 DSL 加可复用的纯表达式：函数在编译期内联，
> 不进入运行时状态、不破坏确定性。

## 1. 语法

```nro
函数 夹紧
  参数 x, lo, hi
  返回 最大(lo, 最小(x, hi))
```

调用：

```nro
力迫 调
  当 值 < 70
  效果
    值 = 夹紧(值 + 50, 0, 100)
```

- `参数` 逗号分隔；
- `返回` 一个表达式；
- 函数可调用其他用户函数；
- 函数可引用世界弦（在调用点解析）；
- 函数进入命名空间时名字会被限定。

## 2. 编译期语义

```text
调用 夹紧(值 + 50, 0, 100)
  → 参数替换到函数体
  → 最大(0, 最小(值 + 50, 100))
  → 正常 lower / 类型检查
  → LExpr（运行时不认识“函数”）
```

- 参数数量错误 → `NRO2003`；
- 递归调用 → `NRO2008`；
- 函数体类型错误在调用点展开后报错；
- 参数被替换成调用点表达式，因此实参表达式只按正常求值一次。

## 3. 序列化边界

函数是**编译期构造**：

- IR 里没有函数表；
- 序列化后的 `.nro` 只保留内联后的调用表达式（无函数声明）；
- 语义不变，但作者结构会丢失；
- 这是 v5.17 的明确限制，不是运行时特性。

## 4. 验收

- 单元 **351/351**：新增
  - 函数内联并参与运行时；
  - 函数调用其他函数；
  - 参数数量/递归错误；
  - 序列化后行为不变。
- 既有世界不含函数时行为不变；
- GUI 仍为 276。

## 5. 边界

- 没有函数类型标注/重载/可变参数；
- 没有闭包/高阶函数/递归；
- 编译期内联，序列化丢失函数声明；
- 函数不能定义在系统/场景块内；
- 没有函数级诊断位置映射（错误落在展开后的表达式）。
