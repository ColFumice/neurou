# F10 全参数进入同一条弦效果总线（v1.29.0）

## 根因

之前只把 F10 的：

```text
depth / cutoff / resonance / drive / LFO
```

写进弦类型效果总线，其它参数没有真实音频路径：

- attack / decay / sustain / release：只改了流场视觉包络；
- diffusion：没有进入混响；
- radius / tension：没有音量/驱动映射；
- sampleRate：没有采样率降低。

所以用户听到的差异集中在这些参数上。

## 修复

弦类型效果总线现在包含完整参数：

```ts
KindEffects {
  reverb, cutoff, resonance,
  drive, lfoRate, lfoDepth,
  attack, decay, sustain, release,
  diffusion, level, sampleRate
}
```

音频链：

```text
input
 → lowpass filter
 → waveshaper(drive)
 → sample-rate reducer
 → ADSR gain
 → level
 → dry ─────────────→ master
 → convolver(diffusion) → wet → master
```

F10 节点映射：

| F10 参数 | 音频总线参数 |
|---|---|
| radius | level（音量/空间体量） |
| tension | drive 附加比例 |
| depth | reverb |
| diffusion | convolver 脉冲长度 |
| cutoff | lowpass |
| resonance | filter Q |
| attack/decay/sustain/release | ADSR gain |
| bits | drive |
| sampleRate | 降采样保持步长 |
| LFO rate/depth | filter LFO |

- ADSR 在每次拨弦/持续音触发时应用；
- sample-rate reducer 用 hold 实现；
- diffusion 重新生成该弦类型的卷积脉冲；
- F10 仍只在用户显式调整时写入总线，进入时不会自动改变原始音色。

## 结果

所有 F10 参数都有真实音频路径，并和原始弦界面共享同一条按类型效果总线，不再出现“只有混响一致、其他参数不一致”。

- F10 的 ADSR 作用于类型总线，不是逐音符独立包络；
- 世界谱/持续波形仍是音色真源。
