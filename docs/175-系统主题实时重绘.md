# 系统主题实时重绘（v1.50.0）

## 问题

v1.49 的「跟随系统」只更新：

```text
document.documentElement.dataset.gameTheme
```

如果游戏已经打开，画布不会自动重绘，需要退出重进。

## 修复

App 增加：

```ts
const [systemTheme, setSystemTheme] = useState(() => resolveGameTheme('auto'));
const gameTheme = preference === 'auto' ? systemTheme : preference;
```

`matchMedia('(prefers-color-scheme: light)')` 的 `change` 事件现在：

```ts
setSystemTheme(resolveGameTheme('auto'));
```

而不是只改 dataset。

于是：

```text
系统主题变化
  → App state 更新
  → Scene theme 更新
  → GameHost theme 更新
  → paint effect 重新绘制
```

无需退出游戏。

## 验收

新增 GUI：

```text
系统主题变化实时重绘画布
```

流程：

1. 设置 `auto`；
2. `emulateMedia({ colorScheme: 'light' })`；
3. 读取画布角落像素 `228`；
4. 切换为 dark；
5. 同一画布像素变为 `10`。
