# 拉弦响应与持续波形（v5.35）

## 1. 拉弦延迟

v5.34 之前键盘拉弦要等 `HOLD_MS = 180ms` 才出现 pin：

- 按得快时，pin 还没出现就松手；
- 视觉上像“没有拉弦”。

v5.35：

- 键盘拉弦延迟改为 **0ms**（`KEYBOARD_HOLD_MS = 0`）；
- keydown 立即建立 pin 并刷新按住状态；
- 尾判型松手仍会发声/判定；
- 鼠标长按 pin 仍保留原来的 180ms，避免单击误判成拉弦。

## 2. 持续型弦的形状

v5.34 的持续型弦只有静态 pin，视觉上“一片平静”。

v5.35 起，持续型弦按住时焦点弦显示为**持续音波形**：

- 视觉型（brightness > 0.7）→ 三角波；
- 动画/物理/空间 → 正弦波；
- 沿弦重复 3–6 个周期；
- 相位随时间推进，形成持续动画；
- 振幅来自按住点的位移；
- 端点用 `sin(πx)` 包络收束到基线。

也就是说：**听到的音色类型 = 看到的波形类型**。

## 3. 验收

- 单元 **371/371**；
- GUI **288/288**：
  - 持续型按下持续发声；
  - 持续型弦形状峰谷差 > 20px（实测约 255）；
  - 头判型按下即判定；
  - F2 切段后上下键控制新段；
- 生产冒烟 / perf 通过。

## 4. 边界

- 鼠标持续型的“按住持续发声”尚未完全接入；
- 波形是视觉近似，不采样真实 Faust/AudioWorklet 输出；
- 三角波只用于视觉型；其余持续型用正弦；
- 波形周期数由类别亮度固定，不随音高变化。
