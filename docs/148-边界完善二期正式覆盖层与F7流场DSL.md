# 边界完善二期：正式覆盖层与 F7 流场 DSL（v1.23.0）

## 1. 覆盖层进入真 DSL

`音频配置` 与 `流场` 现在是正式顶层声明：

```nro
音频配置 叙事
  混响 0.4
  低通 3200
  共振 3
  驱动 0.2
  LFO速率 0.15
  LFO深度 240

流场 叙事
  节点 14 10 6.4 0.45 0.55 0.62 3200 2.4 0.18 0.4 0.45 0.8 0.16 1.8 12 32000 0
```

完整链路：

```text
.nro → lexer/parser → AST → compiler → IR(audioConfigs/flowProfiles)
     → serializer → .nro
     → GUI 恢复 F10/F9 运行期状态
```

- 产品世界保存时自动生成这两段；
- 旧注释侧车兼容读取，但新格式不再依赖注释；
- GUI 进入世界时把 IR 覆盖层恢复为音频效果与 FlowNode。

## 2. F7 流场正式 DSL

流场界面按 F7：

- 直接显示 `流场 <kind>`  DSL 段；
- 编辑后走完整编译校验；
- 通过后写回 `.nro`，并同步 FlowNode 存储；
- 不再以 JSON 作为 F7 编辑格式；
- `.nrm` JSON 只保留为 F10 导入/导出侧车。
