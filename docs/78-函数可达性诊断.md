# 函数调用图与未使用诊断（v5.21）

> v5.20 有了共享函数表；v5.21 记录函数调用边，从世界级调用者出发做可达性分析。
> 没有被任何会执行的规则/动作/系统触达的函数，会给一条体验级 warning。

## 1. 调用图

```text
<world> ──规则/动作/系统──▶ 夹紧
夹紧     ──函数体──────────▶ 双倍
双倍     ──内建────────────▶ ...
```

- 编译器在 lowering 用户调用时记录 caller → callee；
- caller 是当前函数名，或 `<world>`（规则/动作/系统/结局/公理等）；
- 函数体只 lower 一次，因此调用边只记录一次；
- 从 `<world>` BFS 可达的函数视为“被使用”。

## 2. 诊断

```nro
函数 废弃
  参数 x
  返回 x + 1
```

如果世界里没有任何地方调用它：

```text
警告[体验/NRO3307] 函数「废弃」没有被任何规则/动作/系统调用。
  → 删掉它，或从一个会被执行的效果/条件里调用它。
```

- 只是 warning，不影响编译；
- 被其他可达函数调用的函数视为可达；
- 被不可达函数调用的函数仍会给 warning。

## 3. 验收

- 单元 **352/352**：新增
  - 未使用函数 warning；
  - 已使用函数不误报。
- 既有函数测试/世界不变；
- GUI 仍为 276。

## 4. 边界

- 只做静态可达性，不做调用次数/频率；
- 不能识别“只在某个不会触发的规则里调用”；
- 没有函数级类型标注/返回类型检查；
- 没有函数调用图 GUI。
