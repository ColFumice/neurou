# 音量与静音：F4 四档（v3.6）

> v3.5 让世界能发声，但声音没有总开关。v3.6 增加极简、无界面的音量控制：
> **F4 循环四档**，并记住上次选择。

## 1. F4

在任意界面按 `F4`：

```text
1.0 → 0.6 → 0.3 → 静音 → 1.0 …
```

- 无面板、无按钮、无提示条；
- 只改本地 AudioContext 的 master gain，不进入世界状态，不写回 `.nro`；
- 持续音、拨弦、世界 `音频` cue、F3 听音都受同一总音量影响；
- 静音时 `rms()` 趋近 0；取消静音后恢复。

## 2. 持久化

- `localStorage['neurou.audio.level']` 保存 `1 | 0.6 | 0.3 | 0`；
- 刷新后恢复；
- 隐私模式/无 localStorage 时退回 1.0。

## 3. 可观测属性

页面根节点：

| 属性 | 含义 |
|---|---|
| `data-audio-level` | 当前实际档位：1 / 0.6 / 0.3 / 0 |
| `data-audio-volume` | 非静音时的音量（静音时仍保存 1） |
| `data-audio-muted` | `true/false` |

## 5. 边界

- 只有四档，没有连续推子；
- 移动端没有 F4，暂不能切总音量（可在系统层静音）；
- F4 不进入可写回世界，也不影响确定性运行时；
- 没有按声音类别分轨音量（拨弦/世界 cue/矩阵听音共用 master）。
