# 章节路线图：F9 淡图（v4.6）

> v4.x 的章节关系只存在于源文件和导航行为里。v4.6 给它一个只读的极简视图：
> 按 F9 看整张章节路线，当前章节高亮。

## 1. 操作

八弦视图按 **F9**：

- 打开/关闭整张章节路线图；
- 每行：`章节标题 → 下一章 / 下一章`；
- 当前所在章节 alpha≈0.9，其余≈0.24；
- `Esc` 或再按 F9 关闭；
- 路线图打开时拦截键盘，避免误拨弦；
- 无面板、无按钮、无滚动条，纯文字，pointer-events:none。

## 2. 数据来源

`chapterGraph.ts` 在构建时从内联的世界源码里抽取：

- `世界` 名；
- `章节` 标题；
- 所有 `下一章`（包括世界级与结局级）；
- 所有 `上一章`；
- 过滤到实际存在的 `examples/*.nro`。

不重新编译、不依赖运行时状态；13 个世界全部进入图。

## 3. 可观测属性

| 属性 | 含义 |
|---|---|
| `data-chapter-graph-open` | 路线图是否打开 |
| `data-chapter-graph-nodes` | 节点数 |
| `[data-testid="chapter-graph"]` | 容器 |
| `.chapter-graph-node` | 单章行 |
| `.chapter-graph-node--current` | 当前章节 |

## 5. 边界

- 只读路线图，不能在图上点击跳章；
- 只显示章节标题与出边，不显示条件/结局名；
- 没有自动布局/连线，只有缩进文字；
- 章节变化后需刷新页面重建图；
- 桌面键盘专属，移动端暂不支持。
