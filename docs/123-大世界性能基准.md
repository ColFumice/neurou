# 大世界性能基准（v6.17）

## 1. 基准生成

`scripts/perf-bench.ts` 现在会生成并运行：

- 48 弦；
- 48 条耦合；
- 16 个动作；
- 6 个视觉端口（带后处理）；
- 6 个音频端口（带自动化）；
- 2 个资产。

运行：

```bash
pnpm build
pnpm preview
pnpm perf
```

## 2. 门禁

| 指标 | 阈值 |
|---|---|
| 大世界 tick 吞吐 | ≥ 200 tick/s |
| 大世界端口数 | ≥ 12 |
| 原有 GUI FPS / 堆 / 小世界吞吐 | 保持 |

本地基线（2026-10-30）：

```text
大世界 tick 吞吐: 61162（阈值 200）
大世界端口数: 12（阈值 12）
```

`artifacts/perf.json` 新增 `large` 字段。

- 大世界是合成基准，不是内容世界；
