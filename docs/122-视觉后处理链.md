# 视觉后处理链（v6.16）

## 1. DSL

视觉端口新增可选字段：

```nro
视觉端口 窗光
  参数 强度 色温
  贴图 雨纹
  后处理 暗角 0.4 颗粒 0.2 色偏 0.15
```

- 仅视觉端口允许；
- 三个字段都可省略，缺省值：暗角 0.55、颗粒 0.035、色偏 0；
- 值范围 0..1；
- 序列化保留。

## 2. 运行时 / 后端

- `IRPort.post` 进入 IR；
- `BackendPortFrame.post` 随端口帧投影；
- GLSL 第二 pass 新增 uniforms：
  - `uVignette`
  - `uGrain`
  - `uTint`
- 全局后处理档位仍作为倍率；
- canvas 暴露 `data-glsl-post="v,g,t"`；
- GUI 根节点 `data-glsl-post-ports`。

## 3. 内容

`examples/vertical-story.nro` 的「窗光」带后处理：

```text
后处理 暗角 0.4 颗粒 0.2 色偏 0.15
```
