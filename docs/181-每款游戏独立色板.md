# 每款游戏独立色板（v1.56.0）

## 目标

全局设置只决定深色/浅色；每款游戏在这个基础上拥有自己的强调色。

## 色板

新增：

```ts
GAME_ACCENTS = {
  tetris:  { dark: '#7fd1c9', light: '#0f766e' },
  snake:   { dark: '#8fce7f', light: '#2f7d3a' },
  pong:    { dark: '#e7c46a', light: '#b7791f' },
  breakout:{ dark: '#e8a86c', light: '#b45309' },
  reaction:{ dark: '#e79ac7', light: '#a21caf' },
}
```

解析：

```ts
accentFor(moduleId, themeName)
```

## 统一注入

GameHost：

```text
baseTheme = themeFor(dark | light)
accent = accentFor(module.id, theme)
themeTokens = { ...baseTheme, accent }
```

所以：

- 每个场景继续只读 theme token；
- 不需要为每款游戏复制整套主题；
- GameHost 根元素带：

```text
data-accent="#e7c46a"
```

## 各游戏强调色

- 俄罗斯方块：分数与高亮；
- 贪吃蛇：食物；
- 乒乓：球与中线；
- 打砖块：砖块与球；
- 外部反应插件：大分数。
