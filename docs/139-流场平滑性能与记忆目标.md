# 流场平滑、性能与记忆目标（v1.14.0）

## 1. 曲线不再尖锐

- 等值线连接后先做两轮 Chaikin 平滑；
- 再以二次贝塞尔绘制；
- LoFi 的视觉量化权重从硬量化改为 72% 平滑 + 28% 量化；
- sample-rate 视觉量化同样做混合，不再整块阶梯；
- 低 bits 仍保留 LoFi 特征，但曲线不再生硬。

## 2. F12 后按 F10：编辑记忆目标音色

- F12 进入时捕获 `memoryKind`（打开记忆模式时的弦类型）；
- F10 打开 FlowField 时传入该目标；
- FlowField 不再启动独立合成环境声，而是：
  - 节点触发直接调用当前弦类型的真实音色 `pluck`；
  - 节点 depth/cutoff 实时写入该弦类型的声场/滤波总线；
  - 修改的是 F12 捕获的元素，而不是一个独立流场世界；
- F10 退出后记忆模式保持，不自动退出。

## 3. 性能与缓动

- canvas DPR 上限降到 1.25；
- 等值线层级 9 → 7；
- 30fps 渲染节流；
- 移除每路径 shadowBlur，改为宽底描边发光；
- 音频参数更新每 3 帧一次；
- 节点拖动时不写 localStorage、不触发 React 状态，松手时一次 commit；
- 点击屏幕生成 900ms 缓出涟漪；
- 节点面板入场、参数选中、按钮 hover 都有过渡动画。

## 5. 边界

- LoFi 视觉量化是效果，不是完全关闭；
- F10 在记忆模式中读取 F12 进入时的弦类型；
- 流场节点音频首次交互后启动；
- 层级目前影响视觉权重，尚无 solo/mute。
