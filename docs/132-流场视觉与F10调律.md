# 可绘制声场流场（v1.7.0）

## 1. 这是什么

`examples/flow-field.nro` 现在进入独立的**全屏声场流场画布**：

- 64×36 可绘制标量场；
- 实时等值线（marching squares + 二次贝塞尔平滑）；
- 等值线随时间做涡旋漂移，线宽随时间呼吸；
- 不叠加弦画布、标签或预览蒙版；
- 鼠标拖拽直接改变流场布局；
- 字母键映射到声场位置：改变布局并发出对应音高。

截图：`artifacts/149-flow-woven.png`

## 2. 数据存储

```text
localStorage["neurou.flow:<worldFile>"]
{ "values": [ ... 64 * 36 个 0..1 数值 ] }
```

## 3. 操作

| 输入 | 行为 |
|---|---|
| 鼠标拖拽 | 平滑改变流场布局 |
| 方向键 | 移动笔刷光标 |
| Shift + 方向键 | 大步移动 |
| 空格 / Enter | 落笔 |
| 字母 / 数字键 | 按声场位置变形并发声 |
| S | 保存 |
| R | 重置 |
| F10 / Esc | 退出画布 |

没有擦除模式、没有圆形笔刷提示；所有输入都是改变流场布局。

## 5. 边界

- 声场数据在 localStorage，不自动写回 `.nro`；
- 等值线动画是显示层漂移，不改变控制场数据；
- 后续可把声场控制点提升为正式 IR 数据。
