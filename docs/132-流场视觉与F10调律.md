# 流场视觉与 F10 调律（v1.4.0）

## 1. 这类动态等值线放在哪里

它作为**视觉端口的程序化纹理模式**加入引擎：

```nro
视觉端口 等值线
  参数 速度 速度
  参数 色相 色相
  参数 细节 细节
  纹理 流场 6
  后处理 暗角 0.2 颗粒 0.15 色偏 0.2
```

存储的是：

- `.nro` 里的视觉端口声明；
- `纹理 流场 <尺度>`；
- 三根绑定弦的名字与当前值（`参数 <参数名> <弦名>`）。

不依赖外部贴图；GLSL 在浏览器里实时生成 FBM 等值线。

## 2. 键盘映射动态编辑

新增 **F10 流场调律**：

- `F10` 打开/关闭；
- ↑/↓ 选择流场参数；
- ←/→ 实时调整绑定弦的值；
- 打开时自动进入 Space 预览，调参立即改变画面；
- Esc / 点击外部关闭。

数据流：

```text
方向键 → universe.inject(绑定弦) → 端口 uniform
→ GLSL 等值线 → 预览画面
```

示例世界：

`examples/flow-field.nro`

初始界面「等值线流场」入口。

## 5. 边界

- F10 修改的是运行时弦值，不自动写回 `.nro`；
- 要持久化可把参数弦基线写进世界，或后续加调律 profile；
- 流场目前是视觉端口模式，不是独立新弦类型；
- 参数数量按绑定弦数生成 uniform。
