# 可绘制流场画布（v1.6.0）

## 1. 这是什么

`examples/flow-field.nro` 现在进入独立的**全屏流场画布**：

- 64×36 可绘制标量场；
- 浏览器实时用等值线（marching squares）渲染；
- 等值线随时间做轻微涡旋位移动画；
- 不叠加原来的弦画布、标签或预览蒙版；
- 鼠标拖拽直接绘制，键盘也可绘制。

截图：`artifacts/148-flow-mode.png`

## 2. 数据存储

流场控制场保存在本地：

```text
localStorage["neurou.flow:<worldFile>"]
```

值：

```json
{ "values": [0.5, 0.42, "..."] }   // 64 * 36 个 0..1 数值
```

它是一张可编辑的二维数据场；`.nro` 里的视觉端口「纹理 流场」仍描述视觉模式，但全屏画布使用这份可绘制控制场。

## 3. 操作

| 输入 | 行为 |
|---|---|
| 鼠标拖拽 | 绘制/加厚流场 |
| 方向键 | 移动笔刷光标 |
| Shift + 方向键 | 大步移动 |
| 空格 / Enter | 在当前光标落笔 |
| 1 / 2 / 3 | 笔刷半径 |
| X | 切换擦除 |
| S | 保存到 localStorage |
| R | 重置流场 |
| F10 / Esc | 退出画布 |

## 4. 集成方式

- `examples/flow-field.nro` 自动进入流场画布；
- 其他世界按 `F10` 进入；
- 退出后恢复正常调律台；
- 画布期间弦图层被隐藏/卸载，不接收键盘或指针事件。

## 6. 边界

- 当前是本地二维控制场，不是新的 DSL 弦类型；
- 字段数据存在 localStorage，不自动写回 `.nro`；
- 等值线动画是显示层涡旋，不改变控制场数据。
