# 游戏主题切换（v1.47.0）

## 设置项

设置页新增：

```text
语言 / Language · 游戏主题
中文
English
深色
浅色
```

保存：

```text
neurou.game.theme = dark | light
```

并同步到：

```text
document.documentElement.dataset.gameTheme
```

## 实现

- 游戏画布在浅色主题下使用：

```css
html[data-game-theme="light"] .tetris-scene__canvas {
  filter: invert(1) hue-rotate(180deg) saturate(.78) contrast(.96);
}
```

- 覆盖层、暂停菜单、帮助层、首次教学、游戏选择层切换为浅色 DOM 样式；
- 深色主题恢复原样；
- 设置在刷新后保留。

## 验收

新增 GUI：

```text
切换浅色游戏主题
切换回深色游戏主题
```

检查：

- `html[data-game-theme="light"]`；
- `localStorage['neurou.game.theme']`；

- 浅色主题通过画布反相实现，不是逐色板重绘；
- 只覆盖游戏层，不影响世界/编辑器主界面；
- 没有跟随系统主题；
- 没有每款游戏独立主题。
