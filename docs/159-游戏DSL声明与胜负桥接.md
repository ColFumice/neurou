# 游戏 DSL 声明与胜负桥接（v1.34.0）

## 目标

把 v1.33 的隐式绑定：

```text
F6 → 当前焦点弦
```

升级为世界作者可声明的显式契约。

## 新 DSL 声明

```text
游戏 方块校准
  模块 俄罗斯方块
  结果弦 信任
  胜利分数 40
  胜利动作 安抚
  描述 "调律台按 F6 进入，得分写回信任弦"
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 游戏名 | 是 | 世界内唯一 |
| 模块 | 否 | 默认「俄罗斯方块」 |
| 结果弦 | 是 | 游戏分数写回的弦名 |
| 胜利分数 | 否 | 默认 100 |
| 胜利动作 | 否 | 达标后触发已有动作 |
| 描述 | 否 | HUD/作者说明 |

## 编译链

已接入：

```text
parser → AST → compiler 校验 → IR.games
       → serializer 写回
```

校验：

- 结果弦不存在 → 诊断；
- 胜利动作不存在 → 诊断；
- 游戏名重复 → 诊断；
- 结果弦编译期解析为 `resultStringId`。

## 世界内行为

- F6 优先读取 `worldIR.games[0]`；
- 结果写入声明的「结果弦」；
- 分数达到「胜利分数」时：
  - 调用已有动作；
  - 结果提示追加动作名；
- 无游戏声明时，回退到当前焦点弦（旧行为）。

## 验收

核心单元新增：

```text
解析/编译游戏声明并解析结果弦 id
序列化往返保留游戏声明
不存在的结果弦/动作给出诊断
```

GUI 保持：

```text
F6 从世界启动绑定游戏
游戏结果写回世界弦
游戏结果提示带弦名
```

## 当前边界

- 世界里的游戏声明目前只绑定一个游戏；
- 胜利动作只触发一次 dispatch；
- 游戏结果还没有直接触发结局；
- 游戏模块只有俄罗斯方块；
- Game SDK 尚未抽取。
