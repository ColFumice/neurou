# 函数局部变量与条件表达式（v5.23）

> v5.22 的函数仍是单个返回表达式。v5.23 允许 `局部` 变量和
> `如果 … 那么 … 否则 …` 条件表达式，同时仍保持纯函数与确定性。

## 1. 语法

```nro
函数 夹紧
  参数 x: 数值, lo: 数值, hi: 数值
  返回类型 数值
  局部 下限 = lo
  局部 上限 = hi
  返回 如果 x < 下限 那么 下限 否则 如果 x > 上限 那么 上限 否则 x
```

规则：

- `局部 名字 = 表达式` 可多行，按顺序生效；
- 局部变量可引用参数和此前的局部变量；
- `返回` 仍只有一个表达式；
- 条件表达式为 `如果 条件 那么 A 否则 B`；
- 条件必须是真假判断，两分支类型需一致（或任一侧为任意）。

## 2. 编译期展开

```text
局部 下限 = lo
局部 上限 = hi
返回 如果 x < 下限 …
  → 按顺序把局部引用替换为表达式
  → 条件表达式下降为 选择(cond, then, else)
  → 正常 lower / 类型检查
```

- 局部变量不进入运行时状态；
- 条件表达式复用运行时的 `选择` 内建；
- `IRFunction.locals` 保存局部源码，供序列化；
- 函数体原文 `bodySource` 仍是返回表达式。

## 3. 序列化

```nro
函数 夹紧
  参数 x: 数值, lo: 数值, hi: 数值
  返回类型 数值
  局部 下限 = lo
  局部 上限 = hi
  返回 如果 x < 下限 那么 下限 否则 如果 x > 上限 那么 上限 否则 x
```

- `局部` 行与条件表达式都会保留；
- roundtrip 编译与运行时行为不变。

## 4. 验收

- 单元 **355/355**：新增
  - 局部变量 + 条件表达式编译；
  - 序列化保留 `局部` / `如果`；
  - roundtrip 运行结果。
- 既有函数/世界行为不变；
- GUI 仍为 276。

## 5. 边界

- 没有 `否则 如果` 链之外的语句块/循环/提前 return；
- 局部变量只在函数内，不是世界状态；
- 条件表达式是表达式，不是控制流语句；
- 仍无泛型/默认参数；
- 局部变量展开可能重复表达式（纯函数下语义一致）。
