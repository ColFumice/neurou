# F10 固定波形与效果增强（v1.18.0）

## 1. F10 内固定波形

- 进入 F10 时按目标弦类型抓取一份固定波形快照：
  - `fixedWavesRef`；
  - 切换目标时重新抓取；
- F10 内按键试听、调效果、触发节点，都不会再改变该波形；
- 固定波形仍然沿用弦界面原来的音色，不会被流场重新生成。

## 2. 效果改变比例增强

过去 F10 只把节点的 `depth` / `cutoff` 映射到目标弦类型，变化太弱。

现在效果总线新增：

```ts
KindEffects {
  reverb
  cutoff
  resonance
  drive
  lfoRate
  lfoDepth
}
```

并新增音频链：

```text
kind input → lowpass filter → waveshaper → dry/wet convolver → master
                ↑
          LFO oscillator
```

F10 节点映射：

| 节点字段 | 目标效果 |
|---|---|
| depth | 混响发送（wet 提升到 1.05，dry 降 0.65） |
| cutoff | 低通截止 |
| resonance | 滤波共振 Q |
| bits | 驱动/失真强度（4bit→最强） |
| sampleRate | 驱动辅助比例 |
| lfoRate | 滤波 LFO 速率 |
| lfoDepth | 滤波 LFO 深度（Hz） |

因此调整 F10 节点时，音色变化会明显更强。

## 3. F9 效果器同步扩展

F9 面板现在也可调：

```text
混响 / 低通 / 共振 / 驱动 / LFO 速率 / LFO 深度
```

↑/↓ 选参数，←/→ 调整。
