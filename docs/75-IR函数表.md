# IR 函数表与函数持久化（v5.18）

> v5.17 的函数在运行时已经内联，但序列化会把函数声明丢掉。
> v5.18 把函数作者结构放进 IR：运行时仍内联，工具/格式化能保留函数。

## 1. IR

```ts
interface IRFunction {
  id: string;        // function:夹紧
  name: string;      // 夹紧
  params: string[];  // [x, lo, hi]
  bodySource: string; // 最大(lo, 最小(x, hi))
}
```

- `WorldIR.functions` 保存作者结构；
- 编译器从源码 span 截取函数体原文；
- 运行时仍使用 v5.17 的编译期内联，不读 IR 函数表；
- `patch` 结构签名包含函数，编辑函数会触发重编译。

## 2. 序列化

```nro
世界 函数测试
  版本 0.1

函数 夹紧
  参数 x, lo, hi
  返回 最大(lo, 最小(x, hi))
...
```

- 函数块在弦/规则之前输出；
- 参数与返回原文保留；
- 调用点仍以 v5.17 内联后的表达式写出（不重建函数调用）；
- 重新编译后语义不变。

## 3. 验收

- 单元 **351/351**：函数测试新增
  - IR `functions` 内容；
  - 序列化包含 `函数/参数/返回`；
  - roundtrip。
- 既有世界不含函数时不变；
- GUI 仍为 276。

## 4. 边界

- IR 函数表是作者结构元数据，不是运行时函数对象；
- 序列化保留函数声明，但调用点已内联，不会恢复成 `夹紧(...)`；
- 没有函数类型/依赖图/未使用函数诊断；
- 命名空间函数的函数体引用仍需作者显式限定；
- 函数体原文来自源码切片，注释/换行可能被压平。
