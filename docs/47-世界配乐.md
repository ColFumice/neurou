# 世界配乐：BGM 循环（v3.8）

> v3.7 的音频资产由信号 cue 触发；v3.8 让世界可以声明一段**循环配乐**，
> 页面首次手势后自动开始，F4 音量/静音统一控制。

## 1. DSL

```nro
音频资产 雨幕 "audio/rain.wav"

配乐 雨幕 音量 0.25 循环 是
```

- 顶层单行声明：`配乐 <资产名> [音量 0..1] [循环 是|否]`；
- 资产名必须来自 `音频资产`；
- 默认 `音量 0.35`、`循环 是`；
- 世界只能有一段配乐，重复报 NRO2004。

## 2. 播放

```text
App 读取 worldIR.bgm
  → 找 audioAssets 里的 src
  → StringAudio.playLoop('/audio/rain.wav', volume, loop)
      context 未建：pending，首次手势后自动开始
      同 src：不叠层，只更新 gain/loop
      不同 src：30ms 淡出旧循环
  → 经 master（受 F4）
```

- 循环播放不阻塞拨弦、世界 cue、矩阵听音；
- `stopLoop(50ms)` 线性淡出；
- 切世界/卸载页面时停止；
- F4 静音时循环仍在调度但 RMS 归零。

## 3. 可观测属性

| 属性 | 含义 |
|---|---|
| `data-bgm` | 配乐资产名 |
| `data-bgm-src` | 解析后的路径 |
| `data-bgm-volume` | 0..1 |
| `data-bgm-loop` | true/false |

## 4. 示例

`examples/soundscape.nro` 现在：

- `音频资产 雨幕 "audio/rain.wav"`；
- `配乐 雨幕 音量 0.25 循环 是`；
- 钟鸣仍用 `clock.wav` 资产；
- 余音仍用 `铜钟` 谱合成。

## 6. 边界

- 一个世界只有一段 BGM，没有播放列表/场景切换；
- 配乐不进入确定性回放，不影响世界值；
- 没有独立于 master 的音乐音量总线；
- 首次手势前不发声（浏览器策略）；
- 生产包只读，不能上传/替换资产。
