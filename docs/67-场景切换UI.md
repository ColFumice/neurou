# 场景切换 UI 与 Engine 场景列表（v5.10）

> v5.3 让世界能自己切换场景；v5.10 让 Host 能列出并手动切换场景，
> 预览蒙版里的场景名随 `Engine.transitionScene` 立即更新。

## 1. Engine API

```ts
engine.scenes();          // [{ id, name }, ...]
engine.currentSceneId;    // 'scene:夜'
engine.sceneName;         // '夜'
engine.transitionScene('昼');
```

- 场景来自 `IR.scenes`；
- 切换执行旧场景离开、新场景进入；
- 没有场景的世界返回空列表。

## 2. GUI：F8 场景列表

八弦视图按 **F8**：

- 世界有场景时打开极淡场景列表；
- `↑/↓` 选择，`Enter` 切换，`Esc`/再按 F8 关闭；
- 切换后顶部预览场景名立即变化；
- 列表打开时拦截其它键盘，避免误拨弦；
- 无面板、无按钮，`pointer-events:none`。

可观测：

| 属性 | 含义 |
|---|---|
| `data-scene-count` | 场景数 |
| `data-scene-menu-open` | 列表是否打开 |
| `data-scene-menu-selected` | 选中项 |
| `data-preview-scene` | 当前场景 |
| `[data-testid="scene-menu"]` | 列表容器 |

## 4. 边界

- 没有场景进入/离开的 GUI 动画；
- 没有场景缩略图/预览/条件解锁；
- 场景切换只改当前场景，不改变章节/存档；
- 多场景世界仍需手写 `场景` 声明；
- 移动端没有 F8 入口。
