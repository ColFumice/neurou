# 交互细节第二轮（v1.2.0）

## 1. 弹窗背景反色

弹窗打开时，底层世界画面进入：

```css
filter: invert(1) hue-rotate(180deg);
```

叠加暗化背景，形成明显的“负片”过渡。

## 2. 波形曲线白色

F6 波形编辑器：

- 网格改为白色低透明；
- 波形主线改为 `rgba(255,255,255,0.94)`；
- 在黑色圆角窗口中对比清晰。

## 3. 初始界面

- 左栏扩展为 52%，不再用硬边分割；
- 中间用渐变 + `backdrop-filter: blur(16px)` 做模糊过渡；
- 菜单字号 21px，当前项 28px / 700 字重 / 纯黑；
- 去掉灰色 hover 背景，只保留文字放大加黑加粗；
- 右半屏弦画布保留可弹奏。

截图：

- `artifacts/132-start-screen-v2.png`

## 4. 弹窗方向键直接选中

Modal 导航行为：

- ↑/↓ 聚焦下一项；
- 若该项是 `data-modal-item` 且不是危险动作，立即 click；
- 回车只在打开弹窗/进入新界面时使用；
- 删除、关闭、应用、跳章等动作加 `data-modal-no-arrow`，避免误触。

## 5. 持续型弦全屏键盘映射

- `layoutKeyboard(..., fillRows=true)`：每行按键横向铺满全屏；
- 持续型弦按键使用该布局，采样覆盖 0..1 全宽；
- 波形采样从 32 段提升到 **48 段**；
- 静态持续弦增加轻微游走和呼吸式线宽变化。

## 6. 非持续弦基线缓冲

新增 `updateBaselineDisplay`：

- 非持续型弦的基线向目标值指数缓动；
- 超限/取值突变时不再瞬间跳变；
- 持续型弦基线保持稳定（避免波形抖动）。
