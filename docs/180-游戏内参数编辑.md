# 游戏内参数编辑（v1.55.0）

## 入口

暂停菜单新增：

```text
继续 / 换游戏 / 参数 / 帮助 / 回世界
```

点击「参数」打开游戏参数面板。

## 可编辑

```text
难度 1..5
波次 1..10
```

- 滑杆修改；
- 「应用并重开」立即以新参数开始新一局；
- 「取消」保持原参数；
- 面板打开时游戏输入被抑制，键盘事件交给滑杆；
- Esc 关闭参数面板（不退出游戏）。

## 运行时

```ts
GameHost params = { difficulty, waves }
GameSession.start(seed, params)
GameModule.create(seed, params)
```

- 难度：俄罗斯方块重力 / 贪吃蛇速度 / 乒乓 AI / 打砖块球速；
- 波次：打砖块 maxWaves；
- 调试 API：

```ts
window.__neurouTetris.params()
// { difficulty: 5, waves: 5 }
```

## 当前边界

- 参数只在当前会话生效，不写回世界 DSL；
- 没有保存为每款游戏的偏好；
- 外部插件也收到 params，但没有专门的编辑项；
- 没有参数预设/重置按钮。
