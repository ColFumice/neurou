# 分支作用域与否则块（v5.25）

> v5.24 的分支只能单返回。v5.25 允许分支内写 `局部`，并支持显式 `否则` 块。

## 1. 语法

```nro
函数 分类
  参数 x: 数值
  返回类型 文本
  当 x < 5
    局部 词 = "小"
    返回 词
  否则
    局部 词 = "大"
    返回 词
```

规则：

- `当` 分支块内可写 `局部`，只在当前分支可见；
- `局部` 按顺序展开，可引用函数参数/函数级局部/此前的分支局部；
- `否则` 块可写 `局部` 与 `返回`；
- 有 `否则` 时不再需要末尾无条件 `返回`；
- 没有 `否则` 时仍必须有末尾 `返回`；
- 所有分支/兜底类型需一致。

## 2. 编译期展开

```text
当 x < 5
  局部 词 = "小"
  返回 词
否则
  局部 词 = "大"
  返回 词

↓

选择(x < 5, "小", "大")
```

- 分支局部按作用域分别替换；
- 分支条件只看到函数级局部，不看到分支局部；
- 展开后仍是惰性 `选择`；
- `IRFunction.branches[].locals` 与 `IRFunction.otherwise` 保存作者结构。

## 3. 序列化

分支局部与 `否则` 都会恢复；roundtrip 后行为不变。

## 4. 验收

- 单元 **357/357**：新增
  - 分支局部变量；
  - `否则` 块；
  - 序列化保留 `否则` / `局部`；
  - roundtrip 运行结果。
- 既有函数/世界行为不变；
- GUI 仍为 276。

## 5. 边界

- 没有循环/多语句分支体；
- 分支局部不与函数级局部做重名诊断；
- 分支条件看不到分支局部；
- 仍然是纯函数，无副作用/提前退出以外控制流；
- 分支/兜底返回类型需统一。
