# 界面交互系统与初始界面（v1.1.0）

## 1. 初始界面

无 `?world=` 时启动进入界面：

- 左半屏白底黑字纵向文本菜单；
- 按钮无边框，完全文本化；
- ↑/↓ 选择，Enter 进入，Esc 进入默认世界；
- 鼠标 hover/点击；
- 右半屏保留弦画布，可直接弹奏/观察；
- 菜单示例：调律台、潮汐之间、垂直切片、谱之境、纹理雨、音频端口、章节路线、手势帮助。

带 `?world=` 的直接链接仍直接进世界（测试/分享用）。

## 2. 统一弹窗

F6 波形/资源、F7 规则、? 手势、F9 章节路线：

- 周围暗化；
- 黑色圆角窗口；
- 点击外部关闭；
- Esc 关闭；
- 方向键在弹窗控件间移动，Enter 触发；
- 输入框/文本域中方向键保留原生行为。

场景列表 F8、存档槽 Backquote 也增加暗化 scrim、黑色圆角与外部点击关闭。
章节选择保留键盘 ↑/↓+Enter。

## 3. F9 修复

此前 F9 打开的是一个未明显的路线图 DOM，默认世界下看起来没反应。
现在：

- 打开黑色圆角「章节路线」模态；
- 路线节点可选（方向键 + Enter）；
- 空数据有提示；
- 点击外部 / Esc 关闭。

## 4. 开发/生产流程中修复的问题

- 初始界面加入后，旧 GUI 测试默认 URL 被菜单拦截 → 测试改为直接 `?world=...`；
- 生产冒烟同样改为直接世界链接，并单独验证初始界面；
- 子编辑器 `stopPropagation` 吞掉方向键/Enter → 移除，改为统一 Modal 导航；
- F9 无反馈 → 模态 + 标题 + 空状态；
- F6/F7 无外部点击关闭 → Modal backdrop；
- 场景/存档菜单无暗化 → scrim；
- 新增 F6 方向键+回车选择测试。

## 6. 边界

- 弹窗内复杂表单仍以鼠标/输入原生交互为主；
- 章节选择是内容决策，不作为可随意关闭的弹窗；
- 初始界面右侧复用八弦画布，不单独建第二套演奏器。
