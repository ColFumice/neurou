# F10 试音毛躁修复（v1.31.0）

## 根因

### 1. 按住键会重复触发拨弦

FlowField 的键盘处理没有忽略 `event.repeat`：

- 按住一个试音键时，浏览器按系统重复率持续发送 keydown；
- 每一次 keydown 都执行 `audio.pluck`；
- 于是同一个音在几十毫秒内被反复触发，听感就是密集毛躁/颗粒。

原始弦界面在 keydown 开头就有 `if (event.repeat) return`，所以没有这个问题。

### 2. 默认总线仍有一次 ADSR 包络重触发

即使默认 ADSR 接近中性，每次拨弦仍会 `cancelScheduledValues` 并重新从 0.0001 起音；
多个音快速触发时会产生明显包络毛刺。

## 修复

- FlowField 键盘处理开头加入：

```ts
if (event.repeat) return;
```

- 每个试音键增加 90ms 防抖，避免重复 keydown/异常键盘事件连续触发；
- 默认中性 ADSR 直接旁路：

```text
attack 0.005 / decay 0.01 / sustain 1 / release 0.1
```

时不再重排 bus gain，只保持 1；
- 主动调 ADSR 后才启用包络；
- 默认 sampleRate 44100、drive 0、bits 16 继续保持透明。

## 结果

- F10 按住键试音不再密集重复触发；
- 默认音质无毛躁；
- 原始弦界面与 F10 继续共用同一音色/效果总线。
