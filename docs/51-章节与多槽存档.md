# 章节前后切换与多槽存档（v4.1）

> v4.0 只能 N 前进、只有一个自动存档。v4.1 补上“回去”和“多个平行局”。

## 1. 上一章

```nro
世界 夜航
  章节 "夜航"
  上一章 "examples/garden.nro"
```

- 结局后按 `B`：保存当前局 → 回到上一章；
- 根节点 `data-prev-chapter`；
- 与 `下一章`/`N` 对称；
- garden ↔ harbor 已形成前后章链。

## 2. 多槽存档

URL 增加 `slot`：

```text
?world=examples%2Fgarden.nro&slot=2&fresh=1
?world=examples%2Fgarden.nro&slot=2&resume=1
```

- `slot` 取 0..9，默认 0；
- 存档键包含槽位：`neurou.run.<world>:<seed>:slot<N>`；
- 每个槽独立自动存档（每 4s/pagehide）；
- `fresh=1` 只清当前槽；`resume=1` 只恢复当前槽；
- 根节点 `data-slot`；
- 章节 N/B 导航会保留当前 slot。

## 3. 可观测属性

| 属性 | 含义 |
|---|---|
| `data-prev-chapter` | 上一章路径，或空 |
| `data-next-chapter` | 下一章路径，或空 |
| `data-slot` | 当前存档槽 0..9 |
| `data-resumed` | 本次是否恢复槽位存档 |
| `data-save-tick` | 最近存档 tick |

## 5. 边界

- 仅前后章，没有章节图/分支树；
- N/B 只在结局后生效，且桌面键盘专属；
- 槽位只在本机 localStorage，没有云端/多设备；
- 槽位不跨版本迁移；
- `slot` 不影响世界自身的 seed 与确定性。
