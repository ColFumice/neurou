# 公开游戏插件清单（v1.52.0）

## 目标

把内置游戏模块的元数据导出为稳定的公开 JSON，供外部工具、文档、编辑器读取与校验。

## 文件

```text
packages/gui/public/games/manifest.json
```

结构：

```json
{
  "schema": "neurou.games/1",
  "version": "1.52.0",
  "games": [
    {
      "id": "tetris",
      "moduleName": "俄罗斯方块",
      "title": { "zh": "俄罗斯方块", "en": "Tetris" },
      "description": { "zh": "...", "en": "..." },
      "controls": { "zh": "...", "en": "..." }
    }
  ]
}
```

当前四款：

```text
俄罗斯方块 / 贪吃蛇 / 乒乓 / 打砖块
```

## 生成与校验

```bash
pnpm manifest:games   # 重新生成
pnpm check:games      # 只校验是否与注册表一致
```

生成器：

```text
scripts/game-manifest.ts
```

## 校验规则

- schema 必须是 `neurou.games/1`；
- version 非空；
- games 非空；
- id / moduleName 唯一；
- title / description / controls 都包含 zh、en；
- 公开文件必须与注册表逐字段一致。

新增单元：

```text
从注册表生成四款游戏
校验生成的清单
拒绝错误 schema / 重复模块 / 缺字段
公开文件与注册表同步
```

## 边界

- 清单是**元数据**，不是可执行插件；
- 运行时 GameModule 仍来自内置注册表；
- 还没有从外部 URL 加载 JS 游戏模块；
- GamePicker 仍使用内置注册表。

这是外部插件系统的第一步：先稳定清单格式与校验，再考虑加载。
