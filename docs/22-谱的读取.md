# 谱的读取：`查谱()` 进入规则与表达式（v2.1a）

> v2.0 让谱能被编辑、能变成音色；v2.1a 让谱进入世界的**规则层**：
> 任何表达式都可以用 `查谱("谱名", 位置)` 读取谱当前的值。位置 0..1，按谱的插值/循环采样。

## 1. 语法

```nro
谱 情绪地形
  段 0.1 0.4 0.8 0.5
  插值 平滑

结局 平静: 当 查谱("情绪地形", 0.5) > 0.6

力迫 回声
  当 查谱("情绪地形", 1) >= 0.5
  效果
    情绪 += 3
```

- 第一个参数必须是**字符串字面量**的谱名；
- 第二个参数是数字表达式（0..1 归一化位置，超出按 clamp/loop 处理）；
- 可出现在所有表达式位置：`当`、效果值、公理、信号、结局、力迫/和弦/动作；
- 编译期校验（NRO2003/NRO2101）：参数个数、名字字面量、位置类型、谱存在；
- 运行期：读**当前 values**（包含 v1.8 的段寻址调制）；谱状态缺失/位置非有限时返回 0。

## 2. 采样语义（与 `Universe.getSpectrumAt` 完全一致）

- 段点位于 `i/(n-1)`；`线性` 直接插值，`平滑` 用余弦缓入缓出；
- 非循环：位置 clamp 到 [0,1]；循环：按 1 取模回绕（1→0，-0.5→0.5）；
- 段值来自运行时当前状态，不受 `min/max` 影响形状（只影响数据含义）；
- 快照/分叉携带谱的插值/循环元数据；旧快照缺失时回退 0..1/线性/非循环，`restore` 从 IR 重建。

## 3. 用在哪些地方

- **结局/公理**：用曲线判断世界状态（如“情绪地形”的某个位置超过阈值）；
- **力迫/和弦/动作**：条件或效果数值可以读谱；
- **信号**：曲线驱动的提示；
- **未来**：音准仪/批量模拟的**参考谱**（把期望曲线与模拟曲线比较）与关系矩阵。

## 4. 验收

- `pnpm test` **182/182**：
  - core 9 项：lowering、规则/效果、参数校验、谱缺失建议、read-tracking、序列化 round-trip；
  - runtime 12 项：线性/平滑/循环/clamp 网格与 `getSpectrumAt` 逐点一致；调制后可见；受迫衰减；缺失/非有限/空谱返回 0；确定性；快照/restore/branch 元数据；旧快照回退。
- `pnpm check` / `check:gui` / `build` / `pnpm sim examples/spectra.nro --ticks 3` 通过。
- 语义注意：调制在 tick 末应用、规则/结局在应用前判定，因此 `modulate → tick` 当拍仍读旧值，下一拍读到新值（测试固定了这个顺序）。

## 5. 边界与下一阶段

- 只支持按归一化位置采样；还不能按“段索引”读或写整条谱；
- 表达式里不能创建/修改谱；调制仍是运行时 API（GUI/未来耦合寻址继续做）；
- 规则读取谱是只读；
- 参考谱与关系矩阵只是本阶段打下的基础，尚未实现。

下一阶段（v2.1b/c）：
1. **参考谱**：音准仪/批量模拟把一条谱作为目标曲线，输出偏差/健康维度；
2. **关系矩阵**：用谱表达“所有配对 × 时间”的关系数据；
3. 谱进入耦合段地址（真正的“其他波影响谱”语言化）。
