# F10 多目标编辑与键盘延用弦映射（v1.17.0）

## 1. F10 可编辑每个弦类型

流场新增音色目标切换：

- 面板顶部列出 8 类弦；
- 点击任意类型立即切换目标；
- 每个类型拥有独立节点档案：
  - `neurou.flow.nodes:<world>:<kind>`；
- 切换目标时：
  - 保存当前类型节点；
  - 加载新类型节点；
  - 更新该类型效果总线；
  - 选中节点回到第一个；
- 键盘 `Ctrl+←/→` 也可循环切换目标。

这样不再是“只能编辑 F10 打开时的那一个元素”。

## 2. 键盘延用弦界面映射

F10 内的键盘不再用于触发 FlowNode，而是沿用弦界面的键位布局：

- 使用 `layoutKeyboard` 的同一套键位坐标；
- 按下字母/数字键 → 按该键在弦界面的位置触发当前目标弦类型；
- 持续型目标使用 `startSustainedSpectrum`；
- 松开停止；
- 可以直接实时听 depth/cutoff/ADSR/LoFi 的变化。

## 3. 命令键迁移

为避免与弦界面键位冲突：

| 旧键 | 新键 |
|---|---|
| S 保存 | Ctrl+S |
| R 重置 | Ctrl+R |
| C 复制 | Ctrl+C |
| E 导出 | Ctrl+E |
| I 导入 | Ctrl+I |
| M 静音 | Ctrl+M |

仍然可用：

- Tab：切换节点；
- `[` / `]`：切换参数；
- `-` / `=`：调整参数；
- Delete：删除节点；
- PageUp/PageDown：层级；
- Enter：新节点；
- Ctrl+←/→：切换音色目标。
