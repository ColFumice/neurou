# F10 效果直控与演奏冻结（v1.26.0）

## 1. F10 参数现在可直接点击调整

之前 F10 节点参数只能用键盘 `[ ]` / `- =`，且连续按键在部分浏览器会丢事件。

现在每一行参数：

```text
声场半径     6.4    − +
滤波截止   3200Hz   − +
滤波共振     2.4    − +
```

- 点击行：选中该参数；
- 点击 `−` / `+`：按步长调整；
- 调整立即调用 `setKindEffects`，写入目标弦类型效果总线；
- 无需键盘记忆。

## 2. F10 进入即应用当前节点效果

- FlowField 挂载时立即把当前选中节点效果应用到目标弦类型：
  - 混响；
  - 低通；
  - 共振；
  - 驱动；
  - LFO；
- 不再需要先改一个参数才生效。

## 3. 可观测验收

新增 GUI：

```text
F10 参数直接改变弦效果总线 — 3200→3499.856
```

直接读取 `StringAudioEngine.kindBuses` 验证目标弦类型的 `filter.frequency` 确实变化。

## 4. 持续型 Space 演奏

- Space 在持续型弦界面不再切换预览层；
- 按住 Space 时键盘映射只演奏，不修改波形；
- 松开恢复编辑；
- 忽略 key repeat，避免闪烁。

## 5. 效果器关联

- F9 在调律台弦界面可直接打开；
- 效果器标题显示「类型 · 弦名」，例如：

```text
声场效果器 · 叙事 · 信任
```

- F10 目标按钮与 HUD 同样显示弦名。
