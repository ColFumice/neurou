# 边界完善：正式覆盖层 DSL 与世界工程操作（v1.22.0）

## 1. 覆盖层进入正式 DSL

新增两个顶层声明：

```nro
音频配置 叙事
  混响 0.4
  低通 3200
  共振 3
  驱动 0.2
  LFO速率 0.15
  LFO深度 240

流场 叙事
  节点 14 10 6.4 0.45 0.55 0.62 3200 2.4 0.18 0.4 0.45 0.8 0.16 1.8 12 32000 0
```

- 编译器解析为 `WorldIR.audioConfigs` / `WorldIR.flowProfiles`；
- 规范序列化会重新输出这两段；
- GUI 进入世界时自动恢复音频效果与 F10 节点；
- 保存产品世界时自动生成这两段，不再依赖注释侧车；
- 旧注释侧车仍可读取，但新保存使用正式段。

## 2. F7 流场 .nrm

- 流场界面 F7 打开当前目标类型的 `.nrm` JSON；
- 应用后写回本机 FlowNode 存储，并随保存进入 `.nro` 的 `流场` 段；
- 仍保留 JSON 作为侧车编辑格式，DSL 段作为正式持久化。

## 3. 世界工程操作

世界栏本机世界：

```text
↓ 导出 .nro
✎ 重命名
× 删除
```

世界栏底部：

```text
＋ 添加世界（模板向导）
导入 .nro
```

- 导入会先编译校验；
- 导出生成本地 `.nro` 文件；
- 重命名同步改 `世界` 行；
- 删除当前世界会回到默认测试世界。

## 4. 模板向导

仍为三步：

```text
命名 → 模板（空白 / 测试世界 / 十分钟小游戏）→ 确认
```
