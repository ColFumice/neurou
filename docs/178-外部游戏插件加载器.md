# 外部游戏插件加载器（v1.53.0）

## 目标

让世界可以加载受限的外部游戏插件，而不把宿主内部暴露给插件。

## DSL

```text
游戏 外部反应
  模块 外部
  脚本 "plugins/reaction.js"
  结果弦 重力
  胜利分数 30
  描述 "外部插件示例：5 次敲击"
```

编译规则：

- `模块 外部` 必须提供 `脚本`；
- 脚本只允许 `plugins/下一层/名字.js`；
- 其它模块不允许 `脚本`。

## 受限 API

插件默认导出：

```ts
{
  id, moduleName, title, description, controls,
  create(seed, params),
  step(state, command, fixedMs),
  score, lines, level, isOver,
  serialize?, deserialize?,
  draw(ctx, state, viewport, phase, best, theme),
  commandFor(code, repeat),
}
```

校验：

- id kebab-case；
- title / description / controls 中英；
- 方法必须存在；
- 只暴露 GameModule + 绘制 + 键位映射；
- 不传世界、引擎、存档内部对象。

## 加载

```ts
loadExternalPlugin('plugins/reaction.js')
```

约束：

- 同源；
- 路径必须在 `plugins/` 下；
- 只允许 `.js`；
- 动态 import + 缓存；
- 校验失败显示插件错误层。

场景：

```text
ExternalScene
  → GameHost
  → 插件 draw / commandFor
```

## 示例插件

```text
packages/gui/public/plugins/reaction.js
```

规则：5 次 Space 敲击结束，得分写回世界弦。

## 当前边界

- 插件仍在页面主线程执行，不是 iframe/Worker 隔离；
- 只限制入口路径与 API 形状，不能阻止恶意 JS 访问 window；
- 插件不能声明自己的世界弦/信号，只能通过结果弦写回；
- 没有插件清单版本/签名校验。
