# 游戏会话存档、暂停菜单与世界信号（v1.39.0）

## 1. 游戏会话进入世界存档

### Game SDK

新增：

```ts
GameModule.serialize / deserialize
GameSession.save() / restore()
```

- `GameSave { moduleId, tick, state }`
- 模块不匹配或状态损坏返回 false；
- Tetris 用 `TetrisEngine.snapshot/load`；
- Snake 序列化状态并校验身体/食物/方向。

### 世界存档键

```text
neurou.game.snapshot:<worldFile>:<弦类型>:<模块>
```

- 退出游戏时保存；
- 再次 F6 进入时自动恢复，暂停在上一局；
- 游戏结束清空存档；
- 换游戏前保存当前局。

### 验收

```text
再次进入恢复上一局
恢复的方块位置一致 — 2→2
```

## 2. 暂停菜单返回选择层

暂停覆盖层新增：

```text
继续 / 换游戏 / 回世界
```

- 继续：恢复 60Hz；
- 换游戏：保存当前局 → 打开 GamePicker；
- 回世界：保存/回传结果 → 调律台。

验收：

```text
暂停菜单出现
暂停菜单换游戏打开选择层
```

## 4. 游戏结果触发世界信号

### DSL

```text
游戏 方块校准
  胜利信号 信任动摇
  失败信号 ...
```

编译期校验信号存在；
序列化往返保留字段。

### Host

新增：

```ts
Engine.forceSignal(name): boolean
Universe.forceSignal(name): boolean
```

- 找到信号并直接发出它的 cues；
- 计入 cueCount；
- 游戏结果达到胜利分数时发 `胜利信号`，否则发 `失败信号`；
- 与结局、胜利动作并行。
