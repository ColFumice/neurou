# 混合方向下一步：世界 ↔ 游戏桥接（v1.33.0）

## 目标

从“孤立的小游戏”推进到：

```text
世界 → 实时游戏 → 结果信号 → 写回世界
```

这是混合路线（DSL 叙事 + Game 插件）的第一个闭环。

## 本次完成

### 1. 世界内启动游戏

在调律台弦界面按 **F6**：

- 取当前焦点弦作为绑定目标；
- 以该弦名启动俄罗斯方块；
- 进入前显示：

```text
结果 → 信任
```

### 2. 游戏结束/退出回传结果

`TetrisScene` 新增：

```ts
interface TetrisResult {
  score: number;
  lines: number;
  level: number;
  reason: 'over' | 'exit';
}
```

- 游戏结束自动回传；
- 玩家按 Esc 主动退出也会回传；
- 回传只触发一次；
- 没有绑定时（从初始界面进入）不写世界。

### 3. 分数写回弦

写回规则：

```text
ratio = clamp(score / 200, 0, 1)
value = lane.min + ratio * (lane.max - lane.min)
```

- 保留目标弦自己的量程；
- 使用现有 `universe.inject`；
- 持久化写回 `.nro`；
- 模块内只读弦仍被拒绝。

### 4. 结果可见

底部出现结果提示：

```text
游戏结果已写入「信任」：xx 分
```

英文模式：

```text
Result → Trust: xx pts
```

### 5. 返回行为

- 从世界按 F6 进入：Esc 回到调律台；
- 从初始界面进入：Esc 回到初始界面；
- 两种入口互不污染。

## 阶段意义

这一步建立了：

```text
Game Scene → Host → World State
```

的桥。

下一步可以继续做：

- `游戏` DSL 声明，显式绑定入口/结果弦/动作；
- 游戏结果触发世界信号或结局；
- Game SDK：复用 FixedStepLoop/输入/Canvas/存档；
- 多游戏注册表。

## 当前边界

- 绑定仍是“当前焦点弦”，还未进入 DSL 声明；
- 只回传分数到弦，尚未触发规则/动作/结局；
- 游戏模块仍只有俄罗斯方块；
- 游戏胜负尚未映射到世界结局。
