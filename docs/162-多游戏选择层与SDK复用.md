# 多游戏选择层与 Game SDK 复用（v1.37.0）

## 目标

当世界声明的游戏超过一个，玩家需要显式选择，而不是完全依赖当前焦点弦。

## 新增 GamePicker

`packages/gui/src/GamePicker.tsx`：

- 文本菜单风格；
- 不弹窗；
- 显示：
  - 游戏名；
  - 模块；
  - 结果弦；
  - 描述；
- 键盘：

```text
↑ / ↓ 选择
Enter 进入
Esc / F6 关闭
```

- 鼠标悬停/点击同样可用；
- 中英双语；
- 测试属性：

```text
data-testid="game-picker"
data-game-choice="蛇行"
data-game-module="贪吃蛇"
```

## 启动方式

### F6

保持旧行为：

```text
当前焦点弦 → 匹配结果弦的游戏 → 直接启动
```

### Shift+F6

打开多游戏选择层：

```text
世界所有 `游戏` 声明 → 选择 → 启动
```

## 选择后的绑定

GamePicker 选择直接复用 `launchDeclaredGame`：

```text
IRGame
  → 解析结果弦
  → 设置 gameBinding
  → 根据 module 渲染 TetrisScene / SnakeScene
```

所以选择层不是另一套逻辑，而是同一个启动函数。

## 世界示例

`examples/tuner.nro`：

```text
游戏 方块校准
  模块 俄罗斯方块
  结果弦 信任

游戏 蛇行
  模块 贪吃蛇
  结果弦 色温
```

操作：

```text
F6        → 信任 / 色温对应游戏直接进入
Shift+F6  → 选择层，↑↓ + Enter
```

## 当前边界

- 选择层只负责启动，不负责运行中切换游戏；
- 游戏渲染仍各自实现；
- 游戏快照还没有进入世界统一存档；
- 游戏结果仍只写回弦/动作；
- 没有游戏内“返回选择层”入口。
