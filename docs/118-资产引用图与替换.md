# 资产引用图与替换策略（v6.12）

## 1. 引用图

F6 选中资产后显示：

```text
引用：配乐 / 贴图 端口名
```

- 音频：`配乐`
- 纹理：所有视觉端口 `贴图`

`assetReferences(ir, kind, id)` 返回引用列表。

## 2. 删除策略

采用决策 A：

- 被引用资产显示「被引用，不能删除」；
- 删除按钮不出现；
- 核心 `removeAsset` 仍做二次校验。

## 3. 替换引用

对已引用资产提供「替换为」：

- 列出同类型其他资产；
- 音频替换 `配乐`；
- 纹理替换所有 `贴图` 端口；
- 行级 patch 更新引用行，资产声明不动；
- 完整重编译后写回。

```ts
replaceAssetReferences(ir, kind, oldId, newId)
```

## 4. 验收

- 单元 **397/397**：
  - 引用图（配乐/贴图）；
  - 引用替换后重编译；
  - patch 更新 `配乐`/`贴图` 行。
- GUI **328/328**：
  - 纹理引用显示 1；
  - 替换为备用纹后文件 `贴图 备用纹`；
  - 被引用资产不可删除；
  - 资产重命名仍可写回。
- 垂直切片新增备用纹理资产。

## 5. 边界

- 一次替换只更新同类型引用；
- 删除被引用资产仍拒绝；
- 引用替换不改变资产声明顺序。
