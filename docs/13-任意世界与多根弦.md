# 任意世界、同类多根弦与更柔和的振动（v1.1）

> v1.0 把「结构编辑」的第一步落在阈值上；v1.1 拆掉两个边界：
> **世界不再写死 `tuner.nro`**，可以 `?world=` 打开任意示例世界；
> **同类多根弦不再只画第一根**，左右方向键可以在同类弦之间切换。
> 同时按用户反馈把弦的振动整体放慢、放柔。

## 1. 打开任意世界（dev）

```
http://127.0.0.1:5188/?world=examples/rain-slice.nro
http://127.0.0.1:5188/?world=examples/negotiation.nro
```

- App 从 URL 读 `world`，只接受 `examples/<一层文件名>.nro`（拒绝路径穿越）；
- dev 下通过 `/__neurou/world?file=…` 读源码；写回也跟随当前文件（`data-world-file`）；
- 世界名、弦名、初值、阈值都来自那个文件；8 类弦里缺的类自然少几根；
- 生产包没有 dev 中间件，仍使用构建时内联的 `tuner.nro`（URL 参数被忽略）。

同一个世界文件也可以直接编辑写回：打开副本、拖弦或拖阈值，只有副本被改，原文件不受影响。

![雨循环世界：打开任意示例世界](images/string-worlds.png)

## 2. 同类多根弦（ArrowLeft / ArrowRight）

一个世界的一类弦可能不止一根（`rain-slice.nro` 的叙事弦有「体力」「饱食」等）。
调律台每类显示**当前选中的那一根**：

- 默认选第一根；
- `ArrowLeft` / `ArrowRight` 在同类候选之间循环（下标取模，可绕回）；
- 只切换视图，不改世界、不拨弦、不落盘；
- 切到哪根，拖弦/阈值编辑就作用在哪根；
- 写回时**所有数值弦**的当拍值都会被冻结成基线，不只是选中的那根。

![ArrowRight 后从「体力」切到「饱食」](images/string-instance.png)

## 3. 振动放慢、放柔（用户反馈）

`KIND_VISUAL` 的波速整体降为原来的约 0.6，阻尼降约 12%：

| 弦类 | 波速（旧 → 新） | 阻尼（旧 → 新） |
|---|---|---|
| 叙事 | 1300 → 820 | 0.55 → 0.48 |
| 视觉 | 2200 → 1350 | 1.6 → 1.4 |
| 动画 | 1800 → 1120 | 0.9 → 0.8 |
| 物理 | 1000 → 620 | 0.35 → 0.31 |
| 控制 | 1900 → 1200 | 2.2 → 1.95 |
| 空间 | 950 → 590 | 0.3 → 0.27 |
| 认知 | 2300 → 1420 | 2.4 → 2.1 |
| 关系 | 1500 → 940 | 0.8 → 0.7 |

另外焦点弦的驻波微颤从 4.5Hz 放慢到 **2.8Hz**（`standingOvertone`）。
效果：波峰爬上爬下更从容，反射与拖尾更柔和；拨弦手感没变（点击位置/幅度语义不变），
音频音高也不变——只有视觉上的波速与微颤更慢。

- `pnpm test` **96/96**（新增同类多根弦的投影/写回 2 个单测；世界投影共 7 个）
- `pnpm test:gui` **69/69** 新增：

    拖弦写回只改副本，原 `tuner.nro` 逐字节不变；
  - 双弦测试世界：默认「甲」，`ArrowRight` → 「乙」、值 70、`data-plucks` 仍 0，`ArrowLeft` → 「甲」；

  - 既有 60 项（世界接线/写回/阈值/撤销/音频/60fps）全部不回归。
- `pnpm check` / `build` / 生产冒烟通过；生产仍 `data-save-state=disabled`、文件不变。

## 5. 边界与下一步

- **世界选择只在 dev**，而且是 URL 参数，没有可见的文件选择器；
- **同类多根弦只显示一根**：没有“同一类多根同时叠在一屏”的表示；
- **耦合强度仍没有 GUI 手势**（core API 与单测已有）；
- 不能增删弦/耦合/规则；写回仍是规范序列化（有损）；
- 撤销历史只在当前会话。

下一步（v1.2）：**画布上编辑耦合强度**（选中两根弦/从焦点弦拖出连线，拖出强度）+ **增删结构**；
再往后（v1.3）做写回保真（源文本行级 patch，保留注释）与 `KIND_SOLVER` 求解器层。
