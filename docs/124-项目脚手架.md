# 项目脚手架（v6.18）

## 1. 命令

```bash
neurou init <名字> --template single|project|assets [--out 路径]
```

### single

生成一个可运行的单文件世界（默认）。

### project

生成：

```text
<root>/
  world.nro          入口
  modules/cast.nro   只读模块
  package.json       本地脚本
  README.md
```

入口通过 `引入 "modules/cast.nro"` 使用模块。

### assets

生成：

```text
<root>/
  world.nro
  audio/README.md
  textures/README.md
  README.md
```

世界包含视觉/音频端口、纹理/音频资产、后处理与自动化示例。
