# 交互体系重构与记忆模式（v1.7.2）

## 1. 流场：从静态视觉到声场画布

- 全屏可绘制 64×36 控制场；
- 等值线用 marching squares + 二次贝塞尔平滑，线条更粗、更连续；
- 线宽随时间呼吸，涡旋位移更大；
- 移除擦除模式和圆形笔刷提示；
- 字母/数字键映射到声场位置：改变布局并发声；
- 方向键移动、空格落笔。

截图：`artifacts/149-flow-woven.png`

## 2. 弹窗系统

### 保留四个弹窗

1. F6 波形/资源；
2. F7 规则/动作；
3. F9 章节路线；
4. 操作说明（初始界面「操作说明」）。

F3 关系谱矩阵是独立界面，不计入弹窗。

### 全屏化

弹窗宽度约 94vw、高度约 90vh，不再是小面板。

### 选中高亮

所有可聚焦/选中的按钮、列表项：

- 周围生成 6 条橙色弦；
- 不同透明度、不同动画延迟；
- 差速弹动后淡出。

全局组件 `StringHighlight` 监听 focus/click/pointerover/class；只在切换到新目标时触发一次，弦簇居中、两端渐变淡化、带随机波长与延迟。初始文件夹卡片保持半透明。

## 3. 光标

- 原生光标隐藏；
- 全屏十字贯穿整个窗口；
- 中心准星为四臂 + 实心点，中间不留空；
- 光标混色显示，黑底白线、白底黑线。

## 4. 初始界面

### 多级收纳

顶层只保留 4 项：

1. 进入调律台；
2. 世界（向右展开 6 个世界文件夹）；
3. 章节路线；
4. 操作说明。

### 差速跟随

- 标题、菜单、选中项以不同速度跟随鼠标；
- 选中项位移约为普通项的 3-4 倍。

### 完整流程操作说明

操作说明按「进入世界 → 调律弦 → 编辑元素 → 流场 → 记忆与发布」排版。

### 缓动进出

- 从初始界面进入调律台：左栏向左缓动移出；
- Esc 从调律台返回：左栏从左侧缓动进入；
- 不再用 Esc 进入总览。

## 5. 记忆模式 F12

- 右上角反色圆从右上角扩张到全屏，屏幕黑底白线；
- 再按 F12 圆缩回右上角；
- 当前界面键盘演奏会叠加为循环声部；
- 退出模式停止循环；
- 切换到其他元素界面（F2/F3/F6/F7/F9/F10、菜单等）自动退出；
- 这是一个新的编辑上下文层，后续可把各界面编辑数据统一挂到记忆目标上。

## 6. 路线检查

引擎主路线仍然是：

```text
八类弦 → 耦合/力迫/动作 → 确定性 tick → Host ABI
```

新增的流场、记忆模式都是 **GUI/编辑层**，没有改变运行时本体；数据仍通过编译校验或本地可视化层承载。

## 7. 数据结构

- 弦/波：`StringDecl` + IR + 行级 patch；
- 谱/关系谱：F2/F3 曲线数据；
- 流场：本地 64×36 控制场；
- 记忆模式：UI 上下文 + 循环声部；
- 统一入口：F7 规则/动作源文本；后续可扩展为所有元素的统一 DSL 输入。
