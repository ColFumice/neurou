# 动态耦合：关系谱曲线决定传导强弱（v2.5）

> 以前耦合强度是编译期常数；v2.5 允许写成**运行期表达式**——`查关系谱`、`此刻`、弦值都能参与。
> 关系谱不再只是规则的数据，而是直接改变世界物理。

## 1. 语法

```nro
耦合 月相 → 潮位 同向 延迟 1 强度 查关系谱("潮汐", "月相", "潮位", 此刻 / 30)
```

- `强度` 后面可以是任意数字表达式；
- 若表达式能在编译期折叠（例如 `0.5`、`0.3 + 0.2`），仍是静态强度，行为不变；
- 否则（含 `此刻`、`查关系谱`、弦值等）成为**运行期强度**，每拍传导时求值；
- 极性、延迟、曲线、`当` 守卫保持原有语义；
- 表达式类型必须为数字（NRO2003）；
- 序列化会写回表达式（`此刻()` 形式），往返编译一致。

## 2. 示例：`examples/tides.nro`

```nro
耦合 月相 → 潮位 同向 延迟 1 强度 查关系谱("潮汐", "月相", "潮位", 此刻 / 30)
耦合 潮位 → 岸线 反向 0.25 延迟 1

力迫 涨潮
  当 查关系谱("潮汐", "月相", "潮位", 此刻 / 30) > 0.6
  效果
    潮位 += 4
```

`pnpm dev run examples/tides.nro` 可看月相/潮位/岸线随曲线互动；F3 打开关系谱矩阵，播放头与 `此刻 / 30` 同步。

## 3. 运行

- 引擎在耦合传导处求值：`strength = strengthExpr ? evalExpr(strengthExpr, state) : strength`；
- 矩阵状态（v2.3 起）随世界进入运行时，所以 `查关系谱` 在耦合里可直接用；
- 快照/分叉不变（表达式是静态 IR 数据）；
- GUI 拖动耦合强度时，动态强度耦合会回退规范序列化，避免改错行。

## 5. 边界

- 强度表达式每拍对每条耦合求值一次（目前无缓存）；
- 不支持按方向/位置逐段改变同一根耦合的强度（仍是单值）；
- `当` 守卫与强度表达式都可用矩阵/谱，注意不要写出每拍剧烈震荡的反馈（可用延迟/曲线/`受迫` 谱稳定）。
