# 鼠标端三类交互统一（v5.36）

v5.35 只完成了键盘端的持续/头判/尾判分流；v5.36 把鼠标点击/按住也按同一张表收敛。

## 1. 鼠标行为

| 弦类别 | 鼠标行为 |
|---|---|
| 持续（视觉/动画/物理/空间） | 按下立即持续发声，移动跟随音高/音量，松开停止；不产生拨弦判定 |
| 头判（控制） | 按下立即发声/判定；不进入拉弦 |
| 尾判（叙事/认知/关系） | 按住拉弦 pin，松开才发声/判定 |

- 鼠标持续型也显示 v5.35 的持续音波形；
- 持续型鼠标松开不会产生拨弦/值注入；
- 鼠标拉弦 pin 仍只对尾判开放；
- 鼠标长按 pin 仍保留 180ms 阈值（避免单击被误判为拉弦）；
- 键盘拉弦仍是 0ms 即时。

## 2. 验收

- 单元 **371/371**；
- GUI **288/288**（既有键盘模式 / F2 / 拉弦波形全部保持）；
- 生产冒烟 / perf 通过。

## 3. 边界

- 鼠标头判没有“拉弦过程”，只有按下判定；
- 鼠标持续型的波形是视觉近似；
- 触控端沿用鼠标路径，但未单独做手势区分。
