# 逐色板浅色主题（v1.48.0）

## 变更

v1.47 的浅色主题是通过画布反相实现的：

```css
filter: invert(1) hue-rotate(180deg);
```

v1.48 改为真正的双色板：

```ts
GAME_THEME_DARK
GAME_THEME_LIGHT
themeFor(name)
```

主题 token：

```ts
{
  background, ink, dim, line, boardFill,
  accent, vignette, titleFont, monoFont
}
```

## 传递

```text
App gameTheme
  → Scene theme
  → GameHost theme
  → themeFor()
  → draw(..., theme)
  → paintGameBackdrop / paintGameBoard / drawGameChrome
```

四个场景都使用 token 绘制：

- 背景 / 暗角；
- 网格底板；
- 标题 / 副标题 / 键位；
- HUD 文字；
- 挡板 / 蛇头眼睛等对比色。

浅色主题不再使用 CSS 反相。

## 验收

新增 GUI：

```text
浅色主题使用浅色画布
```

读取画布角落像素，浅色主题下 R 通道 > 200（实测 228）。

原有：

```text
切换浅色游戏主题
切换回深色游戏主题
```

- 像素级对比仍以 token 为主，个别游戏强调色未完全拆出；
- 没有跟随系统主题；
- 没有每款游戏独立主题；
- 外部插件仍不能提供主题。
