# 迁移说明（v1.0）

## 从早期单文件世界

- `.nro` 仍是入口格式；
- 新增 `引入 "..."` 后自动按项目编译；
- 旧世界无需改动即可编译。

## 波形字段

- v5.43 起持续型弦可写 `波形`；
- 旧文件无波形 → 调律台使用默认波形；
- 写入后每根弦独立保存。

## 模块世界

- 模块弦只读；
- 入口弦可写回基线/阈值/波形，可增删；
- 入口非弦结构暂不可写。

## IR 使用方

- 只依赖 `docs/102` 列出的稳定字段；
- 新字段均为可选；
- 破坏性变更需迁移器。

## 版本

- 当前发布：5.57.0；
- v1.0 语义冻结的是**文档与 API 边界**，运行时版本号仍按 5.x 递增。
