# 真实函数调用 IR（v5.19）

> v5.17 把函数完全内联；v5.18 只保留函数声明。v5.19 让**调用点也保留**：
> LExpr 里出现 `用户:函数名(...)`，运行时按调用节点携带的函数体求值。

## 1. IR

```ts
type LExpr =
  | { k: 'param'; name: string }
  | {
      k: 'call';
      fn: '用户:夹紧';
      args: LExpr[];
      user: { name: string; params: string[]; body: LExpr };
    };
```

- 函数体 lowering 时，形参变成 `param` 节点；
- 调用节点携带函数体，运行时不需要全局注册表；
- 嵌套用户函数调用同样保留；
- IR `functions` 仍保存函数源码元数据（v5.18）。

## 2. 序列化

- `exprText` 对用户调用输出 `夹紧(值 + 50, 0, 100)`；
- 函数声明块输出 `函数/参数/返回`；
- roundtrip 后调用点和函数声明都保留；
- 运行时行为与内联版一致。

## 3. 运行时

```ts
evalExpr(call, state)
  → 求值 args
  → 建立 params 环境
  → evalExpr(user.body, state, env)
```

- `evalExpr` 增加可选参数环境；
- 函数体中的 `param` 从环境读取；
- 无全局函数表，也不依赖源码；
- 递归在编译期拒绝。

## 4. 验收

- 单元 **351/351**：函数测试新增
  - IR 效果包含 `用户:夹紧`；
  - 序列化保留调用 `夹紧(值 + 50, 0, 100)`；
  - roundtrip。
- 既有世界不含函数时不变；
- GUI 仍为 276。

## 5. 边界

- 调用节点携带函数体，同一函数多次调用会重复函数体 IR（后续可抽函数表去重）；
- 没有函数表/共享体/压缩；
- 没有函数类型标注；
- 函数体中的全局引用在 lowering 时解析，序列化仍可重编译；
- 递归仍被禁止。
