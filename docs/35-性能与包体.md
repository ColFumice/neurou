# 性能与包体（v2.18）

## 1. GUI 代码分割

F2 谱编辑器与 F3 关系谱矩阵是最大的两块 GUI 代码，但首屏只显示八弦调律台。
v2.18 起把它们改为 `React.lazy` 动态加载：

- 首屏主包不再包含 `MatrixField` / `SpectrumField`；
- 首屏稳定 350ms 后预取两块 chunk，用户按 F2/F3 时通常已加载完毕；
- 动态 chunk 有独立缓存，后续版本只改其中一个时另一个缓存仍有效。

### 构建结果（Windows，`pnpm build`）

| 产物 | 大小 | gzip |
|---|---|---|
| 分割前主包 | 384.12 kB | 128.10 kB |
| 分割后主包 | **318.41 kB** | **106.40 kB** |
| `MatrixField` chunk | 48.41 kB | 16.96 kB |
| `SpectrumField` chunk | 16.86 kB | 6.54 kB |

首屏主包 gzip 减少约 **22 kB**（-17%），F2/F3 的代码按需/预取加载。

### vendor 分包（v2.18.2）

Vite `manualChunks` 再把 React / `@neurou/core` / `@neurou/runtime` 拆成三个长期缓存 chunk：

| 产物 | 大小 | gzip |
|---|---|---|
| app entry | 64.42 kB | 25.10 kB |
| `vendor-react` | 141.67 kB | 45.38 kB |
| `neurou-core` | 89.82 kB | 30.13 kB |
| `neurou-runtime` | 22.57 kB | 7.25 kB |
| `MatrixField` | 48.52 kB | 17.02 kB |
| `SpectrumField` | 16.97 kB | 6.60 kB |

- 首次加载总传输量与单包接近（约 108 kB gzip），但 React/core/runtime 可跨版本缓存；
- 首屏 `DOMContentLoaded` 26–31 ms、First Paint 132–188 ms（多次运行波动）；
- 代价：初始请求从 1 个 JS 变成 4 个；本地/HTTP2 影响很小，慢网络需结合实际测。

## 3. 性能基线

新增 `scripts/perf-bench.ts`（`pnpm perf`）：

- 生产预览启动：Navigation Timing、First Paint、JS 堆；
- 空闲与 F3 矩阵模式下各 2 秒 `requestAnimationFrame` FPS；
- 三个示例世界的 `simulate` 吞吐（60 局 × 24 拍，random 模型）。

运行方式：

```bash
pnpm build
pnpm preview        # 另开终端，127.0.0.1:5189
pnpm perf           # 输出 artifacts/perf.json
```

本机（Windows，Edge headless）当前基线：

| 指标 | 数值 |
|---|---|
| DOMContentLoaded | 29 ms |
| First Paint | 132 ms |
| JS 堆 | 5.3 MB |
| 空闲 FPS | 60.3 |
| F3 矩阵 FPS | 60.2 |
| tuner 模拟吞吐 | 4196 局/s |
| moon-tide 模拟吞吐 | 4688 局/s |
| rain-slice 模拟吞吐 | 1754 局/s |

数值会随机器负载变化；脚本用于相对比较（改动前后跑同一命令）。

### 性能门禁阈值（v2.18.3）

`pnpm perf` 现在是可失败的门禁（失败时 exit code 1）：

| 指标 | 阈值 |
|---|---|
| DOMContentLoaded | ≤ 800 ms |
| First Paint | ≤ 1200 ms |
| 空闲 FPS | ≥ 45 |
| F3 矩阵 FPS | ≥ 45 |
| JS 堆 | ≤ 100 MB |
| 每个示例模拟吞吐 | ≥ 200 局/s |

阈值刻意保守（本地基线约为阈值的数倍）；如果 CI 机器较慢，先看 `artifacts/perf.json` 再调阈值。

## 4. 边界

- 预取会让首屏后几百毫秒内下载两块 chunk；若追求绝对首屏最小，可去掉预取（首次 F2/F3 会有一次模块加载延迟）；
- 目前没有 vendor 手动分包；React/core/runtime 仍在主包。
