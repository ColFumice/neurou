# 跟随系统主题（v1.49.0）

## 主题偏好

设置页现在三选一：

```text
深色 / 浅色 / 跟随系统
```

持久化：

```text
neurou.game.theme = dark | light | auto
```

## 解析

```ts
resolveGameTheme(preference):
  auto  -> matchMedia('(prefers-color-scheme: light)')
  dark  -> dark
  light -> light
```

- `auto` 时监听系统主题变化；
- 只更新 `documentElement.dataset.gameTheme`，不需要刷新；
- 场景收到的是解析后的 `dark | light`，绘制逻辑不变。

## 验收

新增 GUI：

```text
跟随系统主题解析为浅色
```

流程：

1. `emulateMedia({ colorScheme: 'light' })`；
2. 设置页选择「跟随系统」；
3. 检查 `data-game-theme === 'light'`；
4. `localStorage['neurou.game.theme'] === 'auto'`。

原有：

```text
切换浅色游戏主题
切换回深色游戏主题
浅色主题使用浅色画布
```

保留。

## 当前边界

- 系统主题变化只更新 dataset，当前打开的游戏需要重新绘制或重进才完全刷新；
- 没有每款游戏独立主题；
- 外部插件还不能提供主题；
- 世界/编辑器主界面不跟随游戏主题。

## 下一步
