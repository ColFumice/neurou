# 章节点击切换与标题浮现（v4.2）

> v4.1 的 N/B 只属于键盘。v4.2 让章节切换也能用鼠标/触控完成，
> 并给每次进入章节一个极短的标题浮现。

## 1. 结局点击

结局出现后，在八弦视图点击屏幕：

| 位置 | 行为 |
|---|---|
| 右半屏 | 保存当前局 → 下一章（若有） |
| 左半屏 | 保存当前局 → 上一章（若有） |

- 只在**结局后**和 `strings` 视图生效；
- 矩阵/谱模式点击不触发；
- 与键盘 `N`/`B` 共用同一套导航与存档逻辑；
- 移动端因此也能切章。

## 2. 章节标题

世界写了 `章节 "温室"` 时，进入页面会在画面中央短暂浮现标题：

- 衬线 18px、字距 0.22em、最高 alpha 0.32；
- 1.8s 淡入淡出后自动消失，不占用常驻 UI；
- `data-chapter-intro=true/false`；
- `[data-testid="chapter-intro"]` 可验收。

## 3. 验收

- GUI **252/252**：新增

- `check` / `check:gui` / `check:docs` / `build` / 生产冒烟通过。

## 4. 边界

- 点击只在结局后生效，不会在游玩中误切章；
- 没有章节菜单/网格；
- 标题浮现可能被快速跳过，属于氛围反馈而非信息；
- 左半屏回章要求世界声明 `上一章`；
- 移动端仍没有槽位选择 UI（靠 URL）。
