# 多出口结局：选择下一章（v4.5）

> v4.3 的结局只能去一个下一章；v4.5 允许一个结局声明多个出口，
> 结局出现后由玩家选择。

## 1. DSL

```nro
结局 归港:
  当 航向 >= 90 且 灯塔 >= 65
  下一章 "examples/soundscape.nro"
  下一章 "examples/lighthouse.nro"
```

- 同一个结局块可以重复 `下一章`；
- 顺序就是选择列表顺序；
- 每个路径都必须是 `examples/<名字>.nro`；
- 只有一个出口时仍保持 v4.3 的直接切章。

## 2. 选择界面

结局出现且出口数 >1 时：

- 画面偏下出现极淡的出口列表（无面板，衬线，未选 alpha≈0.32）；
- `↑/↓` 选择，`Enter` 前往；
- 点击某一项也可前往（触控）；
- 此时 N/半屏点击不直接跳章，必须先选；
- 只有一个出口时仍用 N / 点击右半屏。

可观测：

| 属性 | 含义 |
|---|---|
| `data-chapter-choices` | 当前结局出口数 |
| `data-chapter-choice-selected` | 选择索引（多出口时） |
| `[data-testid="chapter-choices"]` | 列表容器，`.chapter-choice` 行 |

## 3. 示例

`harbor.nro` 的「归港」现在有两个出口：

```text
归港 → soundscape / lighthouse
失踪 → garden
```

## 5. 边界

- 出口列表没有描述/预览，只显示文件名；
- 没有解锁/条件可见；
- 多出口时 N 不直接跳，避免默认选第一个；
- 点击列表项在桌面/触控都可；
- 出口仍限制在 `examples/`，没有跨项目章节包。
