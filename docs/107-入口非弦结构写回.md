# 入口非弦结构写回（v5.58）

模块世界里，入口文件除弦字段外，现在还能写回入口自己的谱/关系谱/耦合。

## 1. 实现

编译多文件时记录入口文本在合并文本中的 `entryOffset`。

`projectEntryView(ir, entryOffset, entryLength)`：

- 只保留 span 落在入口文本内的声明；
- 把 span 重基到入口文本偏移；
- 模块声明全部剔除。

写回：

```text
baseView = projectEntryView(baseProjectIR, offset, entryLength)
candidateView = projectEntryView(candidateIR, offset, entryLength)
→ patchWorldText(entryText, baseView, candidateView)
→ compileProjectFromFiles(新入口 + 模块)
→ 只写入口文件
```

## 2. 支持范围

| 结构 | 状态 |
|---|---|
| 入口弦：基线/阈值/波形/增删 | ✅ |
| 入口谱：段值 | ✅ 行级 patch |
| 入口关系谱：格子/曲线 | ✅ 行级 patch |
| 入口耦合：强度 | ✅ 行级 patch |
| 入口规则/动作效果 | ❌ 暂无编辑手势 |
| 模块声明 | ❌ 只读 |

## 3. 验证

- 单元 **384/384**；
- GUI **297/297**；
- 新增 GUI 用例：项目入口谱拖动 → `saved` + `patch`，文件段行更新、注释/引入保留、模块不写入；
- 新单元：入口视图过滤/重基；谱段点 + 耦合强度 patch 后完整项目重编译正确。

## 4. 边界

- 入口规则暂无 GUI 编辑手势，因此本阶段没有规则写回入口；
- patch 失败不会回退整文件序列化；
- 模块内结构仍只读。
