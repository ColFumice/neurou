# F10 通道修复：使用弦自己的音色（v1.27.0）

## 根因

F10 试听与调律台原始弦界面走的是两条不同音色通道：

- 调律台：`StringField` 拨弦时传入当前弦的 `lane.timbre`（世界里的谱）；
- F10：调用 `audio.pluck(kind, ...)` 时没有传 timbre，落回通用音色；
- 持续型弦：F10 也使用默认波形，而不是弦自己的持续波形。

所以同一个元素在 F10 内外听起来完全不同。

## 修复

- App 把当前目标弦的：
  - `targetStringId`
  - `targetTimbre`（来自世界谱）
  传给 FlowField；
- F10 键盘试听拨弦改为：

```ts
audio.pluck(targetKind, x, y, 0.82, 1, targetTimbre)
```

- 持续型弦使用：

```ts
sustainedWaves.getFor(targetStringId, targetKind)
```

作为固定波形；
- F10 节点触发也使用同一 timbre；
- 返回调律台后继续使用原始弦通道与效果总线。

## 结果

- F10 内试听与原始弦界面音色一致；
- F10 调整 depth/cutoff/resonance/drive/LFO 后，效果写入同一按类型总线；
- 退出 F10 不再出现“两种音色”。
