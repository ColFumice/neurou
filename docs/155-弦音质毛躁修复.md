# 弦音质毛躁修复（v1.30.0）

## 根因

上一版把完整参数接到弦效果总线后，默认参数本身带有强 LoFi：

1. `KindEffects.sampleRate` 默认是 `32000`；
2. 所有弦总线都始终串着 sample-rate reducer；
3. F10 节点默认 `bits` 只有 7–14、`sampleRate` 只有 12k–32k；
4. 这些默认值直接映射成音频 drive 与降采样；
5. 默认 ADSR 还会对每个拨弦做一次包络切割。

所以只要进入/调整过 F10，所有弦都会出现大量毛躁声。

## 修复

### 1. 总线默认值恢复透明

```text
sampleRate = 44100
drive      = 0
attack     = 0.005
decay      = 0.01
sustain    = 1
release    = 0.1
level      = 1
```

sample-rate reducer 在 44100 时 step=1，完全透明；
ADSR 默认接近直通；
drive 曲线默认恒等。

### 2. F10 节点默认值中性化

- 默认 `bits = 16`；
- 默认 `sampleRate = 44100`；
- 默认 ADSR 中性；
- 旧版 localStorage 节点自动迁移到中性音频参数；
- 节点存储增加 `version: 2`，新保存保留用户主动设置的 LoFi。

### 3. 保留用户主动 LoFi

只有用户主动把：

```text
bits 调低
sampleRate 调低
```

才会得到有意的颗粒/降采样，而不是所有弦默认变脏。

## 结果

- 原始弦界面音质恢复正常；
- F10 试听与原始弦继续共享同一效果总线；
- 默认无毛躁；
- 用户主动调 LoFi 时才出现 LoFi。
