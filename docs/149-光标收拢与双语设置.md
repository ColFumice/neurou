# 光标收拢与双语设置（v1.24.0）

## 1. 光标静止收拢

- 全局光标层 `CursorLayer` 新增 1 秒静止计时；
- 鼠标移动/按下时十字展开；
- 静止超过 1 秒：
  - 全屏十字线淡出；
  - 准星四臂向中心收拢；
  - 中心点轻微缩小；
- 使用与矩阵界面一致的收拢思路，过渡 260ms；
- 所有界面共享同一光标层，不再各页单独实现。

## 2. 双语设置

初始界面新增：

```text
设置 · 语言 / 字体
```

进入后保持初始界面的文本菜单风格，不使用弹窗：

- 中文；
- English；
- 语言立即生效并保存到本机；
- Esc 返回初始界面；
- 光标继续全屏跟随。

## 3. 全局字体

中文：

```text
Microsoft YaHei / PingFang SC
font-weight: 300
```

英文：

```text
Segoe Script / Bradley Hand / Lucida Handwriting / Brush Script MT
italic + font-weight: 300
```

- 根变量 `--serif` / `--sans` 统一改为上述字体；
- 按钮、输入框、文本域全部继承全局字体；
- 标题、菜单、面板保持同一套字体变量；
- 未单独硬编码字体的组件自动跟随语言切换。

## 4. 初始界面文字

初始菜单支持中英双语：

```text
进入调律台 / Enter Tuner
世界 / Worlds
设置 / Settings
章节路线 / Chapter Map
操作说明 / Guide
```

世界子项：

```text
测试世界 / Test World
十分钟灯塔 / Ten-Minute Lighthouse
```
