## 1. 三条核心判定

### 判定 1 · 定位

**问题**：第一分钟，他主动把界面描述成什么？

- **通过**：编辑器 / 调律台 / 弦网络 / 可以改的世界 / 牵一发动全身。
- **失败**：游戏 / 关卡 / 画面 / 角色 / 一个带调试面板的游戏。
- **通过线**：5 人中 ≥3 人，且不是被追问出来的。

### 判定 2 · 活性

**问题**：他会不会主动碰弦？碰了之后，他看见变化传到哪？

- **通过**：首次注视弦网络后 **30 秒内**主动悬停或拖动一根弦；拖动后能说出
  「变化沿着线传到别的弦 / 不止那一根在变 / 那几根亮了一下」。
- **延迟**：30–60 秒内碰弦。
- **未发现**：全程不碰。
- **通过线**：5 人中 ≥3 人「通过」，且其中 ≥2 人能说出传播，而不是只说「小人动了」。

### 判定 3 · 结构

**问题**：他能不能用自己的话解释一个结构？

- **通过**：能说出至少一条回路 `A → B → C → A`，或一个力迫「当 … 就会 …」；
  用词不必是「回路 / 力迫」，说「这个圈让饥饿变成恐惧」也算。
- **失败**：只说「这些是装饰 / 看不懂 / 很酷」。
- **通过线**：5 人中 ≥3 人。

## 2. 主持人脚本（逐字念，不补充）

> 这是一个还在很早期的世界创作工具。今天不是测你，是测它。
> 你可以随便点、随便试，没有正确做法；遇到看不懂的，不用忍着，直接说出来。
> 这一版的画面是示意，重点看世界怎么反应，不看画面精不精细。
> 我会尽量不说话，除非你卡住了。

念完补一句：

> 过程中我不会告诉你该点哪里。

**绝对不要提**：弦、回路、力迫、拖动、Tab、F、空格、发布、左下角那行字。
**不要指**：左下提示、任何一根弦、右下那几行字。
**分数话术**（只在发布后说）：**「分数是这个世界当前的状态，不是工具的质量。」**

## 3. 任务卡（一次只给一条）

**A · 第一眼（60 秒，不许动鼠标）**
> 先别动。你看到的是什么？如果要讲给朋友听，你会怎么说？

**B · 自由探索（3 分钟）**
> 现在可以动了。随便看看，想做什么都行。这里没有正确操作。

**C · 改一根（3 分钟）**
> 如果你想让画面里的世界变一点，你会怎么做？
> 试试看。改完告诉我你改了哪一根。

**D · 传开（2 分钟）**
> 刚才你改的那一根，变化有没有传到别的地方？
> 你看到了什么？是只有那一根在变，还是图上也有东西在动？

**E · 圈与菱形（3 分钟）**
> 图里那些圈和菱形是什么？点一下/悬停一下会怎样？
> 你能说出其中一个圈让什么牵动了什么吗？

**F · 换视角（3 分钟）**
> 这张图有没有办法看大一点？除了这张图，还有没有别的看法？
> 右下角那几行小字里，有没有你能看懂的东西？

**G · 发布（3 分钟）**
> 如果你觉得这个世界差不多了，你会按哪里？
> 看到分数后，你觉得它在说什么？

（主持人补：分数是这个世界当前的状态，不是工具的质量。）

## 5. 访谈（任务后）

1. 「用一个词形容这个界面，你会用什么？」（先记原词）
2. 「那些竖线是什么？它们和这个世界是什么关系？」
3. 「你刚才改的那一根，变化传到哪里了？你怎么看出来的？」
4. 「那些圈是做什么的？你为什么点/不点？」
5. 「五个小词（弦、回路、调性、力迫、和弦）你看到了几个？哪个最清楚？」
6. 「你会先教朋友做什么？」
7. 「这是一个游戏，还是一个做世界的工具？为什么？」
8. 「哪里让你觉得『这还是个网页仪表盘』？」
9. 「58 分是在说这个世界，还是说这个工具？」
