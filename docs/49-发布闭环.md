# 发布闭环：静态发布包（v3.10）

> v3.4 让生产包能通过 URL 打开任意世界；v3.10 把“能构建”收口成“能交付”：
> 一条命令生成可直接静态托管的目录，并带版本清单。

## 1. 一条命令

```bash
pnpm release
```

内部等价于：

```text
pnpm build
node scripts/release.mjs
```

产物：

```text
release/neurou/
  index.html
  assets/
  audio/
  release.json
  README.txt
```

- `release/neurou/` 可直接放到任意静态文件服务器；
- 不需要 Node 服务、不需要 `/__neurou/save` 中间件；
- 生产包只读，调律只影响当前运行，刷新回文件初值。

## 2. release.json

```json
{
  "name": "neurou",
  "version": "3.10.0",
  "builtAt": "...",
  "entry": "index.html",
  "worlds": ["examples/core-test.nro", "..."],
  "save": "disabled"
}
```

- 版本来自根 `package.json`；
- `worlds` 是构建时可用的示例世界清单；
- 构建后页面根节点有 `data-version`，与清单一致。

## 3. 访问

```text
index.html
index.html?world=examples%2Fmoon-tide.nro
index.html?seed=42
index.html?world=examples%2Fsoundscape.nro&seed=7
```

## 4. 子路径部署

默认 `base: '/'`。部署在 `https://host/neurou/` 时：

```bash
NEUROU_BASE=/neurou/ pnpm release
```

Vite 会把资源路径改成 `/neurou/assets/...`。

## 5. 验收

- `pnpm release` 成功：版本 3.10.0、13 个世界、`release.json` 生成；
- 单元 **314/314**、GUI **241/241** 不回归；
- `pnpm build` / `pnpm perf` / 默认生产冒烟 / 世界选择冒烟通过；
- 发布包与 `packages/gui/dist` 同源。

## 6. 边界

- 没有自动上传/部署到云，只生成可托管目录；
- 没有 CI 配置、没有签名/校验和（后续可加）；
- 生产包无写回、无资产上传、无用户账户；
- `release/` 被 `.gitignore` 忽略，不提交构建产物；
- 子路径部署需要重新构建，不是运行时切换。
