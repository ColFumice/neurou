## 2. 五个方向交付

| 方向 | 内容 |
|---|---|

## 3. 关键能力

- DSL：八类弦、实体、耦合、力迫、动作、结局、谱/关系谱、场景、系统、端口、模块、函数、资源；
- 运行时：确定性 tick、快照/恢复、分叉；
- 调律台：八弦、F2 谱、F3 矩阵、F6 波形/资源、F7 规则；
- 后端：GLSL 两 pass + 后处理参数、Faust wasm、持续弦复音与自动化；
- 工程：行级写回、模块入口写回、迁移器、CI、发布门禁。

## 5. 已知边界

- 规则源整块/逐行编辑，不做完整 AST 结构化编辑；
- 资产删除被引用时拒绝；
- 后处理参数为本地偏好；
- Host 跨 ABI 大版本需显式迁移；
- 内容仍以示例世界为主，不是完整商业游戏。

## 6. 结论

v1.0.0 是第一个**可编译、可编辑、可发布、可外部集成**的稳定版本。
