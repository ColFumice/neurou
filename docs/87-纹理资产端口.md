# 纹理资产端口（v5.30）

> v5.29 的纹理是 Host 内置程序化图案。v5.30 允许世界声明**纹理资产**
> 并把资产绑定到视觉端口；Host 异步加载真实图片，加载完成前保留程序化兜底。

## 1. 语法

```nro
纹理资产 雨纹 "textures/rain.svg"

视觉端口 雨幕
  参数 强度 雨量
  贴图 雨纹
```

- `纹理资产 <名字> "<path>"` 是世界级声明；
- 路径只允许 `textures/` 下一层的 `.png/.jpg/.jpeg/.webp/.svg`；
- `贴图 <资产名>` 绑定到视觉端口；
- 仍可同时写 `纹理 <图案> <尺度>`，作为加载前/加载失败时的兜底；
- 音频端口不能绑定贴图。

## 2. 数据链路

```text
纹理资产
  → WorldIR.textureAssets
  → IRPort.textureAsset
  → Engine.observe() BackendPortFrame.textureAsset
  → GlslArtifact.textureSrc
  → GlslCanvas 异步 Image 加载 → WebGL 纹理
```

- Host URL 以 `/textures/...` 解析；
- 图片加载失败时保留 v5.29 程序化纹理；
- release 会把仓库 `textures/` 一并复制到发布包；
- 序列化保留 `纹理资产` 与 `贴图` 行。

## 3. 示例

新增 [examples/texture-rain.nro](../examples/texture-rain.nro)：

```nro
纹理资产 雨纹 "textures/rain.svg"

视觉端口 雨幕
  参数 强度 雨量
  贴图 雨纹
```

对应资产：[textures/rain.svg](../textures/rain.svg)。

## 4. 诊断

| 情况 | 诊断 |
|---|---|
| 重复纹理资产名 | `NRO2004` |
| 非法路径（目录/扩展名/`..`） | `NRO2108` |
| 端口引用不存在的资产 | `NRO2101` |
| 音频端口绑定贴图 | `NRO2003` |

## 5. 验收

- GUI **279/279**：`data-glsl-assets` 可观测 `雨纹`；

## 6. 边界

- 没有纹理资产目录扫描/自动发现；
- 没有 UV 变换端口；
- 没有图片透明通道混合配置；
- 没有加载失败 UI（只回退程序化纹理）；
- 生产发布仍需静态服务器可从 `/textures` 提供文件。
