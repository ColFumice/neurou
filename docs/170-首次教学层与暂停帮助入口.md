# 首次教学层与暂停帮助入口（v1.45.0）

## 1. 首次进入游戏教学

GameHost 在游戏首次进入时显示教学块：

```text
FIRST RUN
俄罗斯方块
七种方块、消行与计分。
← → 移动 · ↑ 旋转 · ↓ 软降 · Space 硬降
Enter 开始 · H 查看完整帮助
```

数据来源：

- `GameModuleInfo.description[language]`
- `GameModuleInfo.controls[language]`

首次开始后写入：

```text
neurou.game.tutorial:<moduleId> = 1
```

之后进入不再显示。

## 2. 暂停菜单帮助入口

暂停菜单现在：

```text
继续 / 换游戏 / 帮助 / 回世界
```

点击「帮助」打开游戏内帮助层，关闭后仍保持暂停状态。

- 教学是单块，不是分步引导；
- 教学不区分难度；
- 外部插件不能自带教学；
- 主题仍固定深色。
