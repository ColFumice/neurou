# v1.0 发布清单与迁移器（v6.21）

## 1. 冻结边界

- Host ABI：`neurou-host/1`；
- stateVersion：`1`（缺省视为 1）；
- IR format：`neurou/ir-0.1`；
- 破坏性变更必须提升 ABI 并提供迁移器。

## 2. 发布清单

```bash
pnpm check
pnpm test
pnpm test:gui
pnpm check:docs
pnpm build
pnpm perf
pnpm release
node scripts/gui-prod-smoke.mjs
node scripts/gui-prod-world-smoke.mjs
```

通过标准：

- 单元/GUI 全绿；
- 大世界 tick 吞吐 ≥ 200；
- 生产预览 DOM/FP/FPS/堆达标；
- release.json 版本与 package.json 一致。

## 3. 回滚

1. `git revert <发布提交>` 或回退到上一稳定 tag；
2. `pnpm build && pnpm release`；
3. 重跑生产冒烟；
4. 浏览器 `?fresh=1` 复验。

## 4. 迁移器

```bash
neurou snapshot-migrate <快照.json> [--out 路径]
```

支持：

- 当前 v1 快照；
- 缺失 `stateVersion` 的旧快照（补 1）；
- `neurou-host/0` 提升到 v1；
- 未知 ABI / 版本拒绝。

实测：

```text
已迁移 artifacts/migrated-snapshot.json
· 补上缺失的 stateVersion=1
snapshot-check → { "ok": true }
```
