# F10 音色/音量/混响通道完全对齐（v1.28.0）

## 剩余差异的三个来源

1. F10 进入时自动把节点效果写入弦总线，导致混响突然变湿；
2. F10 试听使用固定音量 `0.82`，原始弦的拨弦音量取决于按键相对基线的拉幅；
3. F10 的 y 归一化方向与原始弦相反，会影响亮度与音量。

## 修复

- 移除 F10 进入/切换目标时的“自动应用节点效果”：
  - 只有用户真正调整参数（行内 `−/+`）时才写入效果总线；
  - 进入 F10 不再改变原始混响/滤波。
- F10 键盘试听音量改为与原始弦一致：

```ts
baseline = valueToY(targetNorm * 100)
amplitude = |key.cy - baseline| / maxPull
```

- 持续型弦使用同一个基线计算 `maxKeyDistance` 与 amplitude；
- y 归一化改为 `cell.cy / LOGICAL_H`，与原始弦一致；
- 继续传入目标弦自己的谱 timbre / 持续波形。

## 结果

F10 内试听与原始弦界面：

- 同一音色；
- 同一音量；
- 同一混响；
- 只有用户主动调整效果参数时，两个界面才一起变化。
