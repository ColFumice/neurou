# 模块依赖图（v5.15）

> v5.9 有了多文件 `引入`，v5.15 给它一个只读依赖图命令。
> 这是工具层，不改变语言语义。

## 1. CLI

```text
neurou modules examples/storm.nro
```

输出：

```text
examples/storm.nro
  examples/lib/tide.nro
    examples/lib/rain.nro
```

- 入口在前，缩进表示依赖；
- 重复模块只展开一次（DAG）；
- 循环/缺失模块沿用 `ProjectError`；
- 路径相对当前工作目录。

## 2. Core API

```ts
projectGraph(entryPath, (path) => readFileSync(path, 'utf8'));
// [{ path, imports: string[] }, ...]
```

- 按深度优先、依赖先于入口的顺序返回；
- 不编译、不做名字解析，只读 `引入` 行；
- 与 `compileProject` 共用路径归一化/相对解析。
