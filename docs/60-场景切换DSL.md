# 场景切换 DSL：初始场景与切换场景（v5.3）

> v5.1 让场景/系统进入 IR 与运行时；v5.3 让世界自己决定从哪个场景开始、
> 以及在规则/系统效果里切换场景。GUI 预览蒙版仍留给 Host 层（v5.4）。

## 1. 初始场景

```nro
世界 雨幕
  版本 0.1
  初始场景 "夜"
```

- `初始场景` 是世界元数据，值为场景名；
- 未声明时使用第一个场景；
- 没有场景的世界保持旧行为（隐式默认场景）；
- 场景名不存在时回退第一个场景。

## 2. 切换场景效果

```nro
系统 换景
  阶段 收尾
  效果
    切换场景 昼
```

- `切换场景 <场景名>` 是效果，可出现在系统、力迫、和弦、动作、场景进入/离开中；
- 效果只**排队**，在本拍 `收尾` 阶段之后统一生效；
- 切换时先执行旧场景 `离开`，再执行新场景 `进入`；
- 同拍多个切换以最后一个为准（确定性，不递归）；
- 无效场景名在编译期报 `NRO2101`。

## 3. 快照与 Host

- `WorldState.sceneId` 进入快照/序列化；
- `Universe.transitionScene(name)` 仍可被 Host 立即调用；
- `Engine.observe().scene` 给预览层当前场景名；
- Engine 不因场景切换重启，tick/值/延迟队列保留。

## 4. 验收

- 单元 **328/328**：新增
  - 初始场景元数据；
  - `切换场景` 编译/IR/序列化/roundtrip；
  - 非法场景效果；
  - 系统效果在收尾切换场景。
- 既有世界无场景时行为不变；
- GUI 仍为 261，未改表现层。

## 5. 边界

- 场景不能声明局部弦；
- 没有场景栈/返回栈，只有单当前场景；
- 没有 GUI 场景切换入口；
- 预览蒙版/hot swap 未实现（v5.4）；
- 场景切换不触发章节/存档等 Host 语义。
