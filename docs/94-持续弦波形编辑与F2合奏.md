# 持续型弦的可编辑波形与 F2 合奏（v5.37）

## 1. 持续型弦：按键 = 编辑波形

- 焦点切到持续型弦（视觉/动画/物理/空间）时，弦显示的是**可编辑波形**，不再播放动态波形；
- 按键/鼠标在弦上的位置会写入该位置的波形（高斯平滑到邻近采样）；
- 写入后波形**保持静止**；
- 持续发声使用这条波形作为音色；
- 松开按键停止发声，波形仍保留；
- 每条持续型弦各自保存一条 32 段波形。

数据流：

```text
按键 x/y
  → sustainedWaves.editAt(kind, x01, amplitude, direction)
  → 弦显示静态波形
  → startSustainedSpectrum(当前波形)
```

## 2. F2 谱模式：合奏只作用于「按住方向键」

v5.38 明确范围：

- **只有按住 ↑/↓ 连续调音时**，F2 的持续音使用**所有持续型弦波形的合奏**；
- 拖段点、映射键试听、单击段点等其它 F2 发声，仍使用**谱曲线自身波形**；
- 谱曲线继续用于世界数据、播放头、写回；
- 编辑持续弦波形会改变 F2 方向键合奏音色；拖谱曲线不会改变方向键合奏音色。

| F2 操作 | 音色来源 |
|---|---|
| 按住 ↑/↓ | 四条持续弦波形合奏（按下时取一次波形，只跟踪音高/音量） |
| 拖段点 | 当前谱曲线 |
| 映射键试听 | 当前谱曲线 |
| 单击段点 | 当前谱曲线 |

### v5.40：方向键不再每帧换波表

之前按住 ↑/↓ 时，合奏声源每帧调用 `updateSustainedSpectrum`，而该函数会
每 70ms 重建一次振荡器，听感上变成不断重复的“头判音”。

现在：

- 按下方向键时 `startArrowVoice` 只创建一次合奏声源；
- 按住期间只调用 `updateSustainedTone` 跟随音高/音量；
- 方向键松开才停止；
- ←/→ 切段时只重建一次新段声源。

### v5.41：鼠标拖动与键位映射修正

- F2 鼠标拖段点：只在起音时取谱曲线波形，拖动期间只更新音高/音量，
  不再重复换波表/重复起音；
- 持续型弦的键盘上下映射修正：上方按键写入向上的波峰，下方按键写入向下波峰。

## 4. 边界

- 波形编辑只保存在当前 GUI 会话，不写回 `.nro`；
- 波形为 32 段采样，不是任意长度曲线；
- F2 合奏固定取四类持续弦，不区分场景/世界；
- 持续弦的鼠标/键盘共用同一波形库。
