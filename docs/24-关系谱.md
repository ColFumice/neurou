# 关系谱：配对 × 数值的静态关系矩阵（v2.1c）

> v2.1c 引入第二种「谱」数据形状：**关系谱**——行/列是标签，矩阵每个格子是一个数值。
> 它表达“谁对谁的关系强度”，并通过 `查关系谱("名","行","列")` 在编译期常量折叠。

## 1. 语法

```nro
关系谱 势力网
  行 信任 色温 步态
  列 信任 色温 步态
  段 0 0.3 0.1
  段 0.3 0 0.6
  段 0.1 0.6 0
```

- `行` / `列` 各一行，1..64 个任意标签（不要求是已声明的弦名）；
- `段` 必须重复 `行数` 次，每行 `列数` 个有限数字；
- v2.3 起可加 `曲线 行 列 …`（每格时间曲线）；v2.4 起可加 `周期 <拍数>`（GUI 播放头跟随运行时 tick，见 [关系谱驱动世界](27-关系谱驱动世界.md)）；
- 顶层名字与谱/弦/实体/其他关系谱共享命名空间；
- 错误码：语法 NRO1100、重名 NRO2004、形状/标签/数值 NRO2100、查关系谱参数 NRO2003、找不到矩阵/行列 NRO2101。

## 2. 读取：编译期常量折叠

```nro
结局 稳定: 当 查关系谱("势力网", "信任", "信任") > 0.5
```

- 三个参数都必须是字符串字面量；
- 矩阵是静态数据，因此编译期直接折叠成数字常量（运行时不改、无额外状态）；
- 行/列标签大小写/空白需完全匹配；错误信息带可用标签/近似名提示。

## 3. 序列化与写回

- 规范块顺序：谱 → 关系谱 → 耦合；
- 关系谱是静态数据；patch 把它纳入结构签名，任何关系谱变化都会回退整图规范序列化（暂不做行级 patch）；
- `examples/spectra.nro` 新增 2×2 示例 `情绪关系`（标签是任意标识，不要求已声明为弦）。

## 5. 边界与下一步

- 静态矩阵，不能随时间/每拍变化，也没有运行时调制；
- 每格是一条数值，不是曲线（完整“配对 × 时间”是后续 B 方案）；
- 暂无 GUI 关系谱视图/编辑；写回是整图回退而非保真 patch；
- 下一步：v2.2 或把关系谱扩成每格曲线 / GUI 矩阵视图（按你的优先级定）。
