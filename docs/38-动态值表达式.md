# 动态值表达式：关系谱格子由谱与其它格子计算（v2.19）

> 关系谱的 `段` 一直是编译期常量。v2.19 起可以给某个格子写 **`动态 行 列 表达式`**：
> 读取该格时实时求值，谱、其它关系谱、弦值、`此刻` 都可以参与。

## 1. 语法

```nro
关系谱 心潮
  行 心情 潮位
  列 心情 潮位
  段 0.2 0.5
  段 0.5 0.7
  动态 心情 潮位 查谱("天气", 心情 / 100) + 心情 / 200
```

- `动态 <行> <列> <数字表达式>`；
- 行/列标签必须在编译期存在；
- 同一格不能同时有 `曲线` 和 `动态`（NRO2100）；
- 动态格不能被规则效果写入（NRO2100）；
- GUI 拖动该格会失败并提示「动态值格不能直接手改」。

## 2. 运行时语义

- `查关系谱(矩阵, 行, 列)` 三参数读取时：
  - 普通格 → 静态 `段` 值；
  - 动态格 → 每次读取都重新求值；
- 四参数在有曲线时仍采样曲线；动态格没有曲线，因此四参数回退到动态值；
- `当前谱值` 仍要求曲线，不使用动态格（动态格用三参数 `查关系谱`）；
- 动态表达式可以引用：
  - 弦值：`心情 / 200`
  - 谱：`查谱("天气", 0.5)`
  - 其它关系谱：`查关系谱("心潮", ...)` / `当前谱值(...)` / `谱位(...)`
  - 时间：`此刻`
- 表达式是 IR 数据，随快照/分叉复制；
- 运行期递归/自引用有深度保护（最多 8 层），返回 0；
- 被动态格引用的矩阵在编译期不能折叠成常量，保证读到运行期值。

## 3. 示例：`examples/relational.nro`

```nro
关系谱 心潮
  动态 心情 潮位 查谱("天气", 心情 / 100) + 心情 / 200

关系谱 网
  动态 潮位 心情 查关系谱("心潮", "心情", "潮位") * 0.5 + 0.1
```

- 第一个动态格把「天气谱」和「心情弦」组合，谱的采样位置本身也由心情决定；
- 第二个动态格再引用第一张关系谱的动态值，形成跨谱关系；
- 动作看天/独处/听潮推动心情和潮位，动态值随之改变；
- sim 80 局：晴 / 阴 / 超时都会出现。

## 5. 边界

- 动态表达式只能写在关系谱标量格，不能写谱 `段` 或曲线采样点；
- 动态格没有曲线，因此没有 `当前谱值` 的时间采样；
- 目前动态表达式不能引用**同一张矩阵的动态格**（编译时矩阵尚未注册），可引用更早声明的矩阵；
- GUI 矩阵画布显示的是源文件静态回退值，不实时显示动态求值结果。
