# 十键并发、F9 迁移与流场声场方案（v1.11.0）

## 1. 十键同时敲击/按住

- 持续型弦支持 10 个物理键同时按住；
- 每个键独立 voice / pin / 波形编辑；
- 波形 localStorage 写入改为 80ms 防抖，避免十键时同步写盘卡顿；
- 十键期间只更新一次可视化帧，键盘输入仍逐键立即响应。

GUI 实测：

```text
持续型：十键同时按住 — 10
持续型：十键复音不卡顿 — 10
```

## 2. F9 键位

- **F9** 现在是记忆模式内的「当前弦类型效果器」；
- 章节路线图迁移到 **Shift+F9**；
- 帮助与初始菜单已同步。

## 3. 流场视觉

- 连续闭合等值线；
- 去除人为弯曲偏移，不再出现线条互相交叉；
- 用相邻线段首尾连接 + 二次贝塞尔平滑；
- 等值线在局部范围内缓慢漂移，不跨区乱飞；
- 线宽随时间与层级动态呼吸；
- 同一层级内曲线自然融合/嵌套。

## 4. 流场中声场/效果器的方案

### 方案 A：等值线声场节点（推荐）

把每个闭环当作一个声场节点：

```ts
FlowNode {
  center, radius, tension
  pan: radius 决定左右声场位置
  depth: 闭环大小决定远近
  reverb: 线宽/透明度决定混响发送
  diffusion: 嵌套闭环层数决定扩散
}
```

- 闭环固定在某个区域游走 → 稳定的空间定位；
- 多个节点靠近 → 等值线融合，声场也融合；
- 适合用鼠标/键盘画节点。

### 方案 B：场梯度滤波器

- 等值线密度 → 低通/带通截止；
- 等值线曲率 → 共振 Q；
- 线条粗细 → 滤波斜率；
- 画一笔等于在空间上放一个滤波器。

### 方案 C：闭环包络器

- 闭环扩张/收缩过程录制为 ADSR；
- 闭环面积 → sustain 电平；
- 拖拽速度 → attack/release；
- 多个闭环可形成复调包络。

### 方案 D：LFO = 局部游走

- 每个闭环拥有 `spin / orbit / phase`；
- 闭环游走轨迹本身就是 LFO；
- 游走速度 = LFO rate，游走半径 = LFO depth；
- 嵌套闭环相位差形成空间 chorus。

### 方案 E：Lo/HiFi

- 降低绘制网格分辨率/量化阶数 → Lo-Fi；
- 等值线平滑 + 高分辨率 → Hi-Fi；
- 可把网格量化映射为 bit depth / sample-rate reduction；
- 每个闭环可单独切换 Lo/Hi。

### 建议的数据结构

```ts
FlowNode {
  id
  center: { x, y }
  radius
  tension
  spin: { rate, depth, phase }
  filter: { cutoff, resonance }
  envelope: { attack, decay, sustain, release }
  lofi: { bits, rate }
  effects: { reverb, delay, width }
}
```

存储为世界旁的 `.nrm` 侧车文件，不污染运行时 IR；Host 只读 descriptor。

### 落地顺序

1. 现有等值线画布加入 `FlowNode` 数据模型；
2. 节点到声场（pan/depth/reverb）的映射；
3. 场梯度 → 滤波器参数；
4. 闭环扩缩 → 包络；
5. 游走 → LFO；
6. 网格/量化 → Lo/HiFi；
7. 保存/加载侧车文件。
