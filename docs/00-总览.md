## 一句话

neurou 是一门**游戏与叙事创作的领域语言**：创作者不写剧情分支，而是设计一张
「弦网络」——状态、阈值、回路、力迫、公理——编译器保证这张网不会散架，
运行时让它在每一拍里活起来，批量模拟告诉创作者它是否值得发布。

类比不是「做一个更好的剧情编辑器」，而是：

| 领域 | 语言 | 编译器保证 |
|---|---|---|
| 图形 | GLSL | 类型与着色器可编译 |
| 音频 | Faust / SC | 延迟分析与 DSP 图 |
| **叙事与游戏** | **neurou** | **回路闭合力、公理一致性、力迫兼容性、体验可感知** |

## 命名

neurou = 雨若。

- 「雨若弦，万物皆弦」：世界不是由物件组成的，是由**振动与耦合**组成的。
- 近义「神经」：创作应当是沉浸的、有身体感的，不是在表单里填参数。
- 因此核心隐喻是乐器，不是机器：**调律台、弦、回路、和弦、曲式、配器、总谱、音准仪**。

## 五个不可动摇的决定

### 1. 图是唯一真源，文本是投影

创作者在结构层拨动一根弦，代码区就多出一行声明；手改代码，结构图跟着变。
所以数据结构必须先是一张图（弦网络 IR），文本语言只是它的一种渲染格式。
v0.1 已经按这个顺序实现：`packages/core/src/ir.ts` 是唯一真源，解析器只是图的入口之一。

### 2. 七类弦 + 关系弦，一切可调之物都是弦

| 弦 | 张力是什么 | 求解器 |
|---|---|---|
| 叙事弦 | 当前值接近阈值的程度 | 状态机（离散事件） |
| 视觉弦 | 偏离基线的程度 | 渲染管线（每帧） |
| 动画弦 | 偏离标准动作的程度 | 混合树 / 程序化生成器（须标注，不可混用） |
| 物理弦 | 与基准物理的偏差 | 物理积分器（每帧） |
| 控制弦 | 意图到力的传导效率 | 输入映射 |
| 空间弦 | 区域可达性偏离基线的程度 | 区域图（与叙事弦双向事件总线） |
| 认知弦 | 「知道 / 不知道」的偏离 | 知识图谱更新器 |
| 关系弦 | 关系当前值（带记忆） | 事件驱动更新器 |

统一的是**编辑语言**，不是运行时。语义统一、求解器分离——这是必须诚实的一条。

### 3. LLM 只做状态解释器

LLM 接收「状态切片 + 类型约束」，输出「结构化表达片段」，不生成世界规则、不改 HOD、
不携带全局上下文。世界知识在创作时编译进弦包，运行时不再重复携带。

这条原则有三个后果，缺一不可：

- 成本：token 随局部变化增长，而不是随世界规模增长；
- 一致性：规则层是宪制，LLM 是解释宪法的法官，不是随时能改法的独裁者；
- 可验证：编译器是第一个验证器，不需要跑起来才知道语法对不对。

### 4. 前端极简，后端极繁

默认路径三步：**看弦网络 → 拖一根弦 → 发布**。弦不是隐藏实现，而是主界面；
模板、求解器、批量模拟仍在引擎盖后。创作者第一眼就该知道自己在操作的是弦。

每一层复杂性仍要有一个极简入口：

- 关系弦 → 拖一个「恐惧衰减」模板；
- 认知弦 → 选「知识驱动探索」，自动挂载基础包；
- 两级模拟 → 默认只显示「硬缺陷检查通过」，深度检查在引擎盖后；
- 程序化动画 → 选「黏滑感」，参数落在哪个手感区间直接用人话显示。

极简不是功能少，是**默认路径短**；极繁不是堆功能，是**复杂性被封装在默认路径之下**。

### 5. 锁运行时，不锁知识

- 可导出：弦网络结构文档、原始素材、弦包协议声明；
- 不可导出：状态机执行、解释器调度、宇宙分支管理、多模态实时行为。

创作者的资产永远拿得走；世界的「演奏法」留在平台。这条写进 Ω，是商业护城河与创作者信任
同时成立的前提。

## 语言长什么样

```nro
世界 谈判
  调性 小调

实体 使者
  叙事弦 信任
    类型 数值 0..100
    基线 50
    悬崖 25     # 低于这里就进入危险侧
    安全 70

回路 猜忌
  边 信任 → 筹码 同向 0.35
  边 筹码 → 局势 同向 0.3
  边 局势 → 信任 同向 0.25

  当 信任 < 25
  效果
    耐心 -= 15
  不可逆
  优先级 10

  效果
    信任 -= 7
    筹码 += 9
```

## 体验的四个视图

调律台不是一个窗口，是同一个宇宙的四种观察姿态：

1. **调律台**（默认）：白纸黑线的全屏弦网络——竖向声部线、横向耦合、常驻品丝、回路闭环、
   力迫菱形；没有侧栏、没有底部工具栏、没有画中画。用户在弦上直接拖。
2. **现象层**（空格）：世界在运行，作为观察与试玩入口，不是默认主画面。
3. **结构层**（Tab）：同一张弦网络放大到全屏。
4. **力迫层**（F）：条件偏序图。玩家每次选择是在条件空间里选一个点，兼容的点才可选——
   叙事张力来自**可能性空间的收缩**，不是路径分叉。
5. **总谱**（G，未来）：时间 × 系统的复杂度地形。哪里耦合过密（玩家过载）、哪里全是死规则、
   哪个时段配器单一，一眼可见。

错误不是弹窗，是**裂缝**：语法错在代码里，语义错在回路上（附可拖入的候选回路），
体验警告在总谱暗区，触碰 Ω 时是界面失真而不是文字解释。

## 四层创作者

| 层级 | 能做什么 | 术语暴露 |
|---|---|---|
| 聆听者 | 只拧一个推子，不知道自己在调弦 | 弦、回路 |
| 演奏者 | 和弦槽位与滑块，无代码区 | + 调性、力迫、和弦 |
| 作曲家 | 完整弦网络、偏序、配器，代码可编辑 | + 认知弦、关系弦、偏序、动机、曲式 |
| 制琴师 | 定义弦类型、写求解器、发布算法包 | + HOD、求解器路由、状态切片 |

术语不教，术语出现：L1 五个词作为调律台的常驻标签（0.3–0.4），L2 用到才出现，L3 藏在引擎盖后。
每个术语配一句人话锚点（「弦」=「一个会变、也会牵动别处的量」），锚点里不许用别的术语解释自己。

## 音准仪：把「好不好玩」变成可计算的

对话里最重要的一次自我质疑是：**没有形式化定义，音准仪就是玄学。**
v0.1 用五个可计算维度回答它：

| 维度 | 度量 | 说明 |
|---|---|---|
| 公理与硬缺陷 | 公理违反次数、死局局数 | 一票否决项 |
| 玩家能动性 | 无动作可选的局占比 | 操作空间归零的早期信号 |
| 规则活性 | 触发过的力迫 / 发出过的信号 / 被用过的动作 | 死规则会拉低分数 |
| 结局的分歧 | 结局分布的归一化熵 | 所有局同一结局 = 0 |
| 节奏与吸引子 | 存活拍数的离散度、最常见终局的集中度 | 过度收敛会扣分 |

分数上限被刻意压在 85 以下。**绿区 60–85**：低于 60 是站不稳，高于 85 是太均衡、
没有意外。一个「哪里都对」的世界不值得发布。

## Ω：二十一条

平台宪法，六章：玩家保护、创作者权利、AI 边界、弦包市场、本地层免费、Ω 修改程序。

- 失败可理解、操作空间不可归零、不静默操纵、随时可退出；
- 原始素材永远可导出、结构文档可导出、运行时行为不可导出；
- 本地 AI 只做重复性功能、不联网、生成内容对创作者可见；
- 基础认证由平台承担，认证报告公开可查，恶意弦包零容忍；
- 本地推理永远免费，不强制联网；
- Ω 由人签发、不由 AI 定稿，修改提前 30 天公示。

条文之内没有商量，条文之外一切可谈。

## 首期切口

不做完整《雨世界》，做它的**最小切片**：单区域、双生物、一个雨循环、一个认知弦。
`examples/rain-slice.nro` 就是这个切片的第一版。

理由是：它恰好压中架构最擅长的三件事——生态关系网、知识驱动、机制压力驱动故事张力。

## 最终简化后的产品形态

一个本地应用，三块：

1. **调律台**：默认是全屏弦网络（弦 + 耦合 + 品丝 + 回路 + 力迫），白纸黑线；
   现象层按空格全屏切换，引擎盖后是算法模块编辑器、批量模拟面板。
2. **本地 AI 助手**：只做重复性功能——状态切片翻译、诊断润色、模板填充、格式检查。
   不联网、不决策、不上传数据。
3. **弦包市场（集成）**：浏览、试听、一键接入、兼容性检查、基础认证报告。

外部 AI 是**离线辅助**：创作者在任意工具里生成 .nro 代码，粘贴回编辑器；
编辑器只负责检查与执行，不负责调用 API、不管理密钥、不写 prompt。

## 早期说法 vs 最新定稿

| 早期 | 最新 |
|---|---|
| 六类弦 | 七类 + 关系弦；音效并入信号通道，不单独成类 |
| 关系表是静态声明 | 关系必须是可被事件驱动的弦 |
| 力迫平铺、无优先级 | 必须有偏序（`先于` + `优先级`），编译期查环 |
| 空间弦单向耦合 | 与叙事弦共享双向事件总线 |
| 动画弦 = 混合树 | 必须标注「混合 / 生成」，求解器不同 |
| 万物皆弦 = 一切 | 弦只覆盖设计层，不覆盖引擎层与计算层 |
| 云端 AI + 平台合作 | 只跑本地；外部 API 离线粘贴；不做平台合作 |
| 弦包独立平台 | 集成进 UGC 主应用 |
| 配器 = 跨系统耦合矩阵 | 拆开：耦合矩阵 / 配器（资产绑定） |
| 完美完备性 | 绿区 60–85，满分是反面信号 |
