# 函数分支返回（v5.24）

> v5.23 的函数仍是单返回表达式。v5.24 允许 `当 … 返回 …`
> 按顺序短路的多分支纯函数，最终仍然只有一个返回类型。

## 1. 语法

```nro
函数 分类
  参数 x: 数值
  返回类型 文本
  当 x < 5
    返回 "小"
  当 x == 5
    返回 "中"
  返回 "大"
```

规则：

- `当 条件` 行起一个分支，缩进块里只写 `返回 表达式`；
- 分支按声明顺序求值，第一个成立的分支返回；
- 最后必须有一个无条件的 `返回` 兜底；
- 分支条件必须是真假判断；
- 所有分支与兜底返回类型必须一致（或任一侧为任意）；
- 局部变量在分支之前生效，可被分支条件/返回引用。

## 2. 编译期展开

```text
当 x < 5 返回 "小"
当 x == 5 返回 "中"
返回 "大"

↓

选择(x < 5, "小",
  选择(x == 5, "中", "大"))
```

- 条件表达式复用运行时 `选择`；
- `选择` 在运行时惰性求值，只算命中的分支；
- 局部变量按 v5.23 规则展开；
- 分支源码进入 `IRFunction.branches`，供序列化。

## 3. 序列化

```nro
函数 分类
  参数 x: 数值
  返回类型 文本
  当 x < 5
    返回 "小"
  当 x == 5
    返回 "中"
  返回 "大"
```

分支/兜底/类型标注都会保留，roundtrip 行为不变。

## 4. 验收

- 单元 **356/356**：新增
  - `当` 分支短路返回；
  - 序列化保留 `当 … 返回`；
  - roundtrip 后运行结果。
- 既有函数/世界行为不变；
- GUI 仍为 276。

## 5. 边界

- 没有 `否则` 块/多语句分支/循环；
- 分支体只能是单个返回表达式；
- 没有分支级局部变量；
- 分支条件中调用函数仍按纯函数展开；
- 返回类型仍是统一类型，不支持联合类型。
