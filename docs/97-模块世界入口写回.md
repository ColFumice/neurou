# 模块世界入口写回（v5.47）

多文件世界此前在 GUI 中只读。v5.47 开放**入口文件弦字段**的写回。

## 1. 可写范围

允许：

- 入口文件里声明的弦；
- 弦字段：基线、悬崖、安全、波形；
- 行级 patch，保留入口注释/排版；
- 保存后用完整项目重新编译校验。

不允许：

- 模块文件里的弦（只读）；
- 入口里的谱/关系谱/耦合/规则等非弦结构改动；
- 整文件规范序列化回退。

触碰只读范围会显示 `data-save-state=error` 与原因，不会写文件。

## 2. 实现

```text
入口源码 → parse → 入口弦声明 span
候选 IR → 入口弦字段 patch
→ compileProjectFromFiles(entry 新文本 + 模块)
→ /__neurou/save 只写入口文件
```

- `projectEntryStrings`：入口弦 id/span；
- `patchProjectEntry`：用入口 span 做行级 patch；
- 模块弦/非弦数组变化检测后拒绝写回。

## 3. 验收

- 单元 **380/380**：入口弦 span、patch、完整项目重编译、模块不受影响；
- GUI **289/289**：模块世界仍可打开，依赖可观测；
- 生产冒烟 / perf 通过。

## 4. 边界

- 只支持入口弦字段，不支持入口结构编辑；
- 多实体/命名空间入口的弦 id 解析是第一阶段实现；
- 写回失败不会回退成整文件序列化。
- v5.48：模块弦在调律台里被标记为只读（`data-module-strings`），
  拖动/拨弦/阈值/波形编辑会被拒绝并显示 `data-save-error`；
  文件保持不变。
