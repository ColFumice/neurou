# 手势总览（v1.0）

调律台以键盘/鼠标手势为主，无常驻面板。

## 八弦场

| 手势 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 切换弦类别 |
| `←` / `→` | 同类多根弦之间切换 |
| 拖动弦 | 改基线 |
| 拨弦（点按/拖） | 注入取值并试听 |
| 滚轮 | 调焦点弦耦合强度 |
| `Shift+↑/↓` | 选择耦合目标 |
| `Shift+Enter` | 增/删与目标的耦合 |
| `Alt+Enter` | 新增同类弦 |
| `Alt+Backspace` | 删除焦点弦 |

## 持续型弦波形

| 手势 | 作用 |
|---|---|
| 按住普通键/鼠标 | 编辑波形并持续发声 |
| 松开 | 停止，不产生拨弦判定 |
| `Alt+1..4` | 正弦/三角/方波/柔波预设 |
| `Alt+R` | 重置当前弦默认波形 |

## 谱 / 矩阵 / 预览

| 手势 | 作用 |
|---|---|
| `F2` | 进入/退出谱模式 |
| `↑/↓` 按住 | 谱调音（持续弦合奏） |
| `←/→` 按住 | 切换音段 |
| 拖动段点 | 连续改谱值 |
| 映射键 / 单击 | 谱曲线音色试听 |
| `F3` | 关系谱模式 |
| `Space` | 现象层预览 |
| `F8` | 场景切换（有场景时） |

## 全局

| 手势 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `R` | 结局后重开世界 |
| `Esc` | 关闭浮层/动作列表 |

## 只读 / 模块

- 模块弦更淡，弦名后有小点；
- 编辑模块弦会被拒绝并显示错误；
- 入口弦可写回，模块只读。

## 边界

- 手势随上下文变化，以画布焦点为准；
- 没有 GUI 提示文字，属隐藏手势；
- 后续可加首次使用引导。
