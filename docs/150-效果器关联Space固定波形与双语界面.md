# 效果器关联、Space 固定波形与双语界面（v1.25.0）

## 1. 「信任」与「叙事」效果器关联

- F9 现在在调律台弦界面也可直接打开，不再只限 F12；
- 效果器目标由：
  - 弦类型（叙事）；
  - 具体弦名（信任）；
  共同显示；
- 效果器标题：`声场效果器 · 叙事 · 信任`；
- F10 流场目标按钮与 HUD 同步显示具体弦名；
- F7 流场声明标题也带弦名；
- 底层仍通过该弦类型效果总线作用于「信任」的拨弦/持续音。

新增 GUI：

```text
调律台 F9 打开当前弦效果器 — 叙事
效果器关联当前弦名（信任）
```

## 2. 持续型弦 Space 固定波形

- App 的 Space 预览切换在持续型弦界面不再生效；
- StringField 接管 Space：
  - 按住 Space 进入「固定波形演奏」；
  - 键盘映射仍发声，但不再 `editAtString`；
  - 当前波形保持不变；
  - 松开 Space 恢复波形编辑；
- Space 只在鼠标预览界面用于打开/关闭现象层，且忽略 key repeat，不会闪烁。

新增 GUI：

```text
持续型：Space 进入固定波形演奏
持续型：Space 演奏不改波形 — 860→860
持续型：Space 松开恢复编辑
```

## 3. 双语界面适配

- 英文模式下启用 DOM 文案翻译观察器；
- 动态面板（F10 参数、F9 效果器、F7 DSL、设置、世界栏）自动翻译；
- 常见 UI 标签：
  - 声场半径 / Space radius
  - 滤波截止 / Cutoff
  - 包络攻击 / Attack
  - 混响 / Reverb
  - 低通 / Low-pass
  - 导出 .nrm / Export .nrm
  - 应用声明 / Apply declaration
- 不翻译世界数据与 DSL 内容（弦名、谱名、剧情文本仍保持作者原文）；
- 中文模式恢复原文；
- 字体仍按语言切换。
