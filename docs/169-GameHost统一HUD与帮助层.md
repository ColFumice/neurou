# GameHost 统一 HUD、帮助层与插件清单（v1.44.0）

## 1. 统一 HUD

GameHost 现在统一绘制：

- 游戏标题；
- 副标题；
- 最高分；
- 底部键位提示。

三个场景不再各自绘制这些 chrome，只画：

- 棋盘/场地；
- 分数/生命等游戏内指标。

统一由 `gameTheme.ts` 的：

```ts
drawGameChrome(ctx, width, height, {
  title, subtitle, keys, best, bestLabel
})
```

负责。

## 2. 游戏内帮助层

任意游戏内按：

```text
H 或 ?
```

打开帮助层：

- 标题 / 副标题；
- 操作说明；
- 暂停菜单；
- 存档续局说明；
- 帮助键说明。

行为：

- 打开时自动暂停当前游戏；
- 关闭后恢复到刚才状态；
- H / Esc / Enter 关闭；
- 打开时阻止游戏输入透传。

测试属性：

```text
data-testid="game-help"
```

## 3. 插件清单

`GameModuleInfo` 增加：

```ts
description: { zh, en }
controls: { zh, en }
```

四款游戏都有：

```text
俄罗斯方块
贪吃蛇
乒乓
打砖块
```

GamePicker 在没有世界内描述时使用模块清单描述。
