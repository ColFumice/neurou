# 主题预设（v1.57.0）

## 预设

设置页新增四种主题预设：

```text
默认 / 极光 / 余烬 / 单色
```

保存：

```text
neurou.game.preset = default | aurora | ember | mono
```

## 解析链

```text
themeFor(dark | light)
  → applyGameThemePreset(preset)
  → accentFor(moduleId, theme)
  → GameHost draw / chrome
```

- 预设只覆盖基础色（背景、墨色、网格、暗角、面板）；
- 每款游戏的强调色仍由 gamePalette 决定；
- 深/浅主题各有一套预设色值。

## 预设色

| 预设 | 深色背景 | 浅色背景 |
|---|---|---|
| 默认 | #0a0b0d | #f3eee4 |
| 极光 | #07151a | #eef8f4 |
| 余烬 | #170f0b | #fbf0e6 |
| 单色 | #0b0b0b | #f2f2f2 |

## 设置 UI

设置页现在三组：

```text
语言
游戏主题（深色 / 浅色 / 跟随系统）
主题预设（默认 / 极光 / 余烬 / 单色）
```

`data-settings-preset` 用于测试。

## 当前边界

- 预设不覆盖每款游戏的 accent；
- 没有自定义预设/导入导出；
- 预设只对游戏生效，世界/编辑器主界面不跟随；
- 外部插件不能声明预设。
