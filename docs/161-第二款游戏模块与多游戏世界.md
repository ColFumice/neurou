# 第二款游戏模块与多游戏世界（v1.36.0）

## 目标

用第二款游戏验证 GameModule / GameSession 是否真的可复用，而不是俄罗斯方块特例。

## 新增贪吃蛇模块

`packages/gui/src/snakeEngine.ts`：

```ts
SNAKE_MODULE: GameModule<SnakeState, SnakeCommand>
```

状态：

```text
24×18 棋盘
蛇身 / 方向 / 待转向
食物 / 分数 / 速度等级
确定性 PRNG
```

规则：

- 固定步长移动；
- 转向不能 180°；
- 撞墙 / 撞自己结束；
- 吃食物 +10 分、身体增长、食物重生成；
- 每 5 个食物升一级；
- 速度 180ms → 最低 75ms。

只实现：

```ts
create / step / score / lines / level / isOver
```

调度、输入队列、暂停、结果回传完全复用 GameSDK。

## 多游戏世界

`examples/tuner.nro` 现在同时声明：

```text
游戏 方块校准
  模块 俄罗斯方块
  结果弦 信任

游戏 蛇行
  模块 贪吃蛇
  结果弦 色温
```

F6 选择规则：

1. 当前焦点弦是「信任」→ 方块校准；
2. 当前焦点弦是「色温」→ 蛇行；
3. 其他 → 第一个游戏。

App 根据 `gameBinding.module` 渲染：

```text
俄罗斯方块 → TetrisScene
贪吃蛇     → SnakeScene
```

结果都走同一个：

```text
GameResult → handleGameResult → 写回结果弦 → 胜利动作
```

## 当前边界

- 两款游戏共用 GameSession，但渲染仍各自实现；
- 没有统一 Renderer / InputProfile 接口；
- 没有游戏选择 UI，F6 按弦隐式选择；
- 游戏快照还没有进入世界统一存档；
- 结果仍只写回弦/动作。
