# 记忆循环与节拍器（v1.10.0）

## 1. F12 记忆循环：真实音频采样

不再使用合成音。

- 进入 F12：在 `StringAudioEngine.master` 上并联 `MediaStreamAudioDestinationNode`；
- 用 `MediaRecorder` 录制进入→退出区间的**真实界面输出**；
- 退出 F12：停止录音，`decodeAudioData` 得到 `AudioBuffer`；
- 这段录音的时长就是一个循环长度；
- 再次进入时，旧 `AudioBuffer` 通过独立的 `AudioBufferSourceNode`（`loop=true`）直接接到 destination 循环播放；
- 新录音只从 master 采样，因此旧循环不会被重复录进去；
- 退出时断开全部循环与录音。

因此音色、拨弦、频谱、混响/后处理都来自原界面本身，而不是合成振荡器。

## 2. 操作

| 输入 | 行为 |
|---|---|
| F12 | 进入 / 退出记忆模式 |
| 任意演奏键 | 原界面照常发声，同时被录进当前循环 |
| 再次 F12 进入 | 旧采样循环叠加播放，同时开始录制新一层 |

HUD 显示：

- 旧采样循环数量；
- 当前循环已录键击数；
- 采样循环时长。

## 3. 节拍器

F11 打开/关闭：

- BPM；
- 每几拍响一次（1..8）；
- `[` / `]` 调拍间隔；
- `-` / `=` 调 BPM；
- 设置持久化到 `localStorage["neurou.metronome"]`。

## 5. 边界

- 采样存于当前页面内存，刷新页面会丢失；
- 采样来自单弦调律 master；Faust 端口、独立音频资产 BGM 不经过该 master 时不会被采样；
- 退出记忆模式会断开全部循环与录音。

## 6. 记忆模式内的上下文编辑

- F2：编辑当前弹奏弦类型绑定的音色谱，不退出记忆模式；
- F9：打开当前弦类型的效果器（混响/低通），不退出记忆模式；
- Ctrl+F12：清空全部已叠声部；
- Ctrl+Delete：删除最近录制的一个声部。

详细重构分析见 [记忆编辑架构重构方案](136-记忆编辑架构重构方案.md)。
