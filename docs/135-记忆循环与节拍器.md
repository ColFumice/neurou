# 记忆循环与节拍器（v1.8.0）

## 1. F12 记忆循环

修复前：所有旧音符被每 1.8 秒同时播放一次。

现在：

- 进入 F12 开始一个新的录制区间；
- 每个键击记录严格相对时间 `offsetMs`；
- 进入至退出的时长 `lengthMs` 就是一个循环长度；
- 退出时断开全部声部；
- 再次进入时，旧循环按各自 `lengthMs` 与 `offsetMs` 精确叠加播放；
- 新演奏继续录成下一层循环。

HUD 显示旧循环数量与本循环已录音符数。

数据：

```json
localStorage["neurou.memory:examples/tuner.nro"] = {
  "takes": [
    {
      "lengthMs": 4200,
      "notes": [
        { "offsetMs": 220, "freq": 520, "gain": 0.04 },
        { "offsetMs": 980, "freq": 610, "gain": 0.04 }
      ]
    }
  ]
}
```

## 2. 节拍器

F11 打开/关闭节拍器。

面板显示：

- BPM；
- 每几拍响一次；
- 节拍脉冲点。

键盘：

| 输入 | 行为 |
|---|---|
| F11 | 开关 |
| `[` / `]` | 每几拍响一次（1..8） |
| `-` / `=` | BPM（30..240） |

设置写入 `localStorage["neurou.metronome"]`。

节拍器在任意界面运行，包括记忆模式。

## 4. 边界

- 记忆声部是合成音循环，不是原界面音色的采样回放；
- 退出记忆模式会断开全部声部；
- 节拍器只出声与显示脉冲，不自动量化演奏。
