# 写回保真：只改被编辑的那几行

> v0.9 起调律台会把整张图序列化写回 `.nro`，代价是**注释、空行、排版全丢**。
> v1.4 换成了**行级 patch**：拖基线/阈值/耦合强度时，只替换源文件里对应的数字，
> 其余字节（包括注释）原样保留；只有结构性修改才回退到规范序列化。

## 1. 写回路径

```
用户手势 → debounce → withCurrentBaselines(IR, Universe) = candidate
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
        patchWorldText(baseText, baseIR, candidate)
                    │ ok                            │ 不支持（结构变化/链式回路…）
                    ▼                               ▼
         行级替换数字 → compileText 校验      serialize(candidate) → compileText
                    │                               │
                    └──────────────┬────────────────┘
                                   ▼
                        POST /__neurou/save（原子写）
```

- **baseText / baseIR**：磁盘上当前文本与它编译出的图。每次成功写回后更新；
  撤销/重做/重新加载后也会重置，因此任意多次编辑都能继续 patch。
- **行级定位**靠 IR span：弦声明块里找 `基线/悬崖/安全` 行，耦合声明里找 `强度`/极性后的数字；
  没有 `基线` 行时插在 `类型` 行后面。
- **换行统一为 LF**：编译器内部会把 CRLF 归一成 LF，span 偏移基于 LF；patch 同样先归一，
  写回即 LF（注释、缩进、空行不变）。这是为了让“位置 → 文本”永远对得上。
- **回退条件**（返回失败 → 规范序列化）：
  - 增删弦/规则等结构变化（普通耦合的增删自 v1.5 起由 patch 插入/删除整行）；
  - 改极性/延迟/曲线/表达式/名字；
  - 链式回路的边没有独立强度；
  - 行格式无法识别。
- `.ink-app` 新增 `data-save-mode`：`patch` / `fallback`，验收可见；回退原因会打印到 console。

## 2. 支持的编辑

| 编辑 | patch 行为 |
|---|---|
| 拖弦改基线 | 替换该弦 `基线 N` 行 |
| 拖阈值刻度 | 替换 `悬崖 N` / `安全 N` 行 |
| 耦合强度滚轮 | 行内 `反向 0.4` → `反向 0.65`，或 `强度 0.4` / 回路块 `边 … 同向 0.5` |
| 保存时冻结当拍值 | 同时更新所有变化的数值弦基线行 |

## 3. 验收

单元（`packages/core/test/patch.test.ts`，8 个）：

- 只改基线：注释/空行/顺序保留，编译后值正确；
- 基线 + 悬崖 + 安全一次 patch；
- 行内耦合强度、回路块 `边` 强度；
- 链式回路强度 → 拒绝 patch；
- 无变化原样返回；回路边删除 → 拒绝；普通耦合增删 → 插入/删除整行（v1.5）；
- CRLF 源文本 → 归一成 LF 后 patch 仍正确。

GUI（`pnpm test:gui`，110 项）新增：

- 阈值写回后：文件仍以 `# 八弦调律台的默认世界` 开头，注释行数 5/5 不变，**不出现**规范序列化头；
- 拖弦写回：同样保留注释，`data-save-mode=patch`；
- 耦合写回：注释保留，文件里 `边 信任 → 色温 同向 0.65`；
- 既有 95 项（按住绷弦/撤销缓动/任意世界/多根弦/世界数据流/音频/60fps）全部不回归。

最近一次数字：`pnpm test` **105/105**、`pnpm test:gui` **97/97**；`data-save-mode=patch`，
注释数 5→5，阈值/基线/耦合三种编辑都走行级路径。

## 4. 边界与下一步

- **只在配套字段上保真**：增删弦/规则、回路编辑仍会回退整图规范序列化（注释会丢）；
- **不保留原换行符**：写回统一 LF（内容与缩进保留）；
- 不支持“改一行里的多个数字”（例如同一行改极性+强度）；这类回退规范序列化；
- 撤销后继续编辑：base 会在应用文本时重置，仍能继续 patch。

v1.5 已补上：
1. **普通耦合增删**：`Shift+↑/↓` + `Shift+Enter`；patch 会插入/删除整行并保留注释
   （见 [增删耦合](17-增删耦合.md)）；
2. 连续 patch（新增→删除）已验证能逐字节恢复原文。

下一步（v1.6 规划）：
1. 增删弦/规则：需要块级插入/删除（更复杂的 patch）；
2. 回路编辑；
3. 之后是 `KIND_SOLVER` 求解器层。
