# 灯与潮：阶跃曲线 + 相位源 + 动态耦合（v2.10.1）

> `examples/lighthouse.nro` 是一个 3 弦、2 关系谱、4 动作、4 信号、3 结局的可玩世界。
> 它同时用上 v2.7 的相位源、v2.9 的阶跃插值、v2.5 的动态耦合：潮位用**离散潮阶**改变灯火，
> 心绪的时间轴又由潮阶曲线驱动。

## 1. 世界结构

| 元素 | 内容 |
|---|---|
| 弦 | 潮位 / 灯火 / 心绪 |
| 关系谱「潮阶」 | 2×2，潮位×灯火曲线 `0.2 / 0.8 / 0.4`，**插值 阶跃**，周期16、速度1.2、相位0.2 |
| 关系谱「心图」 | 2×2，心绪×灯火曲线 `0.1 / 0.6 / 0.9`，周期12、速度0.9、**相位源 潮阶 潮位 灯火** |
| 动态耦合 | `潮位 → 灯火` 的强度 = `查关系谱("潮阶","潮位","灯火", 谱位("潮阶"))`；灯火推心绪 |
| 动作 | 修灯 / 观潮 / 写信 / 出海 |
| 信号 | 潮涨 / 灯暗 / 心绪沉 / 灯稳 |
| 结局 | 灯灭 / 远行 / 归港 |

## 2. 怎么玩

```bash
pnpm dev run examples/lighthouse.nro
pnpm dev sim examples/lighthouse.nro --runs 100 --ticks 100
```

GUI：

```
http://127.0.0.1:5188/?world=examples%2Flighthouse.nro
```

- 八弦模式：拨弦、看潮位/灯火/心绪；
- `F2`：世界里没有谱音色，F2 不进入（提示无谱）；
- `F3`：默认「潮阶」，Tab 切到「心图」：
  - 潮阶曲线是**阶梯**，灯火只会在几个潮位档位间跳变；
  - 心图的播放头相位来自潮阶曲线，因此心绪的时间轴会随潮汐档位忽快忽慢。

## 3. 设计意图

- 阶跃让「潮位档位」变成离散事件，而不是连续噪声；
- 相位源让两张矩阵共享同一条潮汐节奏，但心绪仍按自己的周期走；
- 动态耦合让潮位真正推动灯火，而不是靠规则每拍硬改；
- 四个动作各自偏向一个结局方向：修灯守港、写信养心、观潮/出海推向远行。

## 4. 验收

- `pnpm dev check examples/lighthouse.nro`：3 弦 · 2 耦合 · 4 规则 · 4 信号 · 3 结局；
- sim 100 局：归港约 82% / 远行约 18%，2 种结局，无硬缺陷；
- 不影响既有测试：`pnpm test` 255/255、`pnpm test:gui` 208/208、build/生产冒烟通过。

## 5. 边界

- 心图只有一条曲线，所以「阶跃 + 相位源」组合主要体现在潮阶→心图；
- 两个结局可进一步用信号/结局条件细化，当前示例以可玩性为主。
