# 错误提示：拼写建议与字段级 hint（v2.18.4）

> 编译器的大部分错误都带 `code / span / hint`；v2.18.4 把名字拼写建议抽成共用实现，
> 并补齐了几类之前提示过短的情况。

## 1. 共用拼写建议

- 新增 `packages/core/src/suggest.ts`，`suggestName(word, candidates)` 用 Levenshtein 距离找最近候选；
- parser 与 compiler 共用，不再各写一份；
- `suggestName` 仍从 `@neurou/core` 导出。

## 2. 本次补齐的提示

| 场景 | 之前 | 现在 |
|---|---|---|
| 关系谱字段拼错（如 `周其`） | 只列可用字段 | 先给「你是不是想写「周期」？」，再列字段 |
| 谱/矩阵 `插值` 拼错 | 提示只有「线性、平滑」 | 包含「阶跃」 |
| `曲线` 修饰写错（如 `修饰`） | 只提示数字 | 提示可用修饰：`插值 / 循环 / 速度 / 相位` 与示例 |
| 关系谱 `查关系谱`/曲线标签/矩阵效果 | 多数已有 hint | 保留并继续使用具体标签建议 |

## 3. 错误结构

所有诊断至少包含：

```ts
{
  code: 'NRO2100',       // 分类码
  message: '关系谱「网」...',
  span: { start, end },  // 指向源码位置
  hint?: '...'           // 可操作的修复建议
}
```

GUI 的写回错误会显示在调律台角落；CLI `check` 会带源码行与箭头。
