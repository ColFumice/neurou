# 记忆模式目标元素修复（v1.15.0）

## 问题

- F12 后按 Tab 切换弦，再按 F2/F10，编辑目标仍是切换前的元素；
- 从 F2 谱界面返回后，焦点弦被重置为第一根；
- 没有绑定音色谱的弦类型 F2 总是指向第一条谱。

## 修复

### 1. 记忆目标实时同步

- F12 进入时捕获 `memoryKind`；
- 记忆模式内 `focusKind` 变化时同步更新 `memoryKind`；
- F2 / F9 / F10 统一以 `memoryKind` 为目标，而不是重新从焦点推断。

### 2. 返回时恢复焦点弦

- `StringField` 新增 `initialFocusKind`；
- 从谱/流场返回时，按该类型恢复焦点弦，不再重置到第一根；
- 修复了 F2 返回后目标被覆盖为「叙事」的问题。

### 3. 按弦类型音色覆盖

- `StringAudioEngine` 新增：
  - `setKindTimbre(kind, bands, smooth, loop)`
  - `getKindTimbre(kind)`
  - `clearKindTimbre(kind)`
- 记忆模式下 F2 编辑谱时，同时把曲线写入当前目标弦类型的音色覆盖；
- 即使该弦没有 `音色` 绑定，也会使用当前谱的编辑结果发声；
- 拨弦时会优先使用按类型音色覆盖。
