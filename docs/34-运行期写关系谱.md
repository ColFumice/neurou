# 运行期写关系谱（v2.17）

> 关系谱以前是只读作者数据；v2.17 起，规则/和弦/动作的效果可以**改矩阵标量格**。
> `查关系谱` 在后续守卫、效果、结局里都能读到改后的值。

## 1. 语法

在 `效果` 块里：

```nro
力迫 推
  效果
    关系谱 网 甲 乙 += 0.3
```

- `关系谱 <矩阵> <行> <列> = | += | -= <数字表达式>`；
- 矩阵、行/列标签必须在编译期存在；
- 值必须是数字表达式（NRO2003）；
- 矩阵格允许有限数值，不做 0..1 夹取（作者自行保证）；
- 序列化写回同一行。

## 2. 语义与折叠

- 效果按规则顺序执行，立即写入当前世界的矩阵状态；
- 同一拍内的结局/公理检查能看到新值；
- 快照/分叉携带改后的矩阵（`WorldState.matrices` 已有）；
- 编译器会先扫描所有效果里的矩阵写入：
  - 被写过的矩阵，三参数 `查关系谱(...)` **不再折叠成常量**，改为运行时读取；
  - 没被写过的矩阵仍保持编译期折叠（与旧行为一致）；
- 关系谱的**曲线**仍是作者数据，不能在运行期改曲线采样点（只改标量回退值）。

## 3. 与 GUI 的关系

- GUI 的 F3 矩阵视图读取的是**源文件 IR**，不是运行时状态；运行期写入不会实时显示在矩阵画布上；
- 若想观察，可在规则/结局里用 `查关系谱`、`当前谱值` 或在 CLI `sim` 日志里看；
- 退出/刷新 GUI 会回到源文件的作者值（运行期状态不持久化到文字）。

## 4. 示例

```nro
世界 矩阵写

叙事弦 甲
  类型 数值 0..100
  基线 50

关系谱 网
  行 甲 乙
  列 甲 乙
  段 0.2 0.5
  段 0.5 0.7

力迫 推
  效果
    关系谱 网 甲 乙 += 0.3

结局 成: 当 查关系谱("网", "甲", "乙") >= 0.7
```

第一拍：0.5 → 0.8，同拍结局「成」触发。

## 6. 边界

- 只能写标量格，不能增删行列/曲线/改周期速度相位；
- 不参与耦合传导（耦合仍以弦为主）；
- GUI 矩阵预览不反映运行期写入。
