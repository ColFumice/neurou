# neurou 语言规范 v0.1

状态：**已实现**。本文描述 `packages/core` 与 `packages/runtime` 当前真正支持的语法与语义。
标注「未实现」的部分是路线图，不是现状。

---

## 0. 源文件

- 扩展名 `.nro`，UTF-8。
- 一个文件描述一个**世界**。
- 注释：`#` 或 `//`，到行尾。
- 空行与纯注释行不影响缩进层级。
- 缩进：两个空格为惯例。同一行缩进不能混用空格与制表符（NRO1001）。
- 全角标点会被归一化：`：`→`:`、`，`→`,`、`（`→`(`、`“”`→`"` 等。
- `->` 等价于 `→`。

## 1. 声明总览

```
世界 <名字>
实体 <名字> [是 <种类>]
叙事弦|视觉弦|动画弦|物理弦|控制弦|空间弦|认知弦|关系弦 <名字>
耦合 <弦> → <弦> [行内修饰]
回路 <名字>: <链式回路>
回路 <名字> { 边 ... }
力迫 <名字> { 当/效果/不可逆/优先级/先于/可重复/每 }
和弦 <名字> { 当?/效果 }
动作 <名字> { 当?/耗时/效果/描述 }
公理 <名字>: <表达式>
信号 <名字> { 当/台词/视觉/音频/触觉/字幕/提示 }
结局 <名字>: 当 <表达式>
曲式 <名字> { 段落 <名字> 时长 <拍数> }
```

块用缩进表达。字段行是「键 + 值」，冒号可选，例如 `基线 50` 与 `基线: 50` 等价。

## 2. 类型

| 类型 | 写法 | 默认值 |
|---|---|---|
| 数值 | `数值 0..100`（区间可省略） | 下界或 0 |
| 布尔 | `布尔` | 假 |
| 枚举 | `枚举(忠于汉, 观望, 叛逃)` | 第一个值 |
| 集合 | `集合(区域)` | 空集 |
| 文本 | `文本` | 空串 |
| 引用 | `引用(角色)` | 空 |

省略 `类型` 时由 `基线` 推断：数字→数值、真假→布尔、字符串→文本。
两者都没有则报 NRO2008。

**阈值方向是推导出来的，不是声明的**：`悬崖 < 安全` 表示越高越好（危险在低处）；
`悬崖 > 安全` 表示越低越好（危险在高处）。

## 3. 弦

```nro
叙事弦 信任
  类型 数值 0..100
  基线 50
  悬崖 25
  安全 70
  响应 线性        # 线性 | 缓入 | 缓出 | 阶跃
  可见 真
  描述 "……"
```

行内糖：`叙事弦 信任: 类型 数值 0..100, 基线 50, 悬崖 25, 安全 70`

- 顶层声明 = 全局弦；写在 `实体` 块内 = 实体弦，规范 id 为 `实体.名字`。
- 引用规则：先找完整 id；再找唯一短名；短名有歧义时要求写全（NRO2002）。
- `关系弦` 必须写 `对象 <实体>`，规范 id 同样是 `实体.名字`，值通常是 0..1。
- 认知弦通常用集合，追踪「谁知道 / 知道哪些区域」。
- 每类弦有固定的求解器（见总览表）；v0.1 只实现叙事 / 认知 / 关系 / 控制的事件求解，
  视觉 / 动画 / 物理 / 空间目前以「信号投射」形式存在。

## 4. 耦合

```nro
耦合 信任 → 筹码 同向 0.35 延迟 1 当 信任 > 20
```

或块式：

```nro
耦合 信任 → 筹码
  极性 反向
  强度 0.4
  延迟 2
  当 信任 > 20
  曲线 缓入
```

**强度语义**：源弦归一化变化（`Δ / 源量程`）× 强度 × 极性 × 曲线系数 × 目标量程。
两弦量程都是 0..100、强度 0.35 时，源弦掉 10 点，目标弦在 1 拍后掉 3.5 点。

**延迟**：`0` 表示下一拍抵达（一拍是叙事的最小呼吸）；`n` 表示再晚 n 拍。
耦合只在同拍结算一次，不会在同一拍内递归传导——这保证了确定性与可回放。

## 5. 回路

链式（推荐，一行写完）：

```nro
回路 猜忌: 信任↓ → 筹码↓ → 局势↓ → 信任↓
回路 退让: 信任↓ → 让步↑ → 信任↑
```

每个名字后的 `↑/↓` 是它在环上的变化方向。边的极性 = 两端方向相同为同向(+)，
相反为反向(−)。环的极性是各边极性之积：

- `+1` 自我强化：必须有闸门（阈值 / 量程）或一个引用环上弦的结局，否则报 NRO2102；
- `−1` 自我校正：没有阈值时警告可能「死水化」（NRO3106）。

显式块式（可标强度 / 延迟）：

```nro
回路 捕食
  边 蜥蜴.饥饿 → 蜥蜴.对蛞蝓猫的恐惧 反向 0.25
  边 蜥蜴.对蛞蝓猫的恐惧 → 蛞蝓猫.体力 同向 0.15
  边 蛞蝓猫.体力 → 蜥蜴.饥饿 反向 0.1
```

回路的每条边同时就是一条耦合，会参与运行时传导。编译器会检查它是否真的构成一个单环：
每个节点恰好一条出边、一条入边，且走一圈回到起点（NRO2101）。

## 6. 力迫、和弦、动作

三者共享「规则」的执行模型，区别在触发方式。

```nro
力迫 信任崩塌
  当 信任 < 25
  效果
    耐心 -= 15
  不可逆
  优先级 10
  先于 别的力迫
  可重复
  每 4
```

- `当`：省略等于恒真。
- `效果`：`弦 = 值`、`弦 += 值`、`弦 -= 值`、`施加 <和弦>`。
  数值弦加减数值；集合弦用 `+=` / `-=` 增删元素。
- `不可逆`：这一局触发后不回退（记录在时间线上，供分叉/回放使用）。
- `优先级`：数字越大越先判定，默认 0。
- `先于 <力迫名>`：显式偏序，优先于优先级参与拓扑排序；成环报 NRO2103。
- 一次性规则触发后不再触发；`可重复` 表示条件成立即可再次触发，`每 n` 为冷却拍数。

`和弦` 是一组可复用的效果，可被 `施加`，也可以带 `当` 自主触发：

```nro
和弦 摊牌
  效果
    信任 -= 12
    筹码 += 10
  当 筹码 >= 50     # 可选：条件成立时自动触发一次
```

`动作` 是玩家可选的规则，额外有 `耗时`（占用拍数）与 `描述`：

```nro
动作 提出交换
  当 筹码 >= 30
  耗时 2
  效果
    施加 摊牌
    局势 += 4
```

## 7. 公理

```nro
公理 不可双赢: 信任 + 筹码 <= 130
```

每拍结算后校验。违反时**记录并继续运行**，同时拉低音准仪的硬缺陷分。
编译器能做两类静态检查：公理自身恒假（NRO2104）；简单等式公理被某条 `=` 效果直接破坏（NRO2104）。

## 8. 信号

```nro
信号 语气变冷
  当 信任 < 40
  台词 使者: "有些话说出口就收不回去了。"
  视觉 烛光 -0.3
  音频 心跳 0.6
  触觉 桌面轻震
  字幕 "窗外的雨声忽然大了。"
```

信号在条件的**上升沿**触发一次；同一状态不会重复刷屏。
`台词` 的说话者可省略。`触觉/字幕/提示` 可以不加引号直接写中文短句。

任何有阈值却没有被任何信号读取的弦，会得到**静默失败**警告（NRO3101）——
状态变了但玩家感知不到，是体验级缺陷，不是语义错误。

## 9. 结局与曲式

```nro
结局 破裂: 当 信任 <= 10 或 耐心 <= 10

曲式 雨循环
  段落 平静 时长 40
  段落 降雨 时长 30
  段落 洪水 时长 20
```

结局按声明顺序判定，第一个成立的终止本局。没有结局时模拟跑满拍数上限并记为「超时」。
曲式按顺序循环播放；v0.1 尚未提供「当前段落」的查询原语，曲式只推进时间轴与界面提示。

## 10. 表达式

- 字面量：`50`、`0.4`、`"文本"`、`真`、`假`、`{ 管道, 工业区 }`。
- 路径：`信任`、`使者.信任`、`蜥蜴.对蛞蝓猫的恐惧`。
- 运算：`+ - * / %`、`== != < <= > >=`、`且 或 非`（也接受 `&& || !`）。
- 内置函数：`数量(集合)`、`包含(集合, 值)`、`空(集合/文本)`、`最小(a,b)`、`最大(a,b)`、
  `绝对值(x)`、`存在(引用)`。
- 实体名可以直接当引用值：`已知避难所 += 管道`。

## 11. 执行模型

一拍（tick）内的固定顺序：

1. 投递到期的耦合增量；
2. 执行玩家在上一拍选择的动作；
3. 按拓扑序（`先于`）+ 优先级判定力迫与带触发的和弦；
4. 把本拍所有数值变化按耦合传导，排入下一拍；
5. 校验公理；
6. 判定结局；
7. 信号上升沿检测并发射 cue；
8. 阈值穿越统计；
9. 推进曲式段落；
10. 拍数 +1，检测死局（没有任何可做之事才算，动作耗时不算）。

数值一律夹在量程内；夹掉的部分不传导。同一 seed + 同一动作序列 = 同一局。
`Universe.snapshot()` / `branch()` 可冻结与分叉，这是 V[G] 的实现。

## 12. 诊断

三级，呈现位置不同：

| 前缀 | 级别 | 典型码 |
|---|---|---|
| NRO1xxx | 语法 | 缩进、未闭合字符串、缺字段 |
| NRO2xxx | 语义 | 未知名字、歧义、类型不匹配、回路不闭合、公理矛盾、偏序成环 |
| NRO3xxx | 体验 | 静默失败、死弦、结局不可达、无动作、自我校正回路死水化 |

常用码：

| 码 | 含义 |
|---|---|
| NRO2001 | 找不到这个名字（附近似建议） |
| NRO2002 | 短名有歧义 |
| NRO2003 | 类型不匹配 |
| NRO2005 | 阈值不可达 / 基线越界 |
| NRO2101 | 回路不闭合 |
| NRO2102 | 自我强化回路无闸门 |
| NRO2103 | 力迫偏序成环 |
| NRO2104 | 公理矛盾或被效果破坏 |
| NRO2105 | 和弦递归 |
| NRO3101 | 静默失败 |
| NRO3102 | 死弦 |
| NRO3103 | 结局不可达 |
| NRO3104 | 没有结局 |
| NRO3105 | 没有动作 |

每条 error 都带一句人话 `hint`，说明怎么改。

## 13. 音准仪

批量模拟后计算：

| 维度 | 定义 |
|---|---|
| 公理与硬缺陷 | 公理违反次数；有则严重扣分 |
| 玩家能动性 | 「无任何可做之事」的局占比 |
| 规则活性 | 触发过的力迫 / 发出的信号 / 被用过的动作 |
| 结局的分歧 | 结局分布（含超时）的归一化熵 |
| 节奏与吸引子 | 存活拍数的变异系数；最常见终局占比 |

满分被压在 85 以下，绿区 **60–85**。低于 60 站不稳，高于 85 太均衡。
