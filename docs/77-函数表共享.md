# 函数表共享与调用去重（v5.20）

> v5.19 的调用节点携带完整函数体，同一函数多次调用会重复 IR。
> v5.20 把函数体收敛到 `IRFunction.body`，运行时从状态里的函数表查找。

## 1. IR

```ts
interface IRFunction {
  id: string;
  name: string;
  params: string[];
  bodySource: string;
  body?: LExpr; // 含 param 节点，只 lowering 一次
}

type LExpr = {
  k: 'call';
  fn: '用户:夹紧';
  args: LExpr[];
};
```

- 调用节点只保留函数名 + 实参；
- 函数体在编译期只 lower 一次；
- 多个调用点共享同一个函数体 IR；
- 序列化仍写 `函数/参数/返回` 与 `夹紧(...)`。

## 2. 运行时

`WorldState.functions`：

```ts
functions?: Record<string, { name: string; params: string[]; body: LExpr }>;
```

- `createState` 从 `WorldIR.functions` 建表；
- `Universe.restore` 从 IR 重建函数表（旧快照不需要函数体）；
- 用户调用按 `fn` 查表、建立参数环境、求值函数体；
- 缺表时返回 `null`，不崩溃；
- 序列化状态不写函数体（静态作者数据在 IR）。

## 3. 验收

- 单元 **351/351**：新增断言
  - 调用节点不含 `"user"` 重复体；
  - `IRFunction.body` 存在；
  - 运行时按函数表继续得到 50/100 与结局。
- 既有世界不含函数时不变；
- GUI 仍为 276。

## 4. 边界

- 函数表随世界状态携带，快照克隆时浅拷贝；旧快照恢复由 IR 补；
- 没有函数级版本/热替换；
- 函数表不参与序列化状态（避免存档膨胀）；
- 递归仍被编译期拒绝；
- 函数体共享但诊断仍指向声明位置。
