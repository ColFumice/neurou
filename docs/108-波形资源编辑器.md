# 波形 / 资源编辑器（v5.59）

按 `F6` 打开，`Esc` / `F6` 关闭；无打开时无面板 DOM。

## 1. 波形编辑

左栏列出当前可编辑的持续型弦（模块弦被排除）。

- 点击弦名切换；
- 画布上按住拖动直接绘制 32 段波形；
- 预设：正弦 / 三角 / 方波 / 柔波；
- 重置为默认波形；
- 编辑结果写入 IR 并 debounce 写回 `.nro`。

## 2. 资源查看

右栏列出当前世界的：

- 音频资产（BGM/cue）；
- 纹理资产；
- 名称与 src。

这是资源**查看器**；文件增删/重命名仍走源文件。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `F6` | 打开/关闭编辑器 |
| `Esc` | 关闭 |
| 鼠标拖动画布 | 绘制波形 |

`F4` 仍是音量档位，不受影响。

## 5. 边界

- 资源编辑器第一阶段只读；
- 波形编辑仍按 32 段；
- 编辑器覆盖层每次打开时读取当前波形。
