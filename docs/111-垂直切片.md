# 垂直切片（v6.2）

`examples/vertical-slice.nro` 用一个真实世界验证完整链路：

```text
DSL 源文件
→ 编译 / IR
→ 确定性运行时 + Engine
→ 调律台（八弦 / F2 谱 / F3 关系谱 / F6 波形）
→ 视觉端口（GLSL 两 pass + 纹理资产）
→ 音频端口（Faust / WebAudio）
→ 动作 / 场景 / 系统 / 结局
→ 写回 / release
```

## 世界内容

- 8 类弦各一根；
- 持续波形：视觉弦带 8 段显式波形；
- 谱「长音」（持续演奏）；
- 关系谱「信任网」；
- 5 条耦合；
- 2 场景「夜 / 昼」+ 系统「潮汐」；
- 视觉端口「雨幕」绑定纹理资产「雨纹」；
- 音频端口「潮声」；
- 6 条信号；
- 动作「安抚」；
- 结局「安顿」。
