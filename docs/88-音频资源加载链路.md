# 音频资源 Host 加载链路（v5.31）

> v3.7/v3.8 已有 `音频资产` 与 BGM/cue 播放代码，但示例引用的
> `audio/*.wav` 实际不存在。v5.31 补齐真实资源、发布复制与端到端验收。

## 1. 资产文件

示例世界引用：

```nro
音频资产 雨幕 "audio/rain.wav"
音频资产 钟声采样 "audio/clock.wav"
```

仓库现在提供：

| 文件 | 时长 | 内容 |
|---|---|---|
| `audio/rain.wav` | 2.0s | 确定性低通噪声，可循环 |
| `audio/clock.wav` | 0.6s | 880Hz 衰减钟声 |

- 生成脚本：`scripts/generate-audio-assets.mjs`；
- 不依赖网络/外部素材；
- 均为 PCM16 单声道 22050Hz；
- 脚本可重复生成同样字节。

## 2. Host 链路

```text
音频资产声明
  → WorldIR.audioAssets
  → GUI BGM / cue
  → StringAudioEngine.loadAsset(src)
  → fetch('/audio/...') → decodeAudioData → AudioBufferSource
  → master gain（受 F4 音量/静音）
```

- BGM 在首次手势后播放；
- cue 由信号 `音频` 消费；
- 资源缺失时播放失败但不使 Engine 崩溃；
- release 会把 `audio/` 复制到发布包。

## 3. 发布
