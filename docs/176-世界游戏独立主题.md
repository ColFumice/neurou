# 世界游戏独立主题（v1.51.0）

## DSL

游戏声明新增可选字段：

```text
游戏 对拍
  模块 乒乓
  结果弦 步态
  胜利分数 300
  难度 4
  主题 浅色
```

可用：

```text
主题 深色
主题 浅色
```

## 优先级

```text
游戏 DSL 主题
  > 设置页全局主题 / 跟随系统
```

- 游戏声明了主题：进入该游戏时使用声明；
- 未声明：沿用设置页的 dark / light / auto；
- 设置页仍然决定没有覆盖时的默认值。

## 实现

- `GameDecl` / `IRGame` 增加 `theme?: 'dark' | 'light'`；
- parser 支持 `主题 深色/浅色`；
- serializer 往返；
- App `gameBinding.theme` 传给场景，覆盖全局 `gameTheme`。

## 当前边界

- DSL 只支持深色/浅色，不支持跟随系统；
- 主题不影响 GamePicker / 世界主界面；
- 外部插件不能声明主题；
- 没有每款游戏独立色板（只覆盖深/浅主题选择）。
