# F6 移除、F10 全局与持续音色修复（v1.16.0）

## 1. F6 界面已删除

- 移除 F6 波形/资源编辑器模态；
- 移除 `WaveformEditor` 组件；
- F6 不再打开任何界面；
- 保留 F7 规则/动作编辑器。

## 2. F10 不再限制于 F12

- 非记忆模式也可以直接 F10 打开流场效果面板；
- 流场始终绑定当前焦点弦类型：
  - `targetKind = memoryMode ? memoryKind : focusKind`；
- 流场界面 `z-index: 300`，始终在黑底上，不再被记忆模式的全局反色覆盖。

## 3. 持续型弦的音色/效果修复

- 流场的音色目标现在直接作用到弦类型效果总线；
- 目标类型为持续型时，节点触发调用 `startSustainedSpectrum`，而不是一次性拨弦；
- 松开节点释放持续声部；
- `depth` 写入该类型混响发送，`cutoff` 写入该类型低通；
- 持续音始终经过该类型总线，因此 F10 调参立即生效。

## 4. 调律台记忆模式 ESC 退出记忆

- 记忆模式、八弦界面、无弹窗时，ESC 优先退出记忆模式，不进入开始界面；
- F9 效果器面板打开时，ESC 仍先关闭面板；
- 流场打开时，ESC 由流场自己处理。

## 边界

- F6 删除后，波形/资源不再提供 GUI 编辑器；
- 流场在非记忆模式下仍会改当前焦点弦类型的效果总线；
- 持续型弦的节点触发是持续声部，释放即停止；
- 记忆目标、音色覆盖目前仍是运行期状态。
