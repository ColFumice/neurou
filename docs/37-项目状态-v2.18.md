# 项目状态总结（v2.19.1）

> 版本：**v2.19.1** · 分支 `main` · HEAD `3ca958e` · 日期 2026-10-28
> 详细变更见 [CHANGELOG](../CHANGELOG.md)；性能见 [性能与包体](35-性能与包体.md)。

## 1. 项目定位

neurou（雨若）是一门**游戏/叙事创作的领域语言**：创作者不写剧情分支，而是描述弦、耦合、关系谱与规则，
由确定性运行时逐拍演化。仓库包含语言前端、弦网络 IR、运行时、CLI 和极简调律台 GUI。

## 2. 包结构

| 包 | 作用 |
|---|---|
| `packages/core` | AST / lexer / parser / compiler / IR / serialize / patch / edit / 诊断 |
| `packages/runtime` | Universe、状态、快照/分叉、规则求值、三种模拟模型、健康分、参考谱 |
| `packages/cli` | `check` / `run` / `sim` / `ir` 等命令 |
| `packages/gui` | 八弦调律台：弦视图 / F2 谱 / F3 关系谱矩阵 / 写回 |

## 3. 语言 / 运行时能力

- 八类弦、实体、耦合、回路、力迫、和弦、公理、信号、动作、曲式、结局；
- **谱**：段值、范围、插值（线性/平滑/阶跃）、循环、演奏方式、弦音色绑定；
- **关系谱**：行×列标量、每格时间曲线、矩阵级周期/速度/相位、相位源（曲线或标量）、多矩阵；
- **曲线**：单曲线覆盖插值/循环/速度/相位；音色/试听/播放头采样一致；
- **动态耦合**：强度与延迟都可写运行期表达式（关系谱、此刻、弦值）；
- **动态值表达式**：关系谱格子可写 `动态 行 列 表达式`，由谱/其它矩阵/弦值实时计算；
- **内置表达式**：`此刻`、`查谱`、`查关系谱`、`谱位`、`当前谱值`；
- **运行期写关系谱**：规则效果可改矩阵标量，被写矩阵的三参数查表不再编译期折叠；
- 参考谱贴合、快照/分叉、确定性回放、健康分（含参考分维度）。

## 4. GUI 调律台

- 八弦视图：拖弦/拨弦/阈值/耦合编辑、增删弦与耦合、按住绷弦、撤销缓动、行级/块级写回；
- 拖尾：与弦 sim 状态解耦，释手后 <0.8s 完全清空（v2.19.1）；
- F2 谱模式：曲线拖点/增删段点/46 键试听/持续音/音色，阶跃阶梯绘制；
- F3 关系谱矩阵：黑底极简、反色准星/视差/深度、每格曲线与聚焦编辑、节点增删、
  行列增删/内联改名、Shift+Space 增删曲线、播放头与运行时同步、Tab 多矩阵、
  `]`/`[` 调速、`Shift+]`/`Shift+[` 调相位；P 播放/暂停；F2↔F3 互切；
- 写回：源码行级 patch 优先，结构变化回退规范序列化；撤销/重做缓动。

### 包体 / 性能

- 首屏 app entry 64.42 kB（gzip 25.10）+ React/core/runtime 独立缓存 chunk；
- F2/F3 按需加载 + 350ms 预取；

  模拟吞吐约 1.6k–5k 局/s（随机模型）。

## 7. 已知边界

- GUI F3 矩阵显示的是源文件 IR，运行期矩阵写入不实时反映到画布；
- GUI 目前是调律台，不是完整游戏界面；动作/结局在 CLI 模拟里可用，GUI 没有动作选择器；
- 历史文档（如 docs/20、23、27）中的旧验收计数是当时版本，未全部回填；
- 关系谱曲线只支持线性/平滑/阶跃；运行期不能增删行列/曲线；
- 动态格在 GUI 画布上只显示静态回退值；动态格不能被效果写入；
- 性能门禁阈值偏保守，主要用于相对回归。
