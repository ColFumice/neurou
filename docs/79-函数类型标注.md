# 函数参数/返回类型标注（v5.22）

> v5.21 的函数只有调用图诊断。v5.22 给函数加显式类型：
> 参数类型、返回类型、调用实参检查与函数体返回检查。

## 1. 语法

```nro
函数 夹紧
  参数 x: 数值, lo: 数值, hi: 数值
  返回类型 数值
  返回 最大(lo, 最小(x, hi))
```

类型名：

| 标注 | 内部类型 |
|---|---|
| 数值 | number |
| 真假 | boolean |
| 文本 | text |
| 枚举 | enum |
| 集合 | set |
| 引用 | ref |
| 任意 | any |

- 参数类型可省略；
- 返回类型可省略，省略时由函数体推断；
- 实参类型与参数标注不匹配 → `NRO2003`；
- 函数体返回类型与声明不匹配 → `NRO2003`。

## 2. 编译期行为

```text
函数体 lowering 时建立带类型的 param 环境
  → 参数引用得到声明类型
  → 返回表达式得到实际类型
  → 与返回类型标注比较
  → 调用点检查实参
```

- 函数返回值类型会作为调用节点的类型；
- 未标注函数仍是 `any`，不强制检查；
- 递归仍被拒绝。

## 3. 序列化

```nro
函数 夹紧
  参数 x: 数值, lo: 数值, hi: 数值
  返回类型 数值
  返回 最大(lo, 最小(x, hi))
```

`IRFunction.paramTypes` / `returnType` 保存原始标注，序列化 roundtrip 保留。

## 4. 验收

- 单元 **354/354**：新增
  - 类型标注进入 IR 并序列化；
  - 实参类型不匹配报错；
  - 返回类型不匹配报错。
- 未标注函数/既有世界行为不变；
- GUI 仍为 276。

## 5. 边界

- 没有泛型/联合类型/函数类型；
- 没有参数默认值/可变参数；
- 返回类型省略时只做推断，不做跨调用点的严格约束；
- 外部实体/集合元素类型没有细化；
- 错误位置使用调用点/函数体 span，不是完整类型推导链。
