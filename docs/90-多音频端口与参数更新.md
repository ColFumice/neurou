# 多音频端口与每拍参数更新（v5.33）

> v5.32 只编译第一个音频端口、只在预览启动时写一次参数。
> v5.33 为每个音频端口各自建 Faust 节点，并把端口参数每拍写回节点。

## 1. 多端口

```nro
音频端口 潮声
  参数 强度 潮位

音频端口 钟声
  参数 强度 潮位
```

- 每个音频端口独立生成 DSP、独立编译、独立 AudioWorklet 节点；
- 汇总状态：
  - `data-faust-ports`：端口数；
  - `data-faust-nodes`：真实 Faust 节点数；
  - `data-faust-runtime`：`faust-wasm` / `mixed` / `webaudio-fallback`；
  - `data-faust-compile`：全部编译成功才是 `ok`。
- 任一端口失败只回退该端口，不影响其他端口。

## 2. 每拍更新

```text
每拍 frame 更新
  → 读取端口绑定的弦值
  → FaustWasmHost.update(values)
  → node.setParamValue('/<dsp>/<p0>', value)
```

- 参数路径来自 `FaustArtifact.bindings`；
- 回退正弦源也会更新频率/增益；
- 参数更新不重新编译 DSP；
- 端口数量变化时才重新建节点。

## 3. 测试示例

新增 [examples/audio-ports.nro](../examples/audio-ports.nro)：

```nro
音频端口 潮声
  参数 强度 潮位

音频端口 钟声
  参数 强度 潮位
```

打开后按空格进入预览，会同时听到两个 Faust 节点。

## 4. 验收

- 单元 **371/371**（新增示例的编译/模拟冒烟）；
- GUI **283/283**：
  - 2 个音频端口；
  - `data-faust-nodes=2`；
  - `data-faust-compile=ok`；
  - `data-faust-runtime=faust-wasm`；
- 生产冒烟 / perf 通过。

## 5. 边界

- 每个端口一个 AudioContext，节点多时开销线性增长；
- 未做混音总线/主压缩；
- 仍是 mono AudioWorklet，不支持 poly/MIDI；
- 参数只在拍边界更新，不做采样级平滑；
- 没有端口级静音/独奏 UI。
