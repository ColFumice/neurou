# 规则 / 动作编辑器（v6.3）

按 `F7` 打开，`Esc`/`F7` 关闭。

## 可编辑字段

| 规则类型 | 字段 |
|---|---|
| 动作 | `耗时` |
| 力迫 | `优先级`、`每`（冷却） |

和弦暂无数值字段可编辑。

## 写回

- 数值修改走 `setRuleNumberField` → IR；
- 行级 patch 只改 `耗时`/`优先级`/`每` 行；
- 结构签名忽略这三个数值字段，但规则新增/删除/效果/条件变化仍会拒绝；
- 入口项目只列入口规则，模块规则不显示。

## 验收

- 单元：动作耗时 1→2、力迫优先级 4→9 行级 patch 后重编译；
- GUI：F7 打开、列出动作、`+` 改耗时、`saved` + `patch`、文件耗时行更新、Esc 关闭；
- 单元 **390/390**，GUI **315/315**。

## 边界

- 只支持已有数值行/可插入数值字段的编辑，不改效果表达式；
- 和弦没有数值字段；
- 条件/效果结构编辑仍走源文件。
