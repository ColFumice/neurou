# 视觉/音频端口与后端适配器（v5.6）

> GLSL 与 Faust 是后端编译目标，不是弦网络本体。
> v5.6 先把“端口契约”落地：DSL 只声明类型化参数，Host 注入的 BackendAdapter 消费它们。

## 1. DSL

```nro
视觉端口 雨幕
  参数 强度 雨量
  参数 色温 烛光

音频端口 潮声
  参数 潮位 潮位
```

- `视觉端口` / `音频端口` 是运行层声明；
- 参数名 → 已有弦名；端口不创造新状态；
- 参数值每拍从弦当前值投影；
- 绑定不存在的弦在编译期报错；
- 无端口的旧世界完全不变。

## 2. IR 与观测帧

```ts
IRPort {
  id: 'port:视觉:雨幕';
  name: '雨幕';
  kind: '视觉' | '音频';
  params: { name: '强度'; string: '雨量' }[];
}
```

`Engine.observe()` 新增 `ports`：

```ts
frame.ports['port:视觉:雨幕'].params['强度'] // 当拍弦值
```

Host 根据 `kind` 选择 GLSL/Faust 适配器；runtime 不 import WebGL/音频编译器。

## 3. BackendAdapter 契约

```ts
interface BackendAdapter {
  id: string;
  kind: '视觉' | '音频';
  compile(port: BackendPortFrame):
    | { ok: true; artifact?: unknown }
    | { ok: false; error: string; line?: number; column?: number };
}
```

约束：

- 只读端口帧，禁止写回 `WorldState`；
- 编译失败是体验级诊断，不使 Engine 崩溃；
- 源码/端口映射/产物可导出；
- 后端版本由 Host 声明，IR 只保存端口契约。

## 5. 边界

- 没有真正的 GLSL/Faust 编译器；
- 没有端口 GUI 预览/调试面板；
- 参数只支持弦绑定，没有常量/表达式/纹理/事件；
- 一个端口可绑定多根弦，但无采样率/分辨率/格式元数据；
- 后端适配器注册/生命周期尚未实现（v5.7）。
