# CI 模板与迁移检查（v6.19）

## 1. 脚手架 CI

`project` 模板新增：

```text
.github/workflows/neurou.yml
```

流程：

- checkout；
- setup-node 20；
- 安装 `@neurou/cli`；
- `neurou check world.nro`；
- `neurou snapshot-check host-snapshot.json`（可选，文件不存在时继续）。

## 2. 快照兼容性检查

Engine 新增：

```ts
isHostSnapshotCompatible(snapshot): { ok: true } | { ok: false; reason: string }
```

校验：

- 快照是对象；
- `abi === 'neurou-host/1'`；
- `stateVersion === 1`（缺省视为 1）；
- 存在 `state` 对象。

`restoreHostSnapshot` 复用同一检查。

## 3. CLI

```bash
neurou snapshot-check artifacts/host-snapshot.json
```

输出：

```json
{ "ok": true }
```

不兼容时返回非零退出码，适合 CI 门禁。

## 4. 验收

- 单元 **411/411**：
  - ABI/stateVersion/state 检查；
  - 旧快照缺 stateVersion 兼容；
  - 错误 ABI/版本拒绝。
- CLI 冒烟：
  - 生成快照 → `snapshot-check` 输出 ok；
  - project 模板生成 5 个文件含 CI。
- release 18 世界；冒烟/perf 通过。

## 5. 边界

- CI 模板假设 `@neurou/cli` 可安装；
- `snapshot-check` 只校验兼容性，不执行迁移；
- 跨 ABI 仍需要显式迁移器。
