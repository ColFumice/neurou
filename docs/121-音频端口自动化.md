# 音频端口自动化（v6.15）

## 1. DSL

音频端口新增可选字段：

```nro
音频端口 潮声
  参数 强度 信任
  自动化 0.2 0.5 0.9 0.4
```

- 仅音频端口允许；
- 2..64 个采样，值 0..1；
- 周期 = 采样数 × 4 拍；
- 序列化保留该行。

## 2. 运行时

`Engine.observe()` 的端口帧新增：

```ts
automation?: number
```

按当前 tick 在采样之间线性插值。

GUI：

- `data-faust-automation` 列出带自动化的音频端口；
- 每拍用 automation 缩放端口参数，写入 Faust / WebAudio voice。

## 3. 内容

`examples/vertical-story.nro` 的「潮声」带自动化曲线：

```text
自动化 0.2 0.5 0.9 0.4
```

## 4. 验收

- 单元 **404/404**：
  - 自动化进入 IR；
  - tick 0/1/2 采样值；
  - 非音频端口/非法值拒绝。
- GUI **337/337**：
  - 垂直故事端口自动化可观测。
- release 18 世界；冒烟/perf 通过。

## 5. 边界

- 周期固定为采样数 × 4 拍；
- 自动化只驱动参数缩放，不单独创建音频图；
- 暂无 GUI 曲线编辑器（可后续加）。
