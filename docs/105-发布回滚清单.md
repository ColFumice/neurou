## 回滚

1. `git revert <发布提交>`（或 `git reset --hard <上一稳定提交>`）；
2. 重新 `pnpm build && pnpm release`；
3. 重跑生产冒烟；
4. 确认 `release.json` 版本与 HEAD 一致；
5. 清除浏览器缓存/用 `?fresh=1` 复验。
