# 持续波形平滑、变形与拖尾（v5.39）

## 1. 平滑曲线

持续型弦的可编辑波形不再用折线连接采样点：

- 32 段采样 → Catmull-Rom 三次插值；
- 逐帧生成 128 点的平滑曲线；
- 端点用 `sin(πx)` 包络收束，不出现尖角。

## 2. 丝滑变形

编辑波形时不会瞬间跳变：

- 每条持续弦维护一份“显示波形”；
- 目标波形来自 `sustainedWaves`；
- 每帧按指数缓动逼近目标（时间常数约 1/9 秒）；
- 按键/鼠标写入后，曲线平滑变形到新形状。

## 3. 动态模糊与拖尾

- 最近 9 帧显示波形组成拖尾队列；
- 每层按衰减透明度绘制；
- 越旧的帧模糊半径越大（2–12px）；
- 主曲线最后以清晰单线覆盖；
- 现有拨弦 trail 层不受影响。

## 4. 验收

- 单元 **371/371**；

  - 持续波形峰谷差约 170px；

## 5. 边界

- 模糊拖尾是 Canvas filter，不是后处理 FBO；
- 显示缓存按弦类别保存，不写回 `.nro`；
- 变形速度固定，不随音高变化。
