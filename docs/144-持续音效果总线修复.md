# 持续型音弦效果总线修复（v1.19.0）

## 问题

F10 调持续型音弦（视觉/动画等）时，效果完全没有变化。

根因：

- `startSustainedSpectrum` 的音频输出直接接到 `master`；
- 绕过了按弦类型的效果总线；
- 所以 F10 的 depth/cutoff/resonance/drive/LFO 对持续音全部无效。

## 修复

- `startSustainedSpectrum` 增加 `kind` 参数；
- 持续音输出改为：

```text
osc → gain → pan → outputFor(kind)
```

即：

```text
kind input → filter → waveshaper → dry/wet convolver → master
```

- 持续音的音色 profile 也按实际弦类型取 `KIND_AUDIO[kind]`；
- `updateSustainedTone` 使用 voice 绑定的弦类型；
- `updateSustainedSpectrum` 的交叉淡化也会接回类型总线；
- 弦界面鼠标持续音、键盘持续音、F10 节点触发全部传入正确类型。

## 效果链

现在持续型音弦会完整经过：

```text
低通 cutoff
共振 resonance
驱动 drive
滤波 LFO lfoRate / lfoDepth
混响 reverb（dry/wet）
```

因此 F10 与 F9 的效果调整会直接作用于持续音。
