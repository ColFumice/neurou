# 游戏结果直达结局（v1.38.0）

## 目标

游戏结果不只写回弦/动作，还能直接把世界推进到声明的结局。

## 新 DSL 字段

```text
游戏 方块校准
  模块 俄罗斯方块
  结果弦 信任
  胜利分数 40
  胜利动作 安抚
  胜利结局 稳定
  失败结局 破碎
  描述 "..."
```

| 字段 | 说明 |
|---|---|
| 胜利结局 | 分数 ≥ 胜利分数 时强制推进的结局 |
| 失败结局 | 分数 < 胜利分数 时强制推进的结局 |

编译期校验：

- 结局不存在 → 诊断；
- 序列化往返保留字段。

## Host 桥接

新增：

```ts
Engine.forceEnding(name): boolean
Universe.forceEnding(name): boolean
```

- 按结局名/ID 查找；
- 设置 `state.ended`；
- 已结束时不会覆盖已有结局；
- 返回是否成功。

只用于游戏桥接；普通世界仍通过 `结局 ...: 当 ...` 自动判定。

## 游戏结果处理

```text
GameResult
  → 写回结果弦
  → 达到胜利分数：
       dispatch 胜利动作
       forceEnding 胜利结局
  → 未达到：
       forceEnding 失败结局
```

结果提示会追加：

```text
游戏结果已写入「信任」：xx 分 · 结局「稳定」
```

## 示例

`examples/tuner.nro`：

```text
游戏 方块校准
  模块 俄罗斯方块
  结果弦 信任
  胜利分数 40
  胜利结局 稳定
```

分数达到 40 时，世界直接进入「稳定」结局。

## 当前边界

- 游戏结果只会强制一个结局；
- 失败结局也只在主动退出/结束时判定；
- 游戏内没有“返回选择层”；
- 渲染仍未抽 Renderer；
- 游戏会话未进入世界存档。

## 下一步

3. 抽 Renderer / InputProfile；
4. 第三款游戏验证 SDK；
5. 游戏结果触发信号（不只是结局）。
