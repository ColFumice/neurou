# 音频资产：波形文件进入世界（v3.7）

> v3.5 的世界声音是合成音色。v3.7 允许把真实音频文件声明成资产，
> 信号 `音频` 命中资产名时直接播放采样；合成音色仍然可用。

## 1. DSL

```nro
音频资产 钟声采样 "audio/clock.wav"

信号 钟鸣
  当 钟声 > 40
  音频 钟声采样 0.8
```

- 资产是顶层声明：`音频资产 <名字> "<站内路径>"`；
- 路径只允许 `audio/` 下一层的 `.wav / .mp3 / .ogg`，拒绝目录穿越；
- `音频` cue 的参数名解析优先级：
  1. **音频资产**（播放采样）；
  2. 同名/同 id 的**谱**（用谱合成音色）；
  3. 都没有 → 名字哈希合成短音。

## 2. 播放

GUI 侧：

```text
cue(param, value)
  → worldIR.audioAssets 找 param
  → StringAudio.playAsset('/audio/clock.wav', value)
      ensureStarted → fetch → decodeAudioData → AudioBuffer 缓存
  → 经 master gain（受 F4 音量/静音）
```

- 同一个 `src` 只 fetch/decode 一次；
- `value` clamp 0..1 作为单次 gain；
- 资产 404/格式错误时静默失败，不抛 console error；
- 资产播放与拨弦、世界合成 cue、矩阵听音共用同一个 master。

## 3. 内置资产

由 `scripts/gen-audio-assets.mjs` 生成（无外部依赖）：

- `packages/gui/public/audio/clock.wav` 钟声；
- `packages/gui/public/audio/rain.wav` 雨声。

Vite 会把 `public/audio` 原样带到 dev 与生产包。

## 4. 示例

`examples/soundscape.nro` 现在：

- `音频资产 钟声采样 "audio/clock.wav"`；
- `信号 钟鸣` 播资产；
- `信号 余音` 仍用 `铜钟` 谱合成音色；
- 一条世界同时演示“采样”和“谱音色”。

## 6. 边界

- 只有站内 `audio/` 资产，没有上传/外部 URL/流式；
- 资产清单不参与 IR 的确定性回放（声音是表现层，不影响世界值）；
- 没有按资产分类的总线/音量；
- 资产只在 GUI 播放，CLI 模拟不加载；
- 生产包仍是只读试玩，没有资产写入。
