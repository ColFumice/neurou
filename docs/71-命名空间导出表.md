# 命名空间导出表（v5.14）

> v5.12 的命名空间所有短名全局可见。v5.14 加第一版导出表：
> 短名只对导出项生效；全限定名仍总是可用。

## 1. 语法

```nro
命名空间 天气
  导出 雨量

  叙事弦 雨量
    类型 数值 0..100
    基线 40
```

- `导出` 可写多个名字，用逗号分隔；
- 第一版只能导出七类弦；
- 导出不存在的弦在编译期报错；
- 序列化会在 `命名空间` 块里恢复 `导出` 行。

## 2. 可见性

```nro
# 导出后，短名可用
结局 停: 当 雨量 >= 100

# 未导出时，短名报错；全限定名总是可用
结局 停: 当 天气.雨量 >= 100
```

- 短名命中唯一命名空间弦且未导出 → `NRO2001`；
- 全限定名 `天气.雨量` 不受导出表限制（第一版边界）；
- 实体弦/普通全局弦不受影响；
- 命名空间内短名同样受此规则影响（没有作用域自动解析）。

## 3. 验收

- 单元 **344/344**：新增
  - 导出表进入 IR `namespaces`；
  - 导出后短名解析成功、序列化 roundtrip；
  - 未导出短名报错。
- 既有无导出/无命名空间世界行为不变；
- GUI 仍为 273。

## 4. 边界

- 只导出弦，不导出系统/场景/规则；
- 只约束短名，全限定名仍可绕过；
- 没有 `公开/私有` 默认策略；
- 没有跨模块导出重命名/别名；
- 命名空间内没有隐式作用域解析；
- GUI 无导出表展示。
