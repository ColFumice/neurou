# 初始界面过渡与全屏键盘（v1.3.0）

## 1. 初始界面交界

针对「弦穿过文字、透明度过渡断裂」：

- 左栏改为白色渐变 + 中间 `blur(20px)` 白色薄纱；
- 底层弦画布在初始界面启用 mask：

```css
mask-image: linear-gradient(
  90deg,
  transparent 0%,
  transparent 45%,
  rgba(0, 0, 0, 0.22) 50%,
  #000 63%,
  #000 100%
);
```

- 菜单文字列收窄到左栏 78%，不再压到弦上；
- 右半屏弦从 63% 之后完全显现，中间是连续模糊/透明过渡。

截图：`artifacts/134-start-screen-v3.png`。

## 2. 持续弦键盘全屏

`layoutKeyboard(width, height, fillRows=true)` 现在：

- 每行按键宽度 = 屏宽 / 本行键数 → 横向满屏；
- 4 行按键高度 = 屏高 / 4，从上到下铺满；
- 持续型弦按键使用该布局，垂直幅度覆盖全屏。

新增单元：

```text
46 键横向铺满、四行纵向铺满
```
