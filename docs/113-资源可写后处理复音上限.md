# 资源可写 / 后处理调参 / 复音上限（v6.4）

## 1. 资源路径可写

F6 编辑器右栏：

- 点击音频/纹理资产；
- 下方输入框编辑 `src`；
- 失焦/Enter 写回 IR 与 `.nro`；
- 只改路径，不改资产名与引用；
- 走新增 `setAssetSource` + 资产声明行级 patch。

## 2. 后处理可调

- F6 编辑器「后处理」循环三档：关 / 轻 / 重；
- 影响 GLSL 第二 pass 的暗角与颗粒强度；
- 预览 canvas 暴露 `data-post-level`；
- 后处理仍不影响端口 shader 协议。

## 3. 复音上限

- 持续弦最多同时 12 个 voice；
- 超出时偷最早的 voice（先淡出再停）；
- 正常两键复音不受影响；
- 避免无限叠音造成爆音/资源增长。

## 验收

- 单元 **391/391**：资产 src 行级 patch + 重编译；
- GUI **319/319**：资源列表、路径输入、写回文件、后处理档位循环；
- 两 pass / Faust / 复音回归通过。

## 边界

- 资产只能改路径，不能重命名/上传；
- 后处理档位是固定三档，不是任意参数；
- voice stealing 是 oldest-first，不做优先级。
