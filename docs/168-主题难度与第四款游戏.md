# 主题、难度与第四款游戏（v1.43.0）

## 1. GameHost 主题

新增 `gameTheme.ts`：

```ts
GAME_THEME {
  background, ink, dim, line, accent,
  titleFont, monoFont
}

paintGameBackdrop(...)
paintGameBoard(...)
drawGameChrome(...)
```

- 背景 / 暗角统一；
- 网格底板统一；
- 标题、副标题、键位、最高分排版统一；
- Pong 全部使用主题，Tetris/Snake 复用背景与暗角，保留各自 HUD 指标。

## 2. DSL 难度

```text
游戏 对拍
  模块 乒乓
  结果弦 步态
  胜利分数 300
  难度 4
```

编译期限制 1..5；序列化往返保留。

SDK：

```ts
GameParams { difficulty?: number }
GameSession.start(seed, { difficulty })
GameModule.create(seed, params)
```

模块效果：

| 游戏 | 难度 |
|---|---|
| 俄罗斯方块 | 重力间隔缩短 |
| 贪吃蛇 | 初始速度提高 |
| 乒乓 | AI 跟随速度提高 |
| 打砖块 | 球速提高 |

## 3. 第四款游戏：打砖块

新增：

```text
breakoutEngine.ts
BreakoutScene.tsx
```

- 8×5 砖块；
- 挡板、反弹、生命；
- 消完所有砖块获胜；
- 球速随难度提高；
- 存档/恢复；
- 使用 GameHost + GameTheme。

### DSL

```text
游戏 拆墙
  模块 打砖块
  结果弦 重力
  胜利分数 100
  难度 3
```
