# 字符串命名空间（v5.11）

> v5.9 的多文件模块没有隔离，所有名字全局。v5.11 先给字符串加命名空间：
> 模块里的弦可以带前缀，入口用限定名引用，避免同名冲突。

## 1. 语法

```nro
命名空间 天气
  叙事弦 雨量
    类型 数值 0..100
    基线 40
```

入口：

```nro
引入 "lib/weather.nro"

世界 模块命名空间
  版本 0.1

力迫 久旱:
  当 天气.雨量 < 20
  效果
    天气.雨量 += 5
```

规则：

- 命名空间内只允许七类弦（第一版不接纳实体/规则/系统）；
- 弦的规范 id 是 `命名空间.弦名`；
- 命名空间外必须用限定名 `天气.雨量`；
- 命名空间内**不会**自动解析短名，仍建议显式写全；
- 序列化会恢复 `命名空间` 块。

## 2. 与模块组合

模块可以自己包命名空间：

```nro
# examples/lib/weather.nro
命名空间 天气
  叙事弦 雨量
    类型 数值 0..100
    基线 40
```

入口 `引入 "lib/weather.nro"` 后用 `天气.雨量`；模块间同名弦不再冲突。

## 3. 验收

- 单元 **341/341**：新增
  - 限定 id / namespace 字段 / 序列化 roundtrip；
  - 模块命名空间 + 入口限定引用；
  - 命名空间内非弦声明被拒绝。
- 既有世界不含命名空间时行为完全不变；
- GUI 仍为 273，未改表现层。

## 4. 边界

- 只有字符串命名空间，没有实体/系统/场景/规则命名空间；
- 没有短名自动解析/导入别名/导出表；
- 没有嵌套命名空间；
- GUI 显示弦名时仍可能显示带点 id；
- 这是真正隔离前的第一阶段。
