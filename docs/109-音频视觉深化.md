# 音频 / 视觉深化（v5.60）

## 1. 音频复音

持续型弦的按住发声使用独立 voice 表：

- 多个按键可同时按住，形成复音；
- 每个 voice 独立 oscillator/gain/pan；
- 松开单个键只停对应 voice；
- GUI 验收：两个键同时按住 = 2 个持续 voice。

现有自动化：

- `updateSustainedTone` 用 `setTargetAtTime`/linear ramp 平滑音高与音量；
- 波形重建时旧 voice 淡出、新 voice 淡入。

## 2. 视觉多 pass + 后处理

GLSL 预览从单 pass 改为两 pass：

```text
scene shader → FBO texture
→ post shader（暗角 + 颗粒 + uTime）
→ canvas
```

- 每个视觉端口一个 canvas，各自 FBO；
- 尺寸变化时重建 FBO texture；
- `data-glsl-passes="2"` 可观测；
- 后处理为内置，不影响端口 shader 协议。

## 3. 验收

- 单元 **384/384**；
- GUI **305/305**；
- 新增 GUI：多键复音、两 pass FBO 后处理；
- 生产冒烟 / perf 通过。

## 4. 边界

- 复音上限由浏览器/voice 表自然约束，暂未做显式 steal；
- 后处理参数目前固定（暗角 0.55、颗粒 0.035）；
- 多 pass 仅视觉预览，不改变 DSL 端口语义。
